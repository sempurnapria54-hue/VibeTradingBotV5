# VibeTradingBotV5

Алготрейдинговый бот. Java 25 + Spring Boot 4 + PostgreSQL.

## На какой вопрос отвечает этот файл

Каковы базовые правила проекта.

## Где что лежит

Структура каталогов и правила размещения — в
`.claude/rules/structure.md`. Дерево-индекс каталогов и файлов
(с вопросом каждого узла) — `.claude/knowledge-tree.md`;
поддержание порядка — `.claude/rules/curation.md`.

Краткое:
- `donor/` — монолит фазы 1: Java-код, из которого портируются
  сервисы. Единицей развёртывания целевой конструкции не является;
  исчезает, когда порт закончен.
- `services/`, `libs/`, `web/`, `deploy/` — единицы развёртывания,
  общие артефакты, фронт и манифесты монорепозитория; наполняются
  шагами фазы 2 (у каждого каталога свой `README.md`).
- `docs/` — продуктовая документация (модели, lifecycles,
  процессы, правила, словарь, продуктовые решения). Лежит одним
  корпусом на корне; какой сервис чем владеет — вторая ось,
  `.claude/rules/knowledge-ownership-by-service.md`.
- `.claude/` — инфраструктура работы (правила, скиллы, агенты,
  снапшоты, рабочий процесс, заметки, методологические
  решения, библиотека внешних первоисточников —
  `.claude/library/`).
- `.claude-archive/2026-05-21/` — снимок старой инфраструктуры
  пайплайна и старой `docs/` на момент обнуления. Материал, не
  источник истины.

## Базовые правила

- Не коммитить автоматически. Изменения остаются в working tree
  для ручного ревью в IDEA.
- После создания/правки файла — `git add` на него (staging,
  не commit), чтобы изменения были видны в IDEA как staged.
- Язык контента — русский (документация, обсуждения).
  Английский — для технических артефактов (имена файлов, код).
- Правила именования файлов — `.claude/rules/naming.md`.
- Процедура размещения нового знания —
  `.claude/skills/place-knowledge.md`.
- Project Instructions для claude.ai (текст из Settings → Custom
  Instructions) — резервная копия в
  `.claude/chat/chat-project-instructions.md`.
