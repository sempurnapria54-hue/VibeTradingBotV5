# VibeTradingBotV5

Алготрейдинговый бот. Java 21 + Spring Boot 3 + PostgreSQL.

## Где что лежит

- `src/` — код.
- `docs/` — продуктовая документация (домен, спецификации). Может
  содержать сломанные ссылки на старый `.claude/` — чинятся по
  мере встречи, не превентивно.
- `.claude/` — инфраструктура работы с Claude. Пересобирается с
  нуля начиная с 2026-05-21. Текущее состояние и конвенции — в
  `.claude/state.md`.
- `.claude-archive/2026-05-21/` — снимок старой инфраструктуры
  пайплайна на момент обнуления. Материал для будущих решений,
  не источник истины. Брать оттуда что-то — осознанное действие,
  не автоматическое.

## Базовые правила

- Не коммитить автоматически. Изменения остаются в working tree
  для ручного ревью в IDEA.
- После создания/правки файла — `git add` на него (staging, не
  commit), чтобы изменения были видны в IDEA как staged.
- Язык контента — русский (документация, обсуждения). Английский
  — для технических артефактов (имена, код, файлы вроде этого).

Дальнейшие конвенции и процессы — появляются по мере
необходимости в `.claude/`.
