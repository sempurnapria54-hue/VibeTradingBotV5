# deploy/

## На какой вопрос отвечает этот файл

Что кладётся в этот каталог.

Манифесты окружений `dev` / `stage` / `prod` — единственный источник
состояния кластера: Argo CD приводит кластер к ним, ручных
`kubectl apply` в поставке нет (`docs/architecture/platform.md`).

Заводится шагом 2 фазы 2. **Провайдер-специфичного здесь не появляется,
пока провайдер не выбран** (`.claude/work/questions/open-questions.md`
ARCH-Q1): до выбора манифесты описывают кластер на операторах и от
облака не зависят.
