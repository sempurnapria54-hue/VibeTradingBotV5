# Процесс: дистилляция торговой библиотеки

## На какой вопрос отвечает этот файл

Как знание из сырых торговых книг (`.claude/library/trading/raw/`)
выносится в рабочий дистиллят (`.claude/library/trading/distilled/`).

## Назначение

Дистилляция переводит первоисточник (книгу корпуса) в компактное рабочее
знание торгового совета — тезисы с указателями книга+глава+страница,
сгруппированные по пиллерам. Рабочее знание агентов — дистиллят; сырые
PDF — источник правды для глубоких сверок (`.claude/rules/structure.md`,
строки `raw/` и `distilled/`).

## Две точки входа

Процесс один, запускается из двух мест (лестница грунтовки
`.claude/agents/trading-specialist.md`, §Опора на знание):

1. **Самодистилляция из имеющейся книги** (шаг 2 лестницы). Специалист
   упёрся в тему, которой нет в дистилляте (или дистиллят сжал нужную
   деталь), а книга в корпусе **уже есть** → специалист сам ныряет в
   `raw/` через `corpus-map.md` и выносит знание в дистиллят.
2. **Дистилляция нового источника по команде** (шаг 4 лестницы). По
   эскалации «в корпусе нет источника» пользователь докачал новую книгу в
   `raw/` → CC дистиллирует новый источник; результат просматривается.

Дисциплина дистилляции для обеих точек входа одинакова (ниже); различаются
только триггер и кто инициирует.

## Дисциплина дистилляции

- **Размещение.** Новая тема — новый файл пиллера в `distilled/`; часть
  существующей темы — дополнение существующего файла пиллера. Пиллеры:
  risk-and-sizing, system-design, strategy-patterns, microstructure
  (манипуляции — кросс-каттинг внутри микроструктуры/риска).
- **Указатель на каждый тезис.** Каждый тезис выводится из книги `raw/` и
  несёт указатель **книга + глава + страница**. Печатная страница — как в
  колонтитулах; офсет PDF↔печатная фиксируется в `corpus-map.md` per
  книга.
- **Только книжное.** В дистиллят идёт только выводимое из книги.
  Не-книжное (математические свойства / «предполагаю», инженерные
  рекомендации, рассуждения роли, интернет-грунт) сюда **не** идёт.
- **Расхождения и пробелы — явно.** Конфликт источников помечается («⚠»);
  где корпус молчит — секция пробела («∅ в корпусе нет»), не
  достраивается выдумкой.
- **corpus-map.** Новая книга регистрируется в `corpus-map.md` (издание,
  офсет страниц) до простановки указателей.
- **Версионирование.** Дистиллят версионируется; гитигнорится только
  `raw/` (PDF остаются локальными).

## Источник правды

Сырые PDF в `raw/` — источник правды; дистиллят — рабочее представление.
При сомнении / глубокой сверке — нырок в PDF по указателю, не доверие
пересказу.
