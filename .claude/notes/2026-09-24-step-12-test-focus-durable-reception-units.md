# Фокус `test` шага 12: проход по юнитам durable-приёма

## На какой вопрос отвечает этот файл

Какие находки дал проход фокуса `test` по юнитам durable-приёма `audit` и `statistics` 2026-09-24?

## Статус

Вход отчёту фокуса `test`, а не отчёт. Проход — субагент захода 147; вернулся
после конверта сессии. Находки проверены им чтением теста и продуктового кода;
заходом, пишущим отчёт, перепроверяются. `док:N` — строки
`.claude/tests/cases/durable-reception.md`; контракты — в
`services/common/test-support`, порты — в `services/{audit,statistics}/src/test`.
Контекст не поднимается, `U8.5` — `debt`, метка исключена из умолчания обоих
`pom.xml`.

## Находки

1. **U10.13 — невалидность.** `ReceptionGapContract.java:399-416` (док:515):
   контрольная доставка `v+1` даёт `false` и при потерянном ожидании; краснеет
   только на мутации `>` → `>=`; размер `outcomes` не проверен. Правка: `v+2` и
   `isTrue()`, `outcomes.hasSize(8)`.
2. **U10.14 — невалидность, тавтология.** `:430-436` (док:516): `observeDelivery`
   `null` не возвращает — `doesNotContainNull()` вхолостую.
3. **U16.10, U9.1, U9.8 («не пишется ничего») — невалидность.** Порты
   `ReceptionGapTest.java:59-70` обоих деревьев, `ReceptionGapContract.java:452-464`
   (док:666, 478, 485): в сток переданы две операции, прочие уходят в мок молча.
   Правка: все операции службы либо `verifyNoMoreInteractions`.
4. **U11.1, U11.6, U16.9 у `statistics` — невалидность.**
   `statistics/…/ReceptionHaltMarkerTest.java:34-53`: перегрузки
   `accept(DealFact|IncidentFact, String)` в сток не переданы.
5. **U15.4 — невалидность, тавтология.** `ReceptionGapContract.java:441-450`
   (док:637): два прогона одной копии.
6. **U12.13, U12.11 — невалидность.** `TopicRetentionProviderContract.java:146-181`,
   порт `TopicRetentionTest.java:16-18`: провайдер новый на каждый вызов — кеш не
   наблюдаем; «в конфигурацию не пишется» не проверено.
7. **U12.4 — невалидность, слабая.** `:54, 247`: копия приватной константы
   таймаута в заглушке.
8. **U9.12 — невалидность и пробел дока** (док:489): «включая четвёртую» не
   держит ни один прогон (U9.5 непрогоняема).
9. **U3.3, U3.7, U11.3, U1.9, U4.5 — невалидность, слабая.** Равенство двух
   выходов без абсолютного значения из дома.
10. **U15.1, U15.5, U15.6, U15.11 — невалидность либо пробел дока.**
    `ReceptionFormContract.java:69-97`: ищется строка семейства в
    `tools/peer-copy-check.py`, а клетка обещает поведенческое равенство.
11. **U15.10 — пробел дока** (док:644): теста нет, в перечне непрогоняемых нет.
12. **Раздел «Существующий набор предмета» — пробел дока** (док:792-813): замер
    в настоящем времени, команда ссылается на удалённые файлы.
13. **U7.2, U7.20, U8.16 — невалидность, слабая.** Отсутствие поля — тремя
    угаданными именами; `getOccurredAt().isNotNull()`.
14. **U1.7 = U1.1, U2.4 = U2.5 — невалидность, спорно.** Вход и ассерт совпадают.
15. **U9.9 — детерминизм, спорно.** Различение держится сдвигом часов между

16. **U5.7 — детерминизм.** `containsExactly` по `getDeclaredFields()`.
17. **U14.14, U15.7 — пробел покрытия, спорно.** Различие имён держит
