# OKX авто-удаляет trade-ключи без IP-привязки после 14 дней неактивности

## На какой вопрос отвечает этот файл

Что я наблюдал/разведал про протухание OKX API-ключей.

## Наблюдение

OKX **автоматически удаляет** API-ключи с правом trade, у которых
**нет IP-привязки (whitelist)**, после **14 дней неактивности**. Это
вскрылось как причина того, что старый OKX-ключ перестал работать
(подпись отвергалась/ключ не найден) при первом реальном прогоне
приватных вызовов на инфра-сессии 2026-06-12.

## Практический вывод

- Для долгоживущих trade-ключей — задавать **IP-привязку** (тогда
  правило 14 дней не применяется), либо держать ключ «тёплым»
  периодическими вызовами.
- Симптом «ключ внезапно не работает после паузы» → первым делом
  проверить, не удалён ли ключ по этому правилу, а не искать баг в
  подписи.
- Контекст хранения кредов — Vault per-profile
  (`secret/tradingbot/okx[-test]`, см. снапшот v47); пересоздание
  ключа = обновить значение в Vault, код не трогаем.

## Статус

Операционная заметка-разведка. Если правило понадобится как durable
часть онбординга интеграции — кандидат на переезд в
`docs/integrations/okx/rules/`.
