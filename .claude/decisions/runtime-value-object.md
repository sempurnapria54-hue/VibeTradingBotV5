# Runtime value object: где живут runtime-объекты компонентного слоя

## На какой вопрос отвечает этот файл

Где живут runtime-объекты компонентного слоя.

## Контекст

NQ-F третьей обкатки (отчёт
`.claude/work/history/2026-05-27-третья-обкатка-классификации-процессы.md`).
Процессные доки полны объектов вроде `CalculationContext`,
`DealContext`, `MarketPriceData`, `Calculated*`,
`RiskValidationResult`. Они не persisted, не имеют identity и
lifecycle — это носители данных, которые компоненты собирают,
передают и возвращают в runtime. Критерий «самостоятельная
бизнес-сущность» из `model-granularity.md` их не покрывает: это не
доменные сущности и не разделы какой-то одной модели.

## Принятое решение

- Вводится новый продуктовый тип — **Runtime value object (RVO)**.
- Вопрос файла, путь, имя и односторонняя связь живут в
  `.claude/rules/structure.md`, строка `docs/components/models/`; признаки
  RVO — `.claude/skills/classify-type.md`
  §«Runtime value object vs доменная/нативная модель / компонент».

## Альтернативы

- **A. Раздел внутри `<Component>.md` (как «вход/выход»).**
  Отказались: общие контракты (`CalculationContext`,
  `MarketPriceData`) проходят через несколько компонентов — нет
  одного хозяина.
- **B. Условная логика «один владелец → внутри компонента;
  несколько → отдельный каталог».** Отказались: одинаковое
  размещение всегда — проще и однороднее.

## Следствия

- Живёт в `.claude/rules/structure.md`, строка `docs/components/models/`;
  тип и признаки — `.claude/skills/classify-type.md`.
- Закрывает NQ-F третьей обкатки.
