# Пустая строка в позиции агрегатной выборки отвергается

## На какой вопрос отвечает этот файл

Почему строковый компонент позиции агрегатной выборки, названный пустой
строкой, отвергается, а не читается пустым ключом зерна.

## Контекст

Позиция страницы агрегатов лежит компонентами ключа выбранного зерна; три из
них строковые — биржевой счёт, определение стратегии и расчётная валюта. У
двух последних пустота есть **значение**: строка «сделка стратегии не имеет»,
строка «валюта результата не резолвилась», — и позиция, их не назвавшая,
указывает ровно на строку с пустым ключом. Про компонент, названный пустой
строкой (`?cursorStrategyInternalId=` — то, что пошлёт форма, эхом вернувшая
пустую половину позиции), дом молчал. Связыватель параметров отдаёт пустую
строку, выборка сравнивает её значением, а сравнения с пустой строкой не
проходит ни одна строка суток и счёта позиции — ни с пустым ключом, ни с
непустым: хвост страницы выпадал молча. Пустой биржевой счёт позицию к тому же
не половинил — обязательный компонент считался названным.

У журнала тот же класс решён отказом
(`.claude/decisions/journal-read-empty-operand.md`); здесь он не переносится
дословно: у журнала пустота отбора значением не бывает никогда, а у двух
компонентов позиции — законное значение ключа.

## Решение (владелец `statistics`, 2026-09-30)

**Строковый компонент позиции, названный пустым либо из одних пробельных
символов, отвергается отказом класса `QUERY_NOT_ACCEPTED`, и пояснение
называет компонент.** Пустота ключа выражается отсутствием компонента. Дом —
`docs/rules/statistics-aggregates.md` §«Что это за числа и кто их читает»,
пункт о порядке и курсоре.

## Отвергнутые альтернативы

- **Пустая строка читается пустым ключом.** Выглядит естественно именно
  здесь: пустота у двух компонентов законна, и форма, эхом вернувшая пустую
  половину, получила бы верную страницу. Но это второе написание одной
  позиции — отсутствие и пустая строка, — и оно не распространяется на
  биржевой счёт, у которого пустоты-значения нет: одному классу входа
  достались бы два исхода по компоненту. Кроме того, пустая строка есть и
  законное значение `varchar`: поведение выборки на строке с таким ключом
  разошлось бы с поведением позиции.
- **Статус-кво — пустая строка значением.** Отдаёт `200` со страницей, из
  которой молча выпал хвост суток и счёта (`docs/concept.md`, П1).

## Почему так

Дом выборки решает класс «вопрос, который читается двояко» одним исходом —
отказом с названным поводом: окно без границы, перевёрнутое окно, половина
позиции, компоненты чужого зерна. Пустая строка — ещё один член класса, и
толкование для неё было бы единственным исключением. Прецедент журнала даёт
тот же исход по тому же доводу.

## Цена

- **Клиент обязан опускать пустые компоненты позиции**, а не слать их
  пустыми: отданная выборкой позиция несёт пустоту отсутствием, и форма
  фронта (шаг 13) эхом возвращает её тем же. Ошибка видна первым вызовом —
  отказом с названным компонентом.
- **Строка, чей ключ несёт пустую строку, дочитывается до неё, а не за неё.**
  Такой ключ достижим только правкой производителя, кладущего пустую строку
  в определение либо валюту (`docs/models/domain/other/StatisticsFact.md` —
  у ключа счёта приём её отвергает); отданная на ней позиция при возврате
  получит отказ — громкий, а не молчаливая потеря.
