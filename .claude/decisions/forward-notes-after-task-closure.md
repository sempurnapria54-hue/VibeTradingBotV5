# Судьба форвард-заметок после закрытия задачи

## На какой вопрос отвечает этот файл

Где живут форвард-заметки на будущие миграции cross-cutting кластеров
после закрытия задачи-источника.

## Контекст

Миграция 6 торговых сущностей породила обширные форвард-заметки на
cross-cutting кластеры (commands, calc, risk, jobs, FSM-handlers, RVO,
audit, anomaly, market-data, API-OKX) — см.
`.claude/decisions/cross-cutting-parking.md`. Файлы
`.claude/work/questions/tasks/<сущность>.md` содержат не «нерешённые
вопросы по задаче», а указания «при миграции кластера X учесть Y».

По `.claude/rules/structure.md` каталог `work/questions/tasks/`
относится к активным задачам; что с файлами после закрытия — не
определено.

## Принятое решение

После закрытия задачи-источника:

- Файлы прогресса и tasks архивируются (механизм архивирования — на
  усмотрение по skills/structure; ключевое требование — не теряются).
- Указатели на форвард-заметки переезжают в backlog: для каждого
  будущего cross-cutting кластера пункт backlog содержит список
  форвард-заметок (источник + краткая суть «что учесть»).
- При запуске задачи из backlog указатели разворачиваются в полные
  форвард-заметки из соответствующих архивных файлов.

Backlog приобретает структуру с подпунктами на будущие миграции;
конкретные пункты появляются по факту накопления форвард-заметок.

## Альтернативы

- **A. В `history/` без индекса.** Поиск при каждом запуске новой
  задачи. Отказались: при разрастании архива поиск становится тяжелее,
  риск пропустить форвард-заметку.
- **B. Оставить в `questions/tasks/` (отвязка от активности задачи).**
  Отказались: размывает назначение каталога (активная vs завершённая),
  `tasks/` растёт бесконечно, теряется различение по статусу.

## Следствия

- `.claude/rules/structure.md` и скиллы могут потребовать обновления —
  но конкретный механизм архивирования и структура backlog-подпунктов
  определяются при закрытии миграции (механизм оставлен «на
  усмотрение», применение к текущей задаче — отдельный шаг). Поэтому
  правка `structure.md` / скиллов выполняется на шаге закрытия
  миграции, не сейчас.
- Конкретное применение к текущей миграции 6 сущностей (архивирование
  прогресс- и tasks-файлов, перенос указателей в backlog) — отдельный
  шаг (закрытие миграции), сейчас не выполняется.
- Судьба форвард-заметок, поднятая как открытый вопрос в
  `.claude/decisions/cross-cutting-parking.md` (§Следствия), закрыта
  этим решением.
