# Триада принципов миграции

## На какой вопрос отвечает этот файл

Почему фрагменты при миграции из источника, который после миграции
станет недоступен, фиксируются по триаде принципов.

## Контекст

Миграция 6 торговых сущностей и текущая миграция архивных процессов
показали повторяющийся вопрос: что делать с фрагментом, если для его
размещения нет однозначного ответа на одном из шагов классификации —
угадывать, искать промежуточные варианты, дробить решения. Нужен общий
принцип, единый для любой миграции из источника, который после работы
перестаёт быть источником истины (архив помечается deprecated, импорт
извне).

## Принятое решение — триада

При миграции из недоступного позднее источника действуют три правила.

Правила 1 («к архиву после миграции не возвращаемся») и 3 («знаем, куда
положить, — кладём») живут в `.claude/processes/knowledge-classification.md`
§«Перенос из источника, который станет недоступен»; правило 2 («не
угадываем: неоднозначное — в `progress/`, `tasks/` или
`open-questions.md`») — в `.claude/agents/knowledge-curator.md` §«Поведение».

## Связь с самодостаточностью open-questions

Отложенные по правилу 2 решения фиксируются самодостаточно — частный
случай сквозного правила, которое живёт в
`.claude/processes/knowledge-classification.md`
§«Самодостаточность open-questions при недоступном источнике».

## Альтернативы

- **Угадывать при сомнениях.** Отказались: рискуем зафиксировать ошибочное
  знание; восстановить будет тяжелее, чем оставить как open-question.
- **Возвращаться к архиву после миграции по необходимости.** Отказались:
  размывает границу «миграция завершена», архив живёт как теневой источник
  истины параллельно с репо.
- **Материализовать всё, в чём есть малейшие сомнения, как файл-заготовку.**
  Отказались: пустые скелеты в `docs/` размывают принцип «один файл = одно
  знание», создают шум.

## Следствия

Область применения и граница с активным источником живут в
`.claude/processes/knowledge-classification.md`
§«Самодостаточность open-questions при недоступном источнике» и
§«Перенос из источника, который станет недоступен».
