# Код-шаблоны и find-code-examples — разные инструменты разных фаз

## На какой вопрос отвечает этот файл

Почему мы решили развести код-шаблоны и `find-code-examples` как два
разных инструмента, а не держать единый слой «референс-доков».

## Контекст

Вопрос REF-Q1 (`open-questions.md`, заведён 2026-05-31) ставил: какой
тип/место у «референс-доков» для `code-writer` и какого они характера
— абстрактные паттерны/шаблоны или конкретные примеры реального кода.
Исходная формулировка `find-code-examples` смешивала две вещи: и
«опору на умозрительный шаблон», и «живые примеры из проекта», и
постулировала «статических шаблонов кода не держим». Это
противоречило потребности иметь абстрактный шаблон (контроллер) до
появления кода.

## Решение

Два **разных инструмента** под две **разные фазы** под-шага `CODE`:

- **Код-шаблоны** — абстрактные паттерны (плейсхолдеры `<Model>`).
  Фаза — **написание** кода. Тир `.claude/templates/code/` (ветка
  `code/<Язык>/<Паттерн>.md`). Вход для `code-writer`.
- **`find-code-examples`** — скилл **пост-код-дозаполнения доков**:
  *после* написания кода подбирает примеры из **реального
  написанного кода** проекта. Остаётся example-based, но источник —
  сам код, а не отдельный слой «референс-доков».

Отдельного слоя «референс-доков» **нет**: источник примеров — сам
код проекта.

Тир `.claude/templates/` получает две ветки:

- `code/` — код-шаблоны (наполняется; первый — `code/Java/Controller.md`);
- `docs/` — доковые шаблоны (формат доковых файлов; пока пусто).

## Альтернатива (отвергнута)

Единый тир «референс-доки» (исходная рамка REF-Q1), смешивающий
шаблоны для написания и примеры реального кода. Отвергнут: смешивал
две фазы (до кода — паттерн; после кода — пример) и два источника
(умозрительный шаблон vs реальный код), из-за чего `find-code-examples`
нёс противоречивую формулировку.

## Последствия

- Создан тир `.claude/templates/` (`code/` + `docs/`), отражён в
  `.claude/rules/structure.md` и `.claude/rules/naming.md`.
- Материализован первый код-шаблон — `.claude/templates/code/Java/Controller.md`.
- `find-code-examples` переписан под пост-код-фазу над реальным
  кодом; убрано «статических шаблонов кода не держим».
- `code-writer` опирается при письме на `.claude/templates/code/`;
  `find-code-examples` — пост-код, для доков.
- REF-Q1 закрыт (убран из `open-questions.md`), маркер P1 в
  `backlog.md` снят.
