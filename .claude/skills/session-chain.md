# Цепочка сессий без держателя

## На какой вопрос отвечает этот файл

Как гнать роадмап цепочкой неинтерактивных сессий без держателя.

## Что это

Роадмап движется сессиями подряд, каждая — **новая** сессия `claude -p`
со стоячим промптом. Держателя за терминалом нет; цепочка идёт, пока
идёт штатная работа, и **останавливается ровно тогда, когда нужен он**.

Состояние между сессиями живёт в репозитории — реестр компонентов,
роадмап, хроника шага, снапшот, — а не в контексте: свежий контекст
каждой сессии есть цель, а не потеря. Поэтому `--continue` не
используется.

## Запуск

```bash
bash tools/session-loop.sh 5             # не больше пяти сессий за запуск
bash tools/session-loop.sh 5 --dry-run   # показать команду, ничего не тратя
```

Единственный обязательный параметр — **максимум сессий за запуск**. Он же
единственный предел расходов, если не задан `SESSION_MAX_USD`.

Перед первой сессией идёт предполётная проверка: `claude` на месте,
стоячий промпт на месте, bare-режим не включён (проверяется живой пробой —
видит ли сессия `CLAUDE.md`), свободного места хватает. Проба стои́т
порядка $0.1 и делается один раз на запуск, а не на сессию.

## Где журнал

`%LOCALAPPDATA%\vibetrading-stand\sessions\journal.md` — дописывается,
читается пачкой. На каждую сессию: время, статус, гейты, стоимость, число
ходов, отказов прав, итог своими словами. Полные ответы CLI — рядом, в
`sessions\raw\`.

Путь переопределяется `SESSION_LOOP_DIR`. Журнал лежит **вне
репозитория**: это машинный вывод прогона, а не знание проекта.

## Почему остановилось

Причина печатается последней строкой и дописывается в журнал. Она же —
код возврата:

| Код | Причина | Что делает держатель |
|---|---|---|
| 0 | лимит сессий исчерпан либо фаза закрыта | читает журнал, запускает снова |
| 2 | предполётная проверка отказала | чинит названное (нет `claude`, включён bare, не репозиторий) |
| 3 | сессии нужен `подтверждение` | отвечает на вопрос в `.claude/work/questions/open-questions.md` |
| 4 | `blocked` — не хватает доступа | даёт секрет, поднимает среду, докачивает — что названо в итоге |
| 5 | гейты красные | смотрит, какая команда корпуса вернула ненулевой код |
| 6 | отказ CLI или негодный ответ | смотрит `sessions\raw\…json`: аутентификация, лимит, обрыв |
| 7 | предохранитель по диску | освобождает место либо переносит хранилище Docker |

**Повторов нет ни на одной остановке.** Сессия, которая уже уперлась,
повторно упрётся туда же, а стои́т это денег.

## Ручки

Все — переменные среды, все с рабочим умолчанием:

| Переменная | Умолчание | Зачем |
|---|---|---|
| `SESSION_MIN_FREE_GIB` | `10` | порог свободного места там, где живёт хранилище Docker |
| `SESSION_MAX_USD` | не задан | предел расходов одной сессии (`--max-budget-usd`) |
| `SESSION_TIMEOUT` | не задан | предел времени одной сессии (`4h`, `90m`) |
| `SESSION_MODEL` | модель по умолчанию | модель сессий |
| `SESSION_PROMPT` | `tools/session-prompt.md` | иной стоячий промпт |
| `SESSION_LOOP_DIR` | `%LOCALAPPDATA%\vibetrading-stand\sessions` | где журнал |
| `SESSION_PERMISSION_MODE` | `bypassPermissions` | режим прав сессий |

## Чего цепочка НЕ делает

Названо, а не умолчано:

- **не коммитит** — правило проекта оставляет дельту в рабочем дереве под
  ревью держателя (`CLAUDE.md`); за много сессий подряд дельта копится,
  и разбирать её держателю;
- **не поднимает стенд и не выкладывает сборку** сама — это делает
  сессия, когда ей нужно (`.claude/skills/local-stand.md`);
- **не отвечает на вопросы держателя за него** — вынос класса
  `подтверждение` останавливает цепочку, а не решается сам;
- **не ждёт ничего**: `--permission-prompts none` означает, что запрос
  прав отклоняется, а не висит. Число отказов видно в журнале — растущее
  говорит, что режим прав выбран не тот.

## Что стои́т помнить держателю

- **Дельта в рабочем дереве растёт линейно.** Пять сессий подряд — это
  пять заходов правок без коммита. Ревью в IDEA после запуска, не через
  неделю.
- **Стенд растёт медленнее, чем раньше, но растёт.** Выкладка убирает
  прежние образы сервиса из узла (`tools/stand/deploy-services.sh`);
  платформенные образы не трогаются.
- **Гейты — обещание сессии, а не измерение цикла.** `gates_green`
  сообщает сессия; цикл ей верит. Проверка независимой рукой — прогон
  команд корпуса самим держателем
  (`.claude/skills/update-roadmap-progress.md` §«Гейт инструментов
  корпуса»).
