# Ревью устойчивости к сбоям

## На какой вопрос отвечает этот файл

Как именно сделать ревью поведения кода при сбоях и рестартах (фокус
`disaster`).

## Когда применять

Под-шаг `CODE` процесса
`.claude/processes/roadmap-step-execution.md` — фокус `disaster`
адверсариального ревью кода.

## Назначение и границы

Адверсариальный проход по коду шага с фокусом на поведение при
сбоях и рестартах. В фокусе:

- биржа недоступна;
- невалидный респонс от биржи;
- рестарт посреди процесса;
- идемпотентность операций (повторный запуск без дублей);
- оптимистичные блокировки, ретраи, транзакции.

Находим и формулируем замечания; не чиним, не размещаем, не решаем
(адверсариальная стойка).

## Скелет

- **Вход:** утверждаемый код шага + контекст шага (внешние вызовы,
  состояние, точки рестарта).
- **Выход:** список замечаний по устойчивости.
- **Принцип:** независимость, свежий взгляд — спрашиваем «что если
  упадёт здесь», а не исходим из happy-path.

## Доработка

Процедура и форма замечаний дорабатываются по ходу; форма снимается
с первого реального применения на под-шаге `CODE`. Спекулятивную
процедуру здесь не фиксируем.
