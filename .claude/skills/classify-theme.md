# Определение темы

## На какой вопрос отвечает этот файл

Как определить тему фрагмента знания внутри уже выбранного
типа.

## Когда применять

Шаг 4 процесса классификации знания: после того как определены
область и тип, до размещения.

## Что такое тема

Тема — узкая формулировка содержания фрагмента, под которую
именуется файл (kebab-case). Темы существуют **внутри типа**:
например, в типе «правила» темы могут быть «именование»,
«размещение знания», «работа с git», «поведение в чате».

## Процедура определения темы

1. Сформулировать суть фрагмента одним словосочетанием —
   кандидат в тему.
2. Посмотреть существующие файлы в каталоге выбранного типа.
3. Если есть файл с темой, охватывающей фрагмент, — фрагмент
   относится к этой теме.
4. Если темы пересекаются частично — развилка: расширить тему
   существующего файла или завести новый. Без явного признака
   за один из вариантов — обсудить с пользователем.
5. Если совпадений нет — фрагмент образует новую тему.

## Пометка

Скилл в обкатке. Критерии «совпадает тема vs нет», «расширить
существующую vs новую» уточняются по ходу — через накопление
открытых вопросов и оформление решений.
