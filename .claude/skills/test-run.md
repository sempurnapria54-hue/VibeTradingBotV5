# Прогон тест-плана

## На какой вопрос отвечает этот файл

Как именно прогнать утверждённый тест-план контура тестов API
источника.

## Когда применять

Этап **RUN** процесса
`.claude/processes/source-api-testing.md` — после аппрува плана
пользователем. Роль — `tester`.

## Назначение и границы

Прогон кейсов по **утверждённому** плану против API источника через
наш клиентский слой и фиксация результата. Самостоятельная
операция: регрессия гоняется по существующему плану **без
пересоставления** (пересоставление — `test-design`).

Прогон до аппрува не запускается. Write-операции — только demo
(test-профиль, demo-креды); prod — только read-only (см. границы
роли `tester`).

## Известный скелет

- **Вход:** утверждённый тест-план
  (`.claude/tests/{testType}/{source}/`).
- **Исполнение:** кейсы в порядке цепочек графа предусловий;
  **дешёвый негативный слой — первым** (быстрый сигнал до дорогих
  цепочек). Teardown по плану — прогон не оставляет висящих
  ордеров / позиций.
- **Выход:** отчёт прогона — по каждому кейсу **ожидание vs факт** +
  наблюдения; плюс расхождения и неожиданности, не предусмотренные
  кейсом. Отчёт — в `history` (датированный).

**Отчёт полный всегда**, независимо от ступени роли (логирование
отвязано от ступени, как в `question-delegation.md`): ступень
управляет тем, что доходит до пользователя на разбор, не полнотой
отчёта.

## Незадокументированное — не выдумывается

Если по кейсу факт расходится с ожиданием, а спека не задаёт, как
должно быть, — tester не подгоняет вердикт: фиксирует факт +
наблюдение и помечает находкой интегратору (этап «разбор находок»
процесса). Источниковый дефицит — эскалация всегда.

## Доработка

Процедура и форма отчёта дорабатываются по ходу; форма снимается с
первого пилотного прогона. Спекулятивную процедуру здесь не
фиксируем.

## Связи

- Роль — `.claude/agents/tester.md`.
- Построение плана — `.claude/skills/test-design.md`.
- Ревью-фокус отчёта — `.claude/skills/test-review.md`.
- Процесс контура (этап RUN, разбор находок) —
  `.claude/processes/source-api-testing.md`.
