# Ревью производительности

## На какой вопрос отвечает этот файл

Как именно сделать ревью производительности кода (фокус
`performance`).

## Когда применять

Под-шаг `CODE` процесса
`.claude/processes/roadmap-step-execution.md` — фокус `performance`
адверсариального ревью кода.

## Назначение и границы

Адверсариальный проход по коду шага с фокусом на производительность
кода и запросов к БД. В фокусе:

- пакетная работа вместо циклов по одной сущности (N+1 и подобное);
- оптимальность запросов по индексам в разумных пределах;
- дедлоки и конкурентный доступ.

Находим и формулируем замечания; не чиним, не размещаем, не решаем
(адверсариальная стойка).

## Скелет

- **Вход:** утверждаемый код шага + контекст шага (объёмы, частоты).
- **Выход:** список замечаний по производительности.
- **Принцип:** независимость, свежий взгляд; «в разумных пределах» —
  не преждевременная оптимизация.

## Доработка

Процедура и форма замечаний дорабатываются по ходу; форма снимается
с первого реального применения на под-шаге `CODE`. Спекулятивную
процедуру здесь не фиксируем.
