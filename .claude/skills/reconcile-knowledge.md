# Реконсиляция доки под изменившийся код

## На какой вопрос отвечает этот файл

Как привести существующую доку к изменившемуся или удалённому в коде
(операция реконсиляции docs←code).

## Когда применять

Под-шаг `SYNC_DOCS_FROM_CODE` процесса
`.claude/processes/roadmap-step-execution.md`. Применяет роль
`knowledge-curator` (`.claude/agents/knowledge-curator.md`) к
расхождениям типа change / remove из списка
`.claude/skills/divergence-review.md`. Добавления (новое знание из
кода) идут штатным потоком размещения curator, не сюда.

## Назначение и границы

Правит и удаляет уже существующие записи знания так, чтобы они
соответствовали утверждённому коду. Не размещает новое знание (это
штатный поток curator) и не пишет код.

## Скелет

- **Вход:** расхождения change / remove из списка
  `divergence-review`.
- **Операции:**
  - правка / удаление существующей записи под изменившийся /
    удалённый код;
  - проверка референтов — кто ссылался на изменённое / удалённое
    (чтобы ссылки не повисли);
  - перепроверка раздела «На какой вопрос отвечает этот файл»
    затронутой доки (не устарел ли вопрос после правки).
- **Выход:** доки, приведённые к коду; список затронутых референтов.

## Доработка

Обработка референтного каскада (как далеко и как именно чинить
повисшие ссылки) дорабатывается по ходу; форма снимается с первого
реального sync. Спекулятивную процедуру здесь не фиксируем.
