# Распознавание знания

## На какой вопрос отвечает этот файл

Как опознать, что фрагмент из обсуждения стоит зафиксировать в
репозитории.

## Когда применять

Шаг 1 процесса классификации знания. По ходу обсуждения в чате,
фоном. Не для каждой реплики — для содержательных фрагментов,
которые похожи на правило, решение, задачу, открытый вопрос,
наблюдение или описание элемента системы.

## Признаки кандидата на фиксацию

- «давай договоримся, что...», «правило такое...», «впредь
  делаем так...» — кандидат в правило.
- «решили X, потому что Y, альтернативы были Z», «выбираем A
  вместо B, потому что...» — кандидат в решение.
- «надо будет сделать...», «потом сделаем...», «в планах...» —
  кандидат в планируемую задачу.
- «непонятно, как...», «надо подумать про...», «не решили
  пока...» — кандидат в открытый вопрос.
- «заметил, что...», «оказывается...», «по факту сейчас
  устроено так...» — кандидат в наблюдение.
- описание доменного объекта, процесса, состояния, термина
  системы — кандидат в продуктовую документацию (модель,
  процесс, lifecycle, правило системы, словарная статья).

Точный тип определяется на шаге 3 каркаса. На шаге 1 достаточно
опознать, что фрагмент стоит фиксации, и грубо понимать
направление.

## Что НЕ является кандидатом

- **Отрицательные формулировки про модели** — «модель X не
  хранит / не содержит / не имеет Y». Сами по себе не
  фиксируются. Процедура: искать позитивное знание, к которому
  отсылает отрицание (где атрибут действительно хранится, какое
  архитектурное решение стоит за отсутствием). Если есть —
  фиксируем позитивное знание там, где оно живёт; отрицание
  отбрасываем. Если позитивного знания за отрицанием нет —
  отбрасываем как шум. См.
  `.claude/decisions/negative-statements-not-fixated.md`.

## Процедура

1. **Заметить признак.** По ходу обсуждения отслеживать
   фразы-маркеры и содержательные фрагменты.
2. **Сформулировать кандидата.** Что именно предлагается к
   фиксации — одной фразой.
3. **Предложить пользователю зафиксировать** — с короткой
   формулировкой кандидата. Не делать молча. Если кандидат
   расплывчатый — уточнить с пользователем, прежде чем
   двигаться дальше.
4. **По согласию — передать дальше.** Следующие шаги каркаса
   (определение области, типа, темы, размещение) — отдельные
   шаги, не часть распознавания.

## Пометка

Скилл в обкатке. Список признаков и формулы-маркеры
дополняются по ходу — если в обсуждении пропущен кандидат на
фиксацию, признак добавляется сюда.
