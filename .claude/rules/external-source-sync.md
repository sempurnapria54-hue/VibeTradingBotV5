# Синхронизация файлов с внешним источником правды

## На какой вопрос отвечает этот файл

Какое у нас правило синхронизации файлов с внешним источником
правды.

## Правило

После правки файла, у которого источник правды вне репозитория
(внешний сервис, поле в настройках и т. п.), — в отчёте
напомнить о синхронизации. Признак такого файла — раздел в
шапке, явно указывающий внешний источник правды и описывающий
процедуру синхронизации.
