# Синхронизация файлов с внешним источником правды

## На какой вопрос отвечает этот файл

Какое у нас правило синхронизации файлов с внешним источником
правды.

## Правило

После правки файла, у которого источник правды вне репозитория
(внешний сервис, поле в настройках и т. п.), — в отчёте
напомнить о синхронизации. Признак такого файла — раздел в
шапке, явно указывающий внешний источник правды и описывающий
процедуру синхронизации.

## Рантайм-расхождение

Если живой прогон (контур тестов API источника) показал факт,
расходящийся с внешним источником правды (офдоком), расхождение
помечается в шапке «Внешний источник правды» затронутого дока рядом с
датой последней сверки и фиксируется провенансом `рантайм` (C3,
`.claude/decisions/source-api-target-rebase.md`,
`.claude/processes/api-docs-completion.md` §4b). Рантайм-факт не
подменяет офдок молча и не теряется.
