# Отчёт о классификации знания

## На какой вопрос отвечает этот файл

Какое у нас правило отчётности при классификации знания.

## Правило

На каждый фрагмент знания при классификации — отчёт о
результате. Цель — отладка концепции классификации: видно, где
ошибка в логике, где скилл не покрывает случай, где формулировки
скиллов недостаточно точны.

## Содержание отчёта по фрагменту

Что определил на каждом шаге каркаса (область, тип, тема), какие
признаки сработали, чем завершилось:

- размещён в файле X;
- отброшен на шаге Y как Z;
- ушёл в `.claude/work/questions/open-questions.md` со шага W —
  с указанием, на какой вопрос шага нет ответа.

## Форма отчёта зависит от объёма

- **1-2 фрагмента** — отчёт в терминал, по каждому фрагменту
  полная картина по шагам.
- **3 и больше фрагментов** — отчёт в файл
  `.claude/work/progress/<задача>.md` (если задача оформлена) или
  временный файл в той же папке. В терминале — короткое summary:
  сколько фрагментов, сколько размещено / в вопросы / отброшено,
  ссылка на файл с деталями.

## Срок действия

Правило действует на время обкатки концепции классификации.
Когда классификация устаканится — отчёт сворачивается до
конечного результата без детализации по шагам.
