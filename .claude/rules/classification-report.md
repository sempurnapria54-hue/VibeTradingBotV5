# Отчёт о классификации знания

## На какой вопрос отвечает этот файл

Какое у нас правило отчётности при классификации знания.

## Правило

На каждый фрагмент знания при классификации — отчёт о конечном
результате, без детализации по шагам каркаса:

- размещён в файле X;
- отброшен как Y;
- ушёл в `.claude/work/questions/open-questions.md` — с
  указанием, какой вопрос не закрыт.

Детализация по шагам (что определил на каждом шаге, какие
признаки сработали) — только когда результат спорный: фрагмент
не лёг ни в один тип, сработало исключение, или по явному
запросу пользователя.

## Форма отчёта зависит от объёма

- **1-2 фрагмента** — отчёт в терминал.
- **3 и больше фрагментов** — отчёт в файл
  `.claude/work/progress/<задача>.md` (если задача оформлена) или
  временный файл в той же папке. В терминале — короткое summary:
  сколько фрагментов, сколько размещено / в вопросы / отброшено,
  ссылка на файл с деталями.
