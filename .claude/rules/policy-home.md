# Дом политики: одно правило — один носитель

## На какой вопрос отвечает этот файл

Какое у нас правило о единственном носителе-доме каждой политики.

## Правило (решение держателя, 2026-08-26)

**У каждой политики один носитель-дом; все прочие носители ссылаются,
не пересказывают.**

- **Дом** — файл слоя правил по владельцу политики: продуктовая
  политика — `docs/rules/` (или док сущности-владельца, если политика
  принадлежит одной сущности — критерий владельца:
  `.claude/decisions/rule-source-of-truth.md`); политика пайплайна —
  `.claude/rules/`. Обоснование выбора (альтернативы, почему так) —
  в `decisions/`, но действующая формулировка живёт в доме.
- **Все остальные носители** (модель, mapping, lifecycle,
  компонент-доки, решения, рабочие файлы) несут **короткое упоминание
  со ссылкой на дом** — без повтора формулировки. Допустимая длина
  упоминания — строка-две: что политика есть и где дом; состав,
  границы, исключения и снятые редакции не копируются.
- **Правка политики = правка дома + проверка указателей.** Свип
  закрытия вырождается в «поправь дом, проверь указатели»
  (`.claude/processes/roadmap-step-execution.md` §3); пересказ,
  найденный вне дома, сводится к ссылке той же правкой.

## Что правило усиливает

`.claude/decisions/rule-source-of-truth.md` отвечал, **где**
первоисточник правила (кто владеет); это правило добавляет
обязательство **формы** для всех остальных носителей: не «короткое
упоминание желательно», а «пересказ вне дома — дефект». Основание —
анализ шага 7 (`.claude/work/2026-08-26-step-7-question-flow-analysis.md`
§4): одна политика жила в 5-10 носителях, каждый ответ требовал
доводки до N мест, каждый недоведённый носитель становился будущей
находкой (~120 переоткрытий из 368 находок).

## Следствия для существующей базы

- Гиганты распиливаются: действующие политики — по домам, история и
  хроника — в архив, в исходных местах — указатели (начато с
  `docs/rules/pnl-reconciliation.md` и
  `docs/models/domain/aggregate/Deal.md`).
- Дублирование политики по слоям сводится к дому+ссылкам — в первую
  очередь кластеры, дававшие переоткрытия (риск/R, холд, epsilon,
  свежесть, окно bills-линковки, cross-ccy, аномалии, частичный
  выход); не тотально за один заход.
