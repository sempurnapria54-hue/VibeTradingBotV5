# Правила именования файлов

## На какой вопрос отвечает этот файл

Какое у нас правило именования файлов в репозитории.

## Правила

- **Модели и lifecycles:** `PascalCase.md`. Совпадает с именем
  Java-класса (например, `Position.md`, `Order.md`).
- **Решения, правила, скиллы, агенты, процессы,
  словарные статьи:** `kebab-case.md` по теме или сути.
- **Шаблоны:** доковые (`.claude/templates/docs/`) —
  `kebab-case.md` по типу файла; код-шаблоны
  (`.claude/templates/code/`) — `<Язык>/PascalCase.md` по паттерну
  (совпадает с именем кодового конструкта, например
  `Java/Controller.md`).
- **Заметки:** `YYYY-MM-DD-тема.md`. Дата обязательна; её предмет —
  **наблюдение**: заметка описывает корпус на свой день.
- **История задач:** файл-итог `YYYY-MM-DD-<задача>.md` и подпапка
  артефактов `YYYY-MM-DD-<задача>/`. Дата — **закрытия единицы**:
  календарный день, в который единица завела свой **первый** артефакт
  в `history/`. Обе формы несут **одну** дату: заведённая второй
  наследует дату первой и при смене суток не переименовывается.
  Почему закрытие, а не начало и не дата породившего решения —
  `.claude/decisions/history-artifact-date.md`.
- **Снапшоты:** `snapshot-vN.md`, где N — целое число, последний
  по номеру — актуальный.
- **Фиксированные имена:** `CLAUDE.md`, `backlog.md`,
  `open-questions.md`.

## Разведение уровней абстракции

Когда в модели появляется **новый уровень абстракции** над уже
существующим (действие над командой, шаг над операцией и т. п.), имена
уровней разводятся **систематическим маркером-суффиксом**, а не
уникальными основами: основа имени у соседних уровней может совпадать,
уровень читается по суффиксу. Так уровень виден в любом имени, а не
угадывается по словарю.

**Способ разведения — самостоятельная развилка.** Он выбирается **до**
подбора конкретных имён, и в набор вариантов обязаны попасть обе оси:
уникальные основы против систематического маркера. Уже принятое единичное
имя **не считается установленным ограничением** на способ: из того, что
одно имя оказалось непохожим на соседнее, ограничение «имена уровней
обязаны различаться основой» не следует.

Смена способа разведения задним числом — переименование по всем
потребителям (значения enum, персистентные значения, ключи конфигурации,
внешние контракты), поэтому развилка проходится до имён, а не после.

## Чего НЕ используем

- Номера в стиле `ADR-0001`, `RFC-002` и т. п. для решений.
- Даты в именах решений, моделей, процессов, правил, скиллов,
  агентов, шаблонов, файлов в `progress/`.
- Префиксы по статусу (`draft-`, `wip-`, `final-`) — статус
  виден из расположения (backlog vs progress vs history).
