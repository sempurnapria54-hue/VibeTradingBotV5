## Методология тест-коллекций (внесено в этой сессии)

5 durable-правил, размещены по конвенциям (каждый дом самодостаточен —
правило переформулировано под задачу дома, не вынесено в справочник):

1. **Полнота покрытия** — план перечисляет всю интеграционную
   поверхность источника, осмысленный кейс на каждый запрос клиентского
   слоя (не подмножество; объём режет только триггер).
2. **Полноценные кейсы + teardown в каждом** — кейс самодостаточен и
   оставляет биржу чистой; teardown внутри кейса, не общим финалом.
3. **Формат — таблица на кейс** — 1 кейс = 1 отдельная таблица, строка =
   запрос кейса (с проверками и ожиданием).
4. **Папка ↔ таблица** — в коллекции 1 папка = 1 таблица плана (кейс),
   структурное соответствие план↔коллекция один-к-одному.
5. **Цена с биржи, минимальный риск** — live-цена с биржи (ticker/mark),
   ордер заведомо неисполнимый с минимальным риском; цену не выдумывать.

**ПРЕДУСЛОВИЕ правила 5 — открытый surface-gap:** в `OkxProxyController`
**нет live-price эндпоинта** (ticker/mark); есть instrument-спека,
balance, чтения order/position/fills, write'ы. Зависимость зафиксирована
как предусловие в правилах; **эндпоинт не строился**. Закрытие gap
(добавить ticker/mark passthrough в прокси) — **предусловие регенерации**.

**Пилотные план + коллекция + окружение — ИНТЕРИМ** (до-ревизионные):
сгенерированы прежде правил, **регенерятся в новом чате** по новым
правилам. Файлы — `.claude/tests/source-api/okx/`.

## Находки на маршрутизацию (ступень Предложение — НЕ финализировать)

Материал, который новый чат маршрутизирует по владельцам (преим.
`integrator`). Заземление — run-log.

- **F1** — write-реджект был непрозрачен → **fixed** (видимость:
  `OkxWriteLoggingInterceptor` + top-level fallback в мапперах).
- **F2** — `getOrder` not-found → HTTP 500 (51603) → **open**; упирается
  в error-политику (шаг 6, TBD `codestyle.md`). Бьёт также в D-B3
  (recovery-by-clientId требует null-on-not-found).
- **F3a** — per-element `sCode` не биндился (Jackson 3 × Lombok) →
  **fixed** (`@JsonProperty`).
- **F3b / В-9** — **open**: адаптер хардкодит `posSide=net`/
  `tdMode=isolated`, нет bootstrap-проверки `acctLv` → глухой 51010;
  должен fail-fast с внятным сообщением. (Слои 51010 account-mode и 50033
  instrument-restriction сняты пользователем на стороне demo-аккаунта —
  не код.) **Самый содержательный для routing** — проектирование
  bootstrap-проверки адаптера.
- **F4** — системный Jackson 3 × Lombok мангли́нг → **fixed interim**
  (5 read-DTO `cTime`/`uTime` + round-trip тесты, `backlog.md` §I4);
  **open:** recurrence-guard (глобальный Jackson-конфиг vs конвенция
  `@JsonProperty`) + sweep будущих/иных источников DTO.
- **A3** — `cancel-advance-algos` **жив на demo** вопреки офдоку OKX
  2025-04-24 → **open**: правка
  `docs/integrations/okx/contracts/algo-order.md` в сторону «эндпоинт
  живой» (факт из прогона).
- **reduce-only trailing без позиции** принимается на demo —
  **наблюдение**.
- **C2** — адаптер-инварианты `tdMode`/`posSide`/`reduceOnly` не
  маппятся в `OrderExternalSnapshot` → проверка инвариантов по снапшоту
  ненаблюдаема — **наблюдение**.
