## Путь к точке (от v52)

v52 оставил контур на пороге **CODE** (DESIGN аппрувнут: план 2124 стр +
коллекция 60 эндпоинтов / 310 запросов + решение). С тех пор:

**1. CODE сдан и принят.**
- **Production-side** (часть 1): публичный обобщённый `dispatch` в
  `OkxRestClient` (3 потребителя: продукт через типизированные методы,
  код-тесты и Postman — через `/raw`); generic `POST /api/proxy/okx/raw`
  на `OkxProxyController` (конверт → `OkxApiResponse<JsonNode>`, гейт
  `@Profile("!prod")`); снос unused типизированных проксиметодов.
  **Типизированные методы клиента и мапперы — остались** (ими пользуется
  продукт).
- **Doc-модель** `OkxRawApiRequest` (конверт `{method, path, query, body,
  signed}`).
- **Код-тесты** (часть 2): **60 классов / 310 запросов**, база
  `OkxSourceApiLiveTestBase`, класс на эндпоинт (M1-M21, TG1-9, AG1-12,
  MG1-10, PG1-8) + offline-probe I-cred. 1:1 с планом; бьют в тот же
  `/raw`.

**2. Тест-инфра переделана** (только тест-слой; production не тронут;
детали — `.claude/notes/2026-06-19-source-api-code-tests.md`):
- **Throttle на каждый запрос** в `raw()` (пол 1с, **per-case override**)
  + **retry-on-429** (backoff); троттл измеряется глобально → покрывает и
  стык между тестами; троттл — **единственный пейсер поллинга** (не
  складывается с poll-интервалом наивно).
- **Per-case poll-timeout** (дефолт 25с, override полем/аргументом).
- **sweep+halt** (`assertRestoredOrHalt`), scope (i) «по-кейсовый sweep»:
  невозврат состояния → **жёсткий фейл** + **по-кейсовый sweep** (кейс
  чистит свой след) + **halt** прогона, если sweep не вычистил. Едино для
  **сущностей и настроек** — это **переопределяет девиацию #5** (настройки
  `acctLv`/`leverage`/`posMode` больше не «находка, не фейл», а под
  sweep+halt как сущности). Находка **C3 логируется всегда**. **И-2
  trailing** (`cancel-advance-algos`) — тоже под halt (раньше soft).
- **Формат ошибки**: каждый путь фейла (assert, исключение `raw()`,
  таймаут поллинга, halt) несёт **case + запрос (method/path/body) +
  ошибку**; `RawResponse` тянет породивший `RawRequest`, `currentCaseId`
  — из `@DisplayName`/`step()`.
- **Архитектура A** (`@Test`-классы `@SpringBootTest`) + **детерминированный
  порядок прогона**: `@Order` по структуре плана (классы M→TG→AG→MG→PG =
  1..60; методы по плану = 10,20,…), orderers в
  `src/test/resources/junit-platform.properties`
  (`ClassOrderer`/`MethodOrderer` = `OrderAnnotation`). Делает **halt**
  осмысленным: «дальше не идём» = всё, что после в этом порядке.
- **Глобальная sweep-эскалация — отложена** («пока хватает по-кейсовой»).
- **Доки синхронизированы** под изменённый инвариант:
  `source-api-target-rebase.md` §Принцип, `plan.md` §Сквозные проверки,
  `skills/test-code.md` (throttle/poll/sweep-halt/error-format/порядок).

## Среда (уточнение против v52)

**CC компилирует.** Доступны `javac` (corretto-25) и `mvn` (Maven 3.9.11,
бандл IDEA/`~/.m2/wrapper`) — `mvn test-compile` гоняется в shell CC. v52
ошибочно полагал «нет Java/Maven в shell CC»; это снято. **Голый `javac`
по всему `~/.m2` даёт ложные успехи** (подхватывает стейл-jar'ы, напр. SB3
с `TestRestTemplate`) — авторитет компиляции **`mvn test-compile`**.

**Demo-RUN — по-прежнему за пользователем.** Исполнение против реального
demo-OKX требует Vault test-кредов + demo-аккаунта + поднятого
Postgres-test; в shell CC этого нет.

## Следующий шаг — demo-RUN (за пользователем)

1. **Пользователь поднимает среду** (Vault test + demo + Postgres-test) и
   прогоняет закалённые тесты против demo. **Прогон одно-форковый** (без
   surefire `forkCount>1`; иначе halt-«всё после» считается лишь в
   пределах форка). **AG5** (`bills-history-archive`) жжёт квоту
   **12/сутки** — гонять осознанно.
2. **CC отлаживает под реальный API** (режим debug-under-API):
   - тест упал из-за тест-бага → **правит тест**;
   - API ≠ дока (реальное поведение расходится с апидоком) → **находка
     C3**, тест **не трогает**;
   - неоднозначное (не ясно, баг или контракт) → **выносит вопросом**.
3. **C3 apidoc-sync**: CC обновляет затронутые апидоки (`integrator`,
   владелец интеграции; `external-source-sync` — офдок источник правды,
   рантайм-расхождение помечается провенансом `рантайм`).

Фаза 3 prod — вне контура (ад-хок пользователем).

## Принципы (что изменилось против v52)

- **Инвариант восстановления — теперь sweep+halt, едино для сущностей и
  настроек.** Невозврат → жёсткий фейл + по-кейсовый sweep + halt если не
  вычистил; находка C3 всегда. (v52: «невозврат настройки → находка»;
  теперь настройка фейлит как сущность, но находка пишется.)
- Прочие принципы v52 — в силе (контур проверяет контракт биржи не наш
  код; `/raw`-only dispatch; цель — документировать реальное поведение
  OKX; структурный изоморфизм план↔коллекция↔тесты).
