## Что изменилось относительно v14

### Новый тип знания

- **Роадмап.** Размещение — `.claude/work/roadmap/`. Главный
  файл — таблица фаз; детальный файл фазы — таблица шагов.
  Scope — только продукт (бизнес-ценность); пайплайн вне.
  Введён decision `.claude/decisions/product-roadmap-type.md`.

### Новые файлы

- `.claude/decisions/product-roadmap-type.md` — обоснование
  типа: scope, принцип ценности (нет «Фазы 0»), уровни,
  источник наполнения, размещение по назначению, тулинг inline,
  связь с backlog, прогресс в самом роадмапе.
- `.claude/work/roadmap/roadmap.md` — главный роадмап (фазы 1-5
  + архитектурный рубеж, все `HOLD`).
- `.claude/work/roadmap/phase-1.md` — детальный роадмап Фазы 1
  (10 шагов: рыночные данные → стратегия → индикаторы → команды
  → риск-преконтроль → FSM → сделки и P&L → AnomalyJob → тесты
  → фронт; все `HOLD`).
- `.claude/processes/roadmap-step-execution.md` — процесс
  docs-first исполнения шага. Канонический набор статусов шага
  (`HOLD` / `TOOLING` / `DOCS_CHECK_N` / `GAPS_CLOSE_N` /
  `CODE` / `DONE`).
- `.claude/skills/update-roadmap-progress.md` — скилл
  обновления статуса шага и пересчёта статуса фазы (ролляп).
