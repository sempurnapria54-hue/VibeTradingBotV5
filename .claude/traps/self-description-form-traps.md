# Ловушки дома `.claude/rules/self-description-form.md`

## На какой вопрос отвечает этот файл

Как узнать и обойти ловушку, которую собрал дом `.claude/rules/self-description-form.md`?

Тела ловушек; оглавление — в самом доме, раздел «Ловушки». Адрес тела — заголовок с номером; форма и правило чтения — `.claude/rules/structure.md`, строка `.claude/traps/`.

### SD-001

- **Порождённый блок `passes:` берёт ПУТЬ-ПРЕФИКС**, а не имя файла:
  `passes:.claude/work/progress/<префикс>`, и тело печатает генератор.
  *(с 2026-09-11)*

### SD-002

- **Проза и таблица одной секции считают РАЗНЫЕ сущности**: таблица позиции
  считала слова, проза — поля, и свип по «числу слов» прозу не увидел. Проба
  строится по **обеим** осям счёта, а не по той, которую правка трогала.
  *(с 2026-09-11)*
