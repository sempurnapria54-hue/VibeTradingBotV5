# Продуктовый роадмап

## На какой вопрос отвечает этот файл

Какими фазами продукт движется к бизнес-ценности. Статус каждой
фазы — атрибут ответа (колонка таблицы).

## Назначение

Карта продуктового движения. Верхний уровень — фазы как
бизнес-способности. Детальный уровень — шаги внутри фазы в
отдельных файлах `phase-<N>.md`. Глубже шаги заранее не дробятся
— детализация рождается в процессе исполнения шага
(`.claude/processes/roadmap-step-execution.md`).

Scope — только продукт (бизнес-ценность). Пайплайн в роадмап не
входит. Обоснование, принципы наполнения, связь с backlog,
правила прогресса — `.claude/decisions/product-roadmap-type.md`.
Пересборка под сервисную платформу (2026-09-04) —
`.claude/decisions/roadmap-rebuild-for-service-platform.md`; целевая
конструкция — `docs/architecture/`.

## Примечания

- **Фронт** не отдельная строка фазы, а шаг в конце каждой фазы
  (см. детальные таблицы). Зрелость фронта — атрибут самого шага:
  простой для прогонов в фазах 2-4, полноценный — шаг фазы 5.
- **Тесты** также — шаг в конце каждой фазы (перед фронтом).
- **Статус фазы — производный.** Считается ролляпом статусов её
  шагов (см. `.claude/skills/update-roadmap-progress.md`):
  все шаги `HOLD` → фаза `HOLD`; все шаги `DONE` → фаза `DONE`;
  иначе → `IN_PROGRESS`. **`FOLDED`** — ставится вручную решением
  держателя: фаза растворена в новом роадмапе, выполненные шаги
  остаются `DONE`, снятые убраны, гейт закрытия фазы не исполняется.
- **Прод-рубеж** не фаза; ролляп не считается, статус ведётся вручную.
  Его прохождение исполняет гейт закрытия фазы
  (`.claude/skills/update-roadmap-progress.md` §«Гейт закрытия фазы») по
  встречным якорям `backlog.md`, переякоренным с «конец фазы 1» на
  «прод-рубеж».
- **Порядок фаз 3-6 — предложение**, ждёт подтверждения держателя
  (`.claude/work/questions/open-questions.md` ARCH-Q2). До ответа
  фаза 2 идёт как есть: от порядка последующих она не зависит.
- **Зависимость фаза 7 ← IND-Q1.** Крипто-надёжность спот-объёма CEX
  (открытый вопрос IND-Q1, книжная часть закрыта) добирается к фазе
  мониторинга, где встаёт продуктовый подбор инструмента/площадки. Якорь —
  `.claude/work/questions/open-questions.md` §IND-Q1.
