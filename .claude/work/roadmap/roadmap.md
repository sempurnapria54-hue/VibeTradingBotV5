# Продуктовый роадмап

## На какой вопрос отвечает этот файл

Куда движется продукт по бизнес-ценности и в каком статусе каждая
фаза.

## Назначение

Карта продуктового движения. Верхний уровень — фазы как
бизнес-способности. Детальный уровень — шаги внутри фазы в
отдельных файлах `phase-<N>.md`. Глубже шаги заранее не дробятся
— детализация рождается в процессе исполнения шага
(`.claude/processes/roadmap-step-execution.md`).

Scope — только продукт (бизнес-ценность). Пайплайн в роадмап не
входит. Обоснование, принципы наполнения, связь с backlog,
правила прогресса — `.claude/decisions/product-roadmap-type.md`.

## Фазы

| Фаза | Описание | Статус |
|---|---|---|
| 1 | Полноценная торговля одной стратегией | IN_PROGRESS |
| 2 | Бэктест-гейт + аудит (без прохождения бэктеста стратегия не активируется и не торгует) | HOLD |
| 3 | Портфель инструментов | HOLD |
| Архитектурный рубеж *(не основная фаза)* | После доказательства жизнеспособности: распил на микросервисы + мониторинг → как полноценный продукт | HOLD |
| 4 | Анализ рынка (фазы/структура) + заведение новых инструментов, которые затем покрываются бэктестом | HOLD |
| 5 | Продукт предлагает собственную стратегию + детекция аномалий рынка | HOLD |

## Примечания

- **Фронт** не отдельная строка фазы, а шаг в конце каждой фазы
  (см. детальные таблицы). Зрелость фронта — атрибут самого шага:
  до архитектурного рубежа — простой (для прогонов), после —
  полноценный.
- **Тесты** также — шаг в конце каждой фазы (перед фронтом).
- **Статус фазы — производный.** Считается ролляпом статусов её
  шагов (см. `.claude/skills/update-roadmap-progress.md`):
  все шаги `HOLD` → фаза `HOLD`; все шаги `DONE` → фаза `DONE`;
  иначе → `IN_PROGRESS`.
- **Архитектурный рубеж** не основная фаза; ролляп не считается,
  статус ведётся вручную.
- **Зависимость фаза 4 ← IND-Q1.** Крипто-надёжность спот-объёма CEX
  (открытый вопрос IND-Q1, книжная часть закрыта) добирается к фазе 4,
  где встаёт продуктовый подбор инструмента/площадки; до фазы 4 не
  добирается (в фазе 1 инструмент/стратегия — ручной выбор пользователя;
  объёмное условие уже ограничено ролью подтверждающего фильтра). Якорь —
  `.claude/work/questions/open-questions.md` §IND-Q1.
