# Фаза 1. Полноценная торговля одной стратегией

## На какой вопрос отвечает этот файл

В каком статусе каждый шаг Фазы 1.

## Назначение

Детальный роадмап Фазы 1. Главный роадмап —
`.claude/work/roadmap/roadmap.md`. Процесс исполнения шага —
`.claude/processes/roadmap-step-execution.md` (там же канонический
набор статусов шага). Скилл ведения прогресса —
`.claude/skills/update-roadmap-progress.md`.

Файл держит только таблицу статусов и живые примечания к
будущим шагам. Хроника текущего шага —
`.claude/work/progress/phase-1-step-<M>-chronicle.md`; итоги и
хроники завершённых шагов — chronicle-файлы в
`.claude/work/history/` (подпапки `YYYY-MM-DD-phase-1-step-<M>-*`;
правило — `.claude/rules/closed-work-transfer.md`).

## Цель фазы

Бот торгует одной стратегией end-to-end: получает рыночные
данные, рассчитывает индикаторы, генерирует сигналы, отправляет
команды на биржу, ведёт позиции, фиксирует P&L. Полный
production-flow одной стратегии.

## Примечания (будущие шаги)

- **Безопасность (шаг 9)** — строит auth-инфраструктуру (Spring
  Security, `@PreAuthorize`, `SecurityFilterChain`). Vault-привязка
  секретов введена раньше — на инфра-шаге; шаг 9 рескоуплен на
  остаточный хардненинг секретов (политики/approle, ротация, unseal)
  поверх уже подключённого Vault. Содержание прорабатывается
  docs-first на самом шаге; на нём реактивируется фокус
  `security-review`. Форвард-материал — `.claude/work/backlog.md`
  §S1 / §S2.
- **Тесты (шаг 10)** и **Фронт (шаг 11)** — отдельные шаги фазы,
  исполняются по тому же процессу docs-first. Фронт — простой, для
  прогонов; полноценный появится после архитектурного рубежа.
- Под-шаги внутри каждого шага заранее не дробятся; они
  появляются в процессе исполнения (см. процесс).
- **Закрытие фазы — не только последний шаг `DONE`.** До перевода фазы в
  `DONE` проходится `.claude/work/backlog.md` §«Закрытие фазы 1 —
  обязательный пересмотр допущения "таблицы пусты"»: снятие
  `.claude/rules/pre-launch-schema-changes.md` и ревизия миграций,
  написанных под пустые таблицы. Механический триггер —
  `.claude/skills/update-roadmap-progress.md` §«Гейт закрытия фазы».
