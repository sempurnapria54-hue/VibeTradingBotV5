# Прод-рубеж

## На какой вопрос отвечает этот файл

Какие условия гейтят первый прод-запуск и в каком они состоянии.

## Назначение

Прод-рубеж — гейт, не фаза: ролляп не считается, статус строки в
`.claude/work/roadmap/roadmap.md` ведётся вручную. Прохождение исполняет
гейт закрытия фазы (`.claude/skills/update-roadmap-progress.md`
§«Гейт закрытия фазы») по встречным якорям `.claude/work/backlog.md`.
