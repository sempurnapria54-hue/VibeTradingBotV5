## Правило узла

**У каждой выборки поверхности чтения названы три операнда её конструкции:
состав входа — какие отборы она принимает и какие из них обязательны;
единица страницы — предмет, по которому идут порядок, курсор и строка
ответа; исполнитель выдачи — модуль и подключение, которым он добывает
каждую отдаваемую величину.**

**Правило не изобретено закрытием — оно расширяет радиус уже записанного.**
`docs/rules/writer-named-for-every-value.md` требует у каждой отдаваемой
величины актора и момент; §«Писатель обязан быть достижим» добавляет, что
у актора обязан быть достижимый момент вызова. Узел поднимает то же
требование со **значения** на **выборку, которая значения отдаёт**: у
выборки конструктивных операндов три, и недоназванный операнд оставляет
автору кода выбор, который корпус считает объявленным.

Три находки узла — по операнду на каждую:

| Находка | Операнд, который у неё не назван |
|---|---|
| A2 | состав входа журнальной выборки: принимает ли она отборы по четырём колонкам радиуса |
| A3 | единица страницы агрегатной выборки: зёрен два, а выборка объявлена одна |
| C2 | исполнитель выдачи агрегатов и подключение, которым он берёт границу полноты из чужой базы |

## Уровень пробела

**Концепция-стык** у всех трёх (`.claude/skills/classify-gap-level.md`):
предмет связывает дом представления в БД (что такое колонка радиуса), два
дома ограничений отбора, дом раскладки ролей и подключений и границу шага.
Закрывается правкой домов, а не заведением нового носителя: дом каждого из
трёх операндов уже существует.

## Популяция правила

Осей четыре при трёх родах: две предметные (операнды конструкции;
операнды входа), носительская и окрестностная. Расщепление предметной
намеренно — перечень операндов конструкции полон по **конструкции** и
молчит о том, чем набит состав входа каждой выборки.

### Ось 1 (предметная): «выборка × операнд конструкции»

**Команда вывода перечня выборок:**

    grep -n -oUzP '(?s)выборок две[^.]{0,200}' docs/models/domain/other/AuditRecord.md
    grep -n -oUzP '(?s)по одной\s+выборке на предмет' .claude/work/backlog.md
    grep -n 'по одной выборке$' .claude/work/roadmap/phase-2.md

Три операнда — разрез самого правила узла, а не выдача команды; перечень
их закрыт формулировкой правила.

| Член | Исход |
|---|---|
| журнальная × состав входа | **правлено этим узлом**: вход принимает четыре необязательных отбора по колонкам радиуса сверх обязательных тенанта и окна (правка 1) |
| журнальная × единица страницы | **правило выполняется**: строка — событие, курсор — пара «момент происшествия, идентичность события», и пара уникальна на любом подмножестве строк; правка 1 называет независимость курсора от набора отборов явно |
| журнальная × исполнитель и подключение | **правлено этим узлом**: выдачу держит модуль аудита своей ролью на своей базе, чужого подключения ей не требуется (правка 8) |
| агрегатная × состав входа | **правило выполняется**: тенант, окно по суткам зерна и курсор объявлены домом; зерно добавлено как операнд правкой 5 — оно операнд входа и одновременно единица страницы |
| агрегатная × единица страницы | **правлено этим узлом**: зерно — обязательный операнд вызова с закрытым перечнем из двух значений, страница и курсор идут внутри выбранного зерна (правка 5) |
| агрегатная × исполнитель и подключение | **правлено этим узлом**: выдачу держит модуль статистики; строки — из своей базы, границу полноты с предикатом — из базы журнала **третьим подключением**, двумя запросами (правки 7-11) |

### Ось 2 (предметная): «операнд входа выборки»

**Команда вывода:**

    sed -n '/^## Как журнал читается/,/^## Границы/p' docs/models/domain/other/AuditRecord.md \
      | grep -oUzP '(?sm)^- \*\*.{0,90}?\*\*'
    sed -n '/^## Что это за числа и кто их читает/,/^## Зерно строки/p' docs/rules/statistics-aggregates.md \
      | grep -oUzP '(?sm)^- \*\*.{0,90}?\*\*'
    grep -oP '^\| `\w+_internal_id`' docs/models/domain/other/AuditRecord.md

Первые две выдачи дают по четыре объявленных ограничения на выборку,
третья — четыре колонки радиуса, каждая из которых есть кандидат в отбор.
Член перечня закрыт, когда у операнда названы **обязательность**, **влияние
на курсор** и **чем обеспечен план запроса**.

| Член | Исход |
|---|---|
| журнальная: тенант | **правило выполняется** — обязателен, курсора не касается, план обеспечен `ix_audit_record_tenant_occurred` |
| журнальная: окно по моменту происшествия | **правило выполняется** — обязательно и ограничено сверху, тем же индексом |
| журнальная: порядок и курсор | **правило выполняется** — обратный хронологический, курсор парой «момент, идентичность»; правка 1 добавляет, что набор отборов курсора не двигает |
| журнальная: выдача границы полноты с предикатом | **правлено**: обязательна, план обеспечен `ix_audit_record_recorded`; исполнитель до узла не был назван ни одним носителем — правка 8 называет модуль аудита и его собственную базу |
| журнальная: отбор по биржевому счёту | **правлено**: необязателен, собственного индекса нет, довод — селективность (счетов у тенанта единицы), план ограничен обязательным окном (правки 1, 2) |
| журнальная: отбор по инструменту | **правлено**: то же, довод тот же (правки 1, 2) |
| журнальная: отбор по сделке | **правлено**: необязателен, план обеспечен `ix_audit_record_tenant_deal` — у индекса появляется названный читатель (правки 1, 2) |
| журнальная: отбор по определению стратегии | **правлено**: то же, `ix_audit_record_tenant_strategy` (правки 1, 2) |
| агрегатная: тенант | **правило выполняется** — обязателен, ключ зерна, план обеспечен `ix_*_aggregate_tenant_bucket` обеих таблиц |
| агрегатная: окно по суткам зерна | **правило выполняется** — обязательно, ограничено сверху своим пределом конфигурации |
| агрегатная: порядок и курсор | **правлено**: порядок и курсор идут по ключу **выбранного** зерна, уникальному своим `uk_*_aggregate_grain` (правка 6) |
| агрегатная: выдача границы полноты с предикатом | **правлено**: величины берутся из базы журнала третьим подключением, отдельным запросом (правки 7, 9) |
| агрегатная: зерно | **правлено**: обязательный операнд вызова, закрытый перечень из двух значений (правка 5) |
