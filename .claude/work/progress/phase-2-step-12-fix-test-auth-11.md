## W-1 — популяция выводится, а не называется

**Что сделано.** Единица оставлена ролевой («звено тропы, производящее отказ
само»), а популяция переведена из **названной** в **выводимую**: признак делит
звенья на производящие и передающие, и тропа читается по коду одним ходом от
фильтра контура. Клетку получает каждое звено, включая передающие
(`BearerTokenAuthenticationFilter`, `JwtAuthenticationProvider`), — тогда
пропущенное звено видно как дырка в цепи, а не как молчание.

**Резолвер получил исход — без кейса, с причиной.** Довод выведен по коду:
отказ резолвера (`invalid_token`, «Bearer token is malformed») на уровне
контракта поверхности совпадает с отказом декодера — `401` через ту же точку
входа, заведения нет; различие живёт **только** в параметре `error_description`
заголовка `WWW-Authenticate`, который собирает стоковый
`BearerTokenAuthenticationEntryPoint`. **Единый error-DTO различия не вернёт**:
`AccessDenialHandler` пишет **класс** отказа (`ACCESS_UNAUTHENTICATED`), один
на оба, — то есть причина держится и после закрытия долга, а не до него. Точка
входа у `auth` сегодня стоковая: `SecurityConfig` своей не ставит, а
`AccessDenialHandler` в контекст не попадает — из периметра взят именованно
только `ActorProvider` (`AuthApplication`).

**Вторая ось резолвера названа недостижимой по конфигурации:** «токен приехал
двумя тропами» требует чтения параметра запроса либо тела, а
`allowUriQueryParameter` и `allowFormEncodedBodyParameter` — `false`.

## W-2 — причина переписана, наблюдатель заведён

**Прежняя причина ложна и снята:** «предикат недостижим» неверно — `validate`
при непустом `cnf.x5t#S256` идёт за сертификатом запроса, не находит его и
отвечает `failure`, а токен строит сам тест.

**Новая причина держится на том, что читается по коду:** предикат достижим
**только на токене, которого наш производитель не выпускает**; на токене,
который тропа несёт, снятие валидатора не наблюдаемо ничем. Посылка названа
посылкой **о производителе**, и у её утраты назван наблюдатель — новая секция
бэклога §«Привязка токена к сертификату клиента у выбранного провайдера
идентичности ни одним домом не названа» (владелец `solution-designer`) плюс
строка F-10 §«Находки владельцам».

**Довод срочности назван несимметричным:** включённая у провайдера привязка
отвергает **каждый** запрос браузерной тропы, то есть меняет контракт, а не
кейс.

## W-3 — клейм о команде 2

**Клейм сведён к печатаемому:** буллет о негативе по единице теперь говорит
то же, что §«Команды разбора», — реестр выводится прогоном, исход по единице
даёт чтение, — и написанного клейма полноты над негативом в документе больше
нет: законных форм у производного числа две, выводимая прогоном либо
отсутствующая (`.claude/rules/self-description-form.md` §«Что чем
закрывается»).

**Секция бэклога перевооружена, а не снята.** Сработавшее условие исполнено
этой правкой; предмет (б) — научить команду 2 сопоставлять реестр с метками
кейсов — остаётся законной задачей, и секция переписана на него с новым
условием `греп:"единиц без исхода:"`. Почему задача не взята сейчас:
сопоставление требует своей конструкции (кейс называет единицу своими словами;
нужен словарь соответствий либо метка единицы в клетке), и дешевле она
под-шагом 3, когда у меток появится кодовое воплощение.

## Найдено самой правкой и закрыто ею же

**Регресс-клейм B1.14 был ложен наполовину.** Клетка утверждала, что переход на
`createDefaultWithValidators` «роняет проверку типа молча». По исходнику
`JwtValidators` это неверно: метод **доставляет** недостающие умолчания
(`JwtTypeValidator`, `JwtTimestampValidator`,
`X509CertificateThumbprintValidator`) и подменяет лишь тот класс, чей экземпляр
положил вызывающий; бины `OAuth2TokenValidator<Jwt>` перечень тоже только
пополняют (`getValidators` автоконфигурации). Снять умолчание может ровно один
ход — свой бин `JwtDecoder` (`@ConditionalOnMissingBean`) либо явный
`setJwtValidator`. Клетка B1.14 и буллет приведены к этому; парковки предмет не
требовал — блокер не отсутствие носителя, а неверная фраза
(`.claude/rules/parking-address.md` §«Чего правило НЕ означает»).

## Команда 3 — точки конфигурации тропы разбора

**Заведена, потому что признак популяции обязан иметь наблюдателя своего
расширения.** Команда печатает места дерева сервиса, которыми вводится или
подменяется звено тропы: бин `JwtDecoder`, бин `OAuth2TokenValidator`, бин
`BearerTokenResolver` либо `AuthenticationConverter`, точки DSL, вызов
`setJwtValidator`, свойство аудитории. Сервис приходит аргументом.

**Прогнана на трёх состояниях** (`.claude/rules/measurement-commands.md`
§«Команда засчитывается проверкой после прогона на двух состояниях»); блок
извлечён из документа и исполнен дословно:

| Состояние | Исход | Код |
|---|---|---|
| действительное (`auth`) | `прочитано файлов: 26; точек конфигурации тропы разбора: 0` | 0 |
| базовый гейт: аргумент — несуществующий сервис | `НЕ ИЗМЕРЯЛОСЬ: … не прочитано ни одного файла` | **2** |
| мутация: во временной копии дерева заведён `JwtDecoder jwtDecoder()` | точка напечатана поимённо, `точек …: 1` | 0 |

**Охват назван и есть нижняя граница:** команда читает `java`, `yaml`, `yml` и
`properties` в `src/main` своего сервиса и берёт точку, выраженную именем типа
либо вызовом; строка комментария из обхода исключена. Чего она не видит,
названо в документе: точку, приехавшую из общего артефакта **сканированием**
пакета (у `auth` такого нет — взятое названо `@Import`-ом поимённо), и точку в
тестовом дереве. **Ноль означает «наших точек нет», а не «тропа не менялась»** —
вторым наблюдателем стои́т линия библиотеки.

## Команда свипа

```bash
cd /c/Users/RomanKrd/IdeaProjects/VibeTradingBotV5
export LC_ALL=C.UTF-8
TMP=$(mktemp -d)
cat > "$TMP/sweep.py" <<'SWP'
import io, os, re, sys
ROOTS = ['docs', '.claude', 'services', 'tools', 'web', 'deploy']
SKIP = ('.claude/work/history', '.claude-archive', 'target', '.git', 'node_modules')
FORMS = [
 ('1 популяция названа местом', r'декодер\s+контура\s+плюс\s+перечень\s+валидаторов'),
 ('2 typ без оговорки о регистре', r'(только\s+со\s+значением\s+.JWT.\s+(либо|или)\s+(без|его)|`typ`\s*=\s*`JWT`\s+либо\s+(его\s+)?отсутствие)'),
 ('3 клейм о прогоне команды 2', r'единица\s+получила\s+исход,\s+читается\s+прогоном'),
 ('4 недостижимость предиката x5t', r'привязки\s+токена\s+к\s+сертификату\s+клиента\s+контур\s+не\s+заводит'),
 ('5 регресс через createDefaultWithValidators', r'переход\s+на\s+явно\s+собранный\s+перечень\s+валидаторов'),
 ('6 охват двух команд', r'Охват\s+обеих\s+назван'),
]
hits = {name: [] for name, _ in FORMS}
files = 0
for root in ROOTS:
    for dirpath, dirnames, filenames in os.walk(root):
        norm = dirpath.replace(os.sep, '/')
        if any(s in norm for s in SKIP):
            dirnames[:] = []
            continue
        for fn in filenames:
            if not fn.endswith(('.md', '.java', '.py', '.sh', '.yaml', '.yml', '.json', '.txt')):
                continue
            path = os.path.join(dirpath, fn)
            try:
                text = io.open(path, encoding='utf-8').read()
            except Exception:
                continue
            files += 1
            for name, rx in FORMS:
                for m in re.finditer(rx, text, re.S | re.I):
                    hits[name].append('%s:%d' % (path.replace(os.sep, '/'), text[:m.start()].count(chr(10)) + 1))
if not files:
    print('--- НЕ ИЗМЕРЯЛОСЬ: не прочитано ни одного файла')
    sys.exit(2)
print('прочитано файлов:', files)
bad = 0
for name, _ in FORMS:
    print('%-45s %d' % (name, len(hits[name])), hits[name][:6])
    bad += len(hits[name])
print('--- попаданий снятых редакций в живых носителях:', bad)
sys.exit(1 if bad else 0)
SWP
py "$TMP/sweep.py"
```
