## Почему у `X-3` взят крен (а), а не (б)

Крен (б) снял бы B2.16 как второй прогон B2.5 и оставил бы три кейса
(`contour`, `azp`, `sub`), у которых тропа и тело другие. Он дешевле на четыре
кейса и отвергнут по существу:

- **обязательность каждого поля — отдельное утверждение поверхности, и
  наблюдаемо оно снаружи.** `@NotBlank` стои́т у каждого поля своя; снятая с
  `secret`, она даёт счёт, чьи запросы площадке подписываются ничем, — и ни
  один соседний кейс этого не ловит. Представитель мерит **механизм**, а
  контракт состоит из семи утверждений;
- **довод B5.8 крен (б) не переживает и не обязан:** там единица — точка
  поверхности (документ `springdoc` против статики обозревателя), и охрана у
  них снимается порознь. Пересмотра он не требует — требует переписать довод с
  «какой из двух» на признак, что и сделано;
- **цена названа и ограничена:** семь кейсов по одному HTTP-вызову каждый на
  уже поднятом контексте.

**Признак, поднятый в дом, за собой крена (а) не тянет автоматически.** У
большого реестра (у `strategies` их 56) исход «не покрыта с доводом о единице»
объявлен законным тем же пассажем: правило требует **названности**, а не письма
кейса на каждую единицу.

## Реестр обязательных входов и его покрытие

Популяция выведена **из кода**, а не из текста документа
(`.claude/rules/handoff-worklist.md` §«Входов у вывода два, и второй
обязателен»). Команда печатает единицы по всем сервисам; ниже — исход по
десяти единицам `auth`. Клетка на единицу.

```bash
cd /c/Users/RomanKrd/IdeaProjects/VibeTradingBotV5
export LC_ALL=C.UTF-8
TMP=$(mktemp -d)
cat > "$TMP/req-units.py" <<'REQ'
import io, re, os, glob, sys
ROOT = 'services'
FIELD = re.compile(r'@Not(Blank|Null|Empty)\b[\s\S]{0,400}?private\s+\S+\s+(\w+);')
CLAIM = re.compile(r'private static final String \w+_CLAIM = "(\w+)";')
units = {}
for svc in sorted(os.listdir(ROOT)):
    base = os.path.join(ROOT, svc, 'src', 'main', 'java')
    if not os.path.isdir(base):
        continue
    found = []
    for path in glob.glob(os.path.join(base, '**', '*.java'), recursive=True):
        norm = path.replace(os.sep, '/')
        text = io.open(path, encoding='utf-8').read()
        if '/api/model/' in norm:
            for m in FIELD.finditer(text):
                found.append(('field', os.path.basename(path)[:-5] + '.' + m.group(2)))
        if '/api/controller/' in norm:
            for m in CLAIM.finditer(text):
                found.append(('claim', m.group(1)))
            if 'getSubject()' in text:
                found.append(('claim', 'sub'))
    if found:
        units[svc] = sorted(set(found))
if not units:
    sys.exit(2)
for svc in sorted(units):
    print('%-18s %2d units' % (svc, len(units[svc])))
    for kind, name in units[svc]:
        print('    %-6s %s' % (kind, name))
REQ
py "$TMP/req-units.py"
```

**Охват команды назван.** Она берёт обязательность, выраженную аннотацией
валидации в `api/model` и константой claim'а в контроллере; обязательность,
выраженную проверкой в теле метода, охраной конфигурации или заголовком, она
не печатает — перечень есть **нижняя граница**
(`.claude/rules/measurement-commands.md` §«Полнота письменных форм предмета —
обязательное свойство детектора»). Встречная форма проверена чтением
поверхности `auth`: иных обязательных входов у четырёх её точек нет —
`ExchangeAccountController` и `MembershipController` своих проверок
предъявленности не делают, а `Contour.valueOf` мерит **домен**, а не
предъявленность (кейс на него — B2.6, своей категории).

**Ложное «ПОКРЫТ» прежней команды снято.** Команда `X-3` печатала `sub`
покрытым, поймав фрагмент B1.5, где `sub` стои́т рядом со словами «без claim
`preferred_username`»; эта команда покрытия не мерит вовсе — она печатает
**реестр**, а исход по каждой единице даёт чтение. Шаблон покрытия невозможен
по построению: кейс называет единицу своими словами.

### Свип по конструкции

Формул и предикатов правка не вводит. Вводит **признаки**, и каждый проверен
на область определения:

- **признак субстрата** («прогон поднимает рядом с ящиком, и делят его кейсы
  модуля») — проверен на четырёх родах: база, брокер, хранилище отвечают ему
  по решениям 2 и 5; стаб — по решению 3 (WireMock один на модуль, адрес
  свойством). Ложного члена не найдено: процесс стороны сквозного набора
  (решение 12) под признак **не** попадает — он не субстрат, а сторона;
- **признак второго основания** («ассерт утверждает о субстрате целиком, а не
  о дельте своего входа») — проверен на выдаче команды `X-2` по предусловиям:
  22 попадания, разведены на два класса чтением предмета, и признак разводит
  их так же (`audit` B6.6, B8.15, `statistics` B2.13, `auth` B3.2 — предмет
  целиком; прочие — наследование);
- **признак единицы негатива** («обязательность снимаема независимо, снятие
  наблюдаемо снаружи») — проверен на трёх категориях: «отсутствие
  обязательного» даёт вход, «значение вне домена» — перечень, «отказ доступа»
  — точку. Крайний случай назван: большой реестр `strategies` (56 единиц), где
  законен исход «не покрыта с доводом».

### Свип по структурным носителям

Структурных правок (поле, колонка, операнд, тропа чтения) заход не вносит:
дерева кода он не касается вовсе. Семь заведённых кейсов новых величин не
вводят — они наблюдают существующие аннотации и claim'ы.

### Свип по перечню предикатов (радиус)

Радиус изменён дважды — перечень субстратов (3 → 4) и единица негатива
(операция → вход). Предикаты, читающие первый радиус, выписаны от предмета:

| Предикат / выборка, читающая радиус | Исход |
|---|---|
| пассаж перебора рода в доме | правлен |
| пассаж популяции признака разрушения в доме | правлен |
| иллюстрация того же пассажа | правлена: считает по именам, а не по числу |
| цена «прогон держит контейнеры субстрата и стаб» | правлена: «контейнеры всех его субстратов» |
| решение 3 (стаб) | правлено: получило указатель на признак |
| шаблон `SUB` команды парковки | правлен: слова стаба внесены; выдача выросла с 0 стабовых попаданий до 50 |
| §«Чем достаются выходы» предмета | правлен: три субстрата, исход по каждому |
| §«Чем достаются выходы» прочих двадцати документов | **не правятся**: чужой предмет, припаркованы |

Предикатов, читающих второй радиус, два — довод B2.16 и довод B5.8; оба
правлены.

### Проход по носителям с клеймом полноты

- **Клейм «перечень субстратов»** — снят как закрытый перечень, заменён
  признаком плюс перечнем-примером. Иллюстрация пересчитана.
- **Клейм «какое из двух»** — снят; на его месте признак единицы и указатель
  на команду реестра.
- **Клейм о покрытии в B2.16** — написан не был: в клетке стои́т указатель на
  соседние метки и на команду, а не число (`.claude/rules/self-description-form.md`).
- **Клейм §«Чем достаются выходы»** — «покрыт по единице» несёт указатель на
  команду этого отчёта, а не счёт.

## Что перепроверено не было и почему

- **Посылка о новом порте хоста у перезапущенного контейнера** — прогоном
  по-прежнему не проверялась (jar'ов Testcontainers в локальном репозитории
  нет); помечена непроверенной в самом доме.
- **Достижимость токена без `sub`** проверена чтением кода поверхности
  (`MembershipController`, `MembershipResolutionService`,
  `TenantProvisioningService`, схема `V1__auth_baseline.sql`), а не прогоном:
  контекста ящика сегодня не существует.
- **Двадцать остальных документов кейсов** — своя единица работы каждый; их
  клетки печатались командами только как популяция классов.
