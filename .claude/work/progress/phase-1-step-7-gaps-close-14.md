## Нулевой ход — записанный инвариант

> **При нарушении контракта интеграции радиус реакции определяется не
> радиусом наблюдаемого ущерба, а неизвестностью радиуса поражения; такой
> случай требует ручного разбора человеком.**

Дом — `docs/rules/error-handling-policy.md` §«Нарушение контракта
интеграции — радиус по неизвестности поражения» (соседом «Радиус ущерба
ограничивает и реакцию» — инвариант называет границу применимости того
правила). Различение с тропой несвежести (отказ **канала** добычи с
известным радиусом — там радиус ущерба работает) записано там же. На него
опираются H7, H10 и исход `ANOM-Q5` «субъект состояния на радиусе биржи —
биржа»; общее свойство триггеров `exchange-hold.md` §«Что переводит в
HOLD» переформулировано от него.

### H6 — резолв класса реакции по типу исключения; отображение установлено inspection'ом

**Решение пользователя:** по типу исключения из существующих классов; ни
новой оси, ни поля в исключении; сетевой таймаут до резолва не доходит
(тропа ретрая); блокировка — только на исчерпании попыток, форма —
**запрет торговли при продолжении сопровождения текущей сделки**.

**Inspection по `src/`** (греп классов исключений, чтение javadoc):
`ControlledExchangeException` + три подкласса (`ExternalStatusException`,
`ExternalInvariantViolationException`, `ExternalNotFoundException`) —
доходят до резолва, безусловный L4 биржевой (ратифицированное правило);
`ExchangeIntegrationException` (транспорт/API, retryable) — поглощается
ретраем, доходит только исчерпание бюджета → `SOFT` инструмента;
`CalculationException` — поглощается калькуляторным слоем. **Следствие,
проведённое по носителям:** разводка реакции серии по стороне ноги
(«вход-сайд vs управление-сайд») **снята** — ни один существующий класс
стороны не несёт, у исчерпания форма одна (мягкая); записанное отклонение
(отказ добычи посттерминальных фактов → полная реакция, довод отладки,
условие пересмотра) **сохранено** как отклонение.
