## З-1. Клейм полноты обхода потребителей стоит на line-number окне, которое секции не соответствует — **гейтит**

**Что не так.** Пункт 2 чек-листа глубины (усиленная редакция: «обойдены
**все потребители** правленной величины») доказан командой с окном по
номерам строк. Окно и секция не совпадали ни в одном из трёх состояний,
которые я замерил.

**Цитата-носитель.** `node-H12.md:77-91`:

```bash
awk 'NR>=790 && NR<=1700' .claude/work/backlog.md \
  | grep -n 'Σ\|≥\|≤\| = \|min(\|max('
```

> Даёт 24 попадания. Разобраны все… Клейм полноты: перебор проведён по
> **всей** секции §«CODE-дельта шага» одной командой, не по памяти
> правки.

**Факт.** §«CODE-дельта шага» сегодня — строки **826…1780**. Окно
`790…1700`:

| замер | попаданий |
|---|---|
| окно `790-1700` (команда отчёта) | **24** |
| фактическая секция `826-1780` | **29** |
| в секции, но вне окна (не разобрано) | **6** (`:1747`, `:1748`, `:1749`, `:1751`, `:1761`, `:1762`) |
| в окне, но вне секции (чужая секция) | **1** (`:796`, пункт X9) |

Совпадение числа «24» — артефакт дрейфа: полутора часами ранее та же
команда на том же (неизменном по содержанию) закрытии давала **23**, а
секция была `808…1762`. Число меняется от чужих правок выше по файлу, а
не от предмета измерения.

**Почему дефект.** Во-первых, клейм полноты ложен: шесть формул секции в
перебор не попали (весь счётный разбор припаркованного блока F18,
включая `protectionRelievedRisk = episodeIncurredRisk −
episodeRiskAtCurrentStop`). Клейм полноты — «инструкция дальше не
искать» (`roadmap-step-execution.md` §«Отдельный проход — по носителям с
клеймом полноты»), и здесь он выдан на неполном переборе. Во-вторых —
самоприменимость: **это ровно тот класс, который закрытие только что
объявило дефектом** в шестой строке таблицы F16 («номер строки в
постоянном носителе протухает при первой же правке спеки») и починило
переводом адресации на имена. Собственный носитель проверки оставлен на
протухающем адресе.

**Что должен сделать автор.** Переякорить команду на имя секции, а не на
номера строк, и пересобрать раскладку. Воспроизводимая форма (проверена
— даёт 29):

```bash
s=$(grep -n '^### CODE-дельта шага' .claude/work/backlog.md | cut -d: -f1)
e=$(awk -v s=$s 'NR>s && /^### /{print NR-1; exit}' .claude/work/backlog.md)
awk -v s=$s -v e=$e 'NR>=s && NR<=e{printf "%d|%s\n",NR,$0}' .claude/work/backlog.md \
  | grep 'Σ\|≥\|≤\| = \|min(\|max('
```

Разобрать шесть непроверенных попаданий и переписать таблицу классов: её
сумма 10+3+11=24 к фактике не сводится (см. З-4, З-7, З-8).
