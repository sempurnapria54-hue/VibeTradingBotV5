### Код — сервис заведён и портирован

**`services/market-data`** (модуль в реакторе, ~70 классов):

| Узел | Чем поставлен |
|---|---|
| схема `V1` | каталог инструментов, единицы сбора, реестры идентичностей, результаты расчёта, **гипертаблицы** свечей и двух рядов срезов; Timescale обязателен, отказ намеренный |
| каталог | `InstrumentSyncJob` + `InstrumentCatalogService`: синк листинга по типам инструмента, справочный навес окном за курсором, готовность по группам |
| свечи | `CandleJob` + `CandleLoader`: тот же цикл `BACKFILL → SYNC → CHECK → REPAIR → ACTIVE`, но горизонт берётся у **группы** |
| производные | `IndicatorJob`, `MarketStructureJob` обходят **заказанные идентичности**; девять калькуляторов и резолвер структуры портированы без правок математики |
| фаза | `MarketPhaseService` + `MarketPhaseResolver` на клаузах **потребителя**, поверх интерпретатора из общей библиотеки |
| срезы | `SnapshotCollectionJob` + `SnapshotCollector`: тикер тремя агрегатными чтениями, стакан поинструментно, отказ доступа прекращает проход |
| поверхность заявки | три команды требований: свечи, идентичность индикатора, идентичность структуры — все идемпотентны по содержанию |
| поверхность чтения | каталог, правила, единицы сбора, история окном, значения и структуры по идентичности со **сроком-операндом**, фаза, цены, последние срезы |
| ручной запуск | пять async-фасадов и `JobController` (`202`) |
