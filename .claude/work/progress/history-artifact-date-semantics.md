# Семантика даты в имени артефакта `history/`

## На какой вопрос отвечает этот файл

Чем закреплена семантика даты в именах артефактов `history/` и что из неё
вышло для артефактов межшагового окна 2-10 → 2-11.

## Единица и её заходы

Единица — закрепление семантики целиком: решение с альтернативами, действующая
формулировка в доме, приведение артефактов окна к закреплённому.

| Заход | Состояние |
|---|---|
| закрепление семантики (корпусный) | `записан` — §«Классификация захода по родам» |

Заход один: корпус правится одной партией. Развилку выдал держатель с тремя
названными альтернативами и правом решить самому.

## Отправная метка и дельта захода

Метка отбита до первой правки; дельта считается против индекса, потому что
дельта предыдущей единицы в нём уже лежит и коммитом ещё не закрыта.

```bash
git write-tree
git diff --cached --name-status e3dea0b516369e666402434dcaaf284b0c3215b9
```

Метка — `e3dea0b516369e666402434dcaaf284b0c3215b9`.

## Что закреплено

**Дата в имени артефакта `history/` — дата закрытия единицы: календарный день,
в который единица завела свой первый артефакт в `history/`.** Обе формы —
файл-итог и подпапка — несут одну дату; заведённая второй наследует дату первой
и при смене суток не переименовывается.

Дом действующей формулировки — `.claude/rules/naming.md` §Правила; довод и
снятые альтернативы — `.claude/decisions/history-artifact-date.md`.

## Чем замерена развилка

Три числа, и каждое печатает своя команда, а не память:

```bash
# пары «файл-итог ↔ подпапка» и совпадение их дат
for d in .claude/work/history/*/; do b=$(basename "$d"); \
  [ -f ".claude/work/history/$b.md" ] && echo "ПАРА: $b"; done | wc -l

# день коммитов шага 10 фазы 2 против даты его итога
git log --format='%ad|%s' --date=short -25 | grep '2-10'
```

- **шестнадцать пар из шестнадцати** несут одну дату — инвариант держался и до
  правила, и закрепление его ничего не переименовывает;
- **шаг 10 фазы 2 шёл с 2026-09-06 по 2026-09-11**, а его итог назван
  `2026-09-11-…`: под семантикой начала он и всякая многодневная единица
  переименовались бы;
- **дата начала нигде не записана**: у единицы есть отправная метка дерева, но
  не дата, и вывести день старта можно только чтением коммитов.

## Что из этого вышло для артефактов окна 2-10 → 2-11

**Ничего не переименовано, и это исход замера, а не умолчание.** Датированный
артефакт у окна один — `.claude/work/history/2026-09-11-interstep-enforcers.md`;
заведён он 2026-09-11, и по закреплённой семантике дата верна. Подпапки
артефактов окно не заводило, поэтому пара не разъезжается по построению.
Ротация снимка (`history/snapshots/snapshot-v241.md`) правилу не подчиняется:
её имя — `snapshot-vN.md`, а не `YYYY-MM-DD-…`.

## Свип снятой редакции

Снятое — формулировка «дата завершения задачи» как ответ на вопрос, какой день
ставится в имя.

```bash
LC_ALL=C.UTF-8 grep -rlUzP 'Дат[аы]\s+завершения' \
  --include=*.md --include=*.py --include=*.txt --include=*.json .claude/ docs/ tools/
```

Выдача печатает файлы; член разбора — файл, и исход о нём утверждает о файле
целиком.

| Файл выдачи | Исход |
|---|---|
| `.claude/rules/naming.md` | **правлен этим заходом**: формулировка заменена семантикой закрытия с указателем на решение |
| `.claude/work/history/2026-06-20-source-api-contour.md` | **остаётся как есть**: архив описывает прошлое и ретро-правке не подлежит (`.claude/rules/curation.md` §«Чек-лист свипа») |
| **Итого** | 2 |

## Свип конструкции: носители формата имени

Предмет — носители, называющие формат `YYYY-MM-DD-…`: не переписывает ли
кто-то семантику второй раз.

```bash
LC_ALL=C.UTF-8 grep -rlUzP 'YYYY-MM-DD-' --include=*.md --include=*.py .claude/ docs/ tools/
```

Живая область — без `work/history/`.

| Носитель выдачи | Исход |
|---|---|
| `.claude/rules/naming.md` | **правлен этим заходом** — он и есть дом |
| `.claude/rules/closed-work-transfer.md` | **остаётся истинным**: несёт формат и прямо отсылает «по правилам именования» — семантики не переписывает |

| `.claude/work/roadmap/phase-1.md` | **остаётся истинным**: шаблон имени артефактов шагов фазы, семантики дня не несёт |

## Окрестность точек вставки

Пробы исполнены по дельте захода от метки; выдачу дал
`py tools/insertion-neighborhood-check.py`, прогнанный по этой метке.

| Носитель | Точек | Анафор в радиусе | Исход |
|---|---|---|---|
| `.claude/rules/naming.md` | 9 | 0 | пусто — цитировать нечего |
| `.claude/work/backlog.md` | 23 | 0 | пусто — цитировать нечего |
| `.claude/work/decision-digest.md` | 14 | 1 | «без левой «**ниже**» находится внутри «понижения»» (4886) — слово в тексте решения Д1455 о самом детекторе анафор, а не указатель расположения; вставка добавила новый раздел ПОСЛЕ таблицы и порядка её строк не меняла — **остаётся истинной** |
| **Итого** | 46 | 1 | — |

**О1 исполнена чтением.** Точка вставки в `naming.md` — строка перечня форм
имени; соседи сверху и снизу («Заметки», «Снапшоты») — пункты того же перечня,
и разбираются они по своим пунктам, а не цитатой. Вставка ни одного из них не
задевает: у заметки предмет назван тем же ходом (наблюдение на дату), у
снапшота даты в имени нет вовсе.

**О3 — греп термина предмета.** Термин — «дата завершения» и «YYYY-MM-DD»;
обе выдачи разобраны свипами выше, и других утверждений о дне в имени в корпусе
нет.

**О4 — по тексту правки.** Оборотов, осмысленных только в черновике («правка
3б», «узел 2», «выше по этому файлу»), внесённый текст не несёт.

## Названный остаток

**Инвариант «одна дата у файла-итога и подпапки» прогоном не мерится.** Он
выразим обходом `history/`, но энфорсера сегодня нет; дом задачи, её оживитель
и причина парковки — `.claude/work/backlog.md` §«Инвариант даты у пары
файл-итог и подпапка прогоном не мерится».
