# Правка кейсов `auth` по находкам ревью

## На какой вопрос отвечает этот файл

Какой исход получила каждая находка ревью кейсов `auth`.

## Охват

**Предмет — девять находок отчёта**
`.claude/work/progress/phase-2-step-12-review-test-auth.md` §«Находки»
плюс два пункта §«Мелкое, не гейтящее апрув». Заход — правка **автором**
(`tester`) в петле ревью (`.claude/skills/test-review.md` §«Петля с
tester»): ревьюер не чинит, автор не переоценивает вердикт.

**Что правилось:** `.claude/tests/cases/auth.md` (кейсы, перечни, §Предмет,
таблица находок владельцам) и `.claude/work/backlog.md` (парковки, которые
находки адресуют чужим владельцам).

**Вне охвата и почему:** дома, которых находки требуют от владельцев
предмета (запрет на текст платформенного исключения, исход пустого адреса
хранилища, судьба роли вне тенантов, javadoc `JpaAuditConfig`), — чужая
дельта; каждая ушла парковкой с домом, оживителем и причиной
(`.claude/rules/parking-address.md`). Перепроверка исправленного — единица
`reviewer`, не эта.

## Свипы захода

Род правки — `снятие` (снята половина ожидания у трёх кейсов) и `клейм`
(перечень предъявителей долга и перечень истин предмета пересобраны);
`величины`, `дома`, `радиуса` и `кардинальности` заход не вводил
(`.claude/rules/edit-kind-obligations.md`).

**Свип снятых формулировок** — многострочный, иначе половина вхождений
невидима (`grep -P` без `-z` через перенос строки не берёт; проверено на
заведомо существующем вхождении, которое однострочный прогон не нашёл):

```bash
export LC_ALL=C.UTF-8
for p in 'отказ\s+оставляет\s+запись\s+в\s+журнале' \
         'ни\s+одного\s+сообщения\s+ни\s+в\s+одной\s+теме' \
         'стабы\s+соседей' 'отдельным\s+прогоном'; do
  grep -rlUzP "(?s)$p" --include='*.md' --include='*.java' --include='*.yaml' \
    .claude docs services tools
done
```

Исход по каждому файлу выдачи:

|---|---|---|

| `.claude/work/progress/phase-2-step-12-review-test-auth.md` | все четыре | **датированный отчёт**, описывает прошлое — не правится (`.claude/rules/self-description-form.md` §«Датированный замер клеймом не является») |
| `.claude/tests/cases/auth.md` | «ни одного сообщения ни в одной теме», «стабы соседей» | **правлено**: формулировки живут внутри объявления «снято как ненаблюдаемое», действующим ожиданием не являются |

Парковка чужой находки — `.claude/work/backlog.md` §«Половина «сегодня» у
кейсов следа отказа доступа не выведена ни одним домом»; условие закрытия
мерит **оба** оставшихся документа одним грепом.

**Свип по конструкции.** Формул и предикатов заход не вводил; ожидания,
дописанные по дому (`500` без текста исключения), сверены с домом
поимённо — `docs/rules/error-handling-policy.md` §«Отказ, произведённый
контейнером, — тот же контракт» (клауза «всё непредусмотренное»), и
иерархия исключений перепроверена по коду: ни `VaultException`, ни
`IllegalStateException` под два объявленных обработчика `auth` не попадают.

**Свип по структурным носителям** не требовался: полей, колонок и троп
чтения заход не вводил.

**Указатели.** Новые `§`-адреса в `docs/**` проверены поимённо:
§«Что он делает и зачем» (`docs/architecture/services/auth.md`),
§«Ответ по контуру `trading-core`» и §«Съём метрик — второе исключение»
(`docs/rules/api-access-policy.md`), §«Отказ доступа — тот же контракт, что
и прочие ошибки» и §«Отказ, произведённый контейнером, — тот же контракт»
(`docs/rules/error-handling-policy.md`), §«Енум `Status`»
(`docs/models/domain/core/Tenant.md`, `ExchangeAccount.md` — хвост в скобках
опускается законно). Адреса в `.claude/**` мерит `py tools/anchor-check.py`.

## Названные остатки

- **Перепроверки не было.** Апрув по предмету `auth` не дан и этим заходом
  не даётся; следующий ход по предмету — перепроверка `reviewer`.
- **Четыре находки уехали чужим владельцам** (F-5…F-8) и живут парковками;
  ни одна не гейтит под-шаг 3 сама по себе — гейтит апрув.
- **Класс R-2 воспроизведён у двух чужих предметов** и припаркован; их
  собственное ревью пройдёт независимо.
