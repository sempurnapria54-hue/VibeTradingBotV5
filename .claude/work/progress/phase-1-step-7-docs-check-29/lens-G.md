## P4. `\b` в `grep -P` вокруг кириллицы молча даёт ноль — третья средовая ловушка ложно-зелёного, не записанная нигде

**Вопрос.** Полон ли перечень средовых ловушек, дающих ложно-зелёный
результат?

**Цитаты (носители).**

- `.claude/processes/roadmap-step-execution.md:120-123` — «**`grep -P` в
  этой среде требует `LC_ALL=C.UTF-8`.** Без него проход падает с
  ошибкой в stderr и **пустым** списком файлов, что читается как чистый
  свип. Класс тот же, что у `python` против `py`».
- Вторая ловушка: `tools/spec-scope-check.py:20-25` и
  `tools/spec-scope-probe.sh:15-16` — `python`/`python3` в PATH
  заглушки Windows Store, код 49 без вывода.
- Третья, не записанная нигде: **`\b` вокруг кириллицы не совпадает
  никогда**, даже с `LC_ALL=C.UTF-8` и даже с префиксом `(*UTF8)`.
  Воспроизведение (GNU grep 3.0, PCRE):

```
printf 'строка со словом выше внутри\n' > t.txt
LC_ALL=C.UTF-8 grep -coP '\bвыше\b' t.txt   # 0, exit=1
LC_ALL=C.UTF-8 grep -coP 'выше'     t.txt   # 1, exit=0
printf 'a word here\n' > t2.txt
LC_ALL=C.UTF-8 grep -coP '\bword\b' t2.txt  # 1, exit=0  (контроль: латиница работает)
```

**Почему не гейтит.** Кода не касается. Но действующее предписание
корпуса — «**свип-грепом по терминам снимаемой формулировки** по всем
живым носителям»
(`.claude/processes/roadmap-step-execution.md:280-296`) — применяется к
русскоязычному корпусу, и всякий такой свип, написанный с `\b` вокруг
русского термина, отчитается нулём при любом состоянии. Класс
идентичен двум записанным, а отличие в том, что этот срабатывает
**после** того, как записанная ловушка обойдена: `LC_ALL` выставлен,
команда исполняется, вывод пуст.

**Целевой док.** `.claude/processes/roadmap-step-execution.md`, третьим
пунктом того же перечня рядом с клаузой о `LC_ALL`, с обходом:
`(?<![а-яёА-ЯЁa-zA-Z])…(?![а-яёА-ЯЁa-zA-Z])` вместо `\b`.

**Ожидаемый владелец.** `knowledge-curator`.

**Трассировка.** Открывал: строил счётную команду для позиционных
адресов (G1) с `\b` вокруг «выше»/«ниже» → получил **0** при том, что
`grep -rn "выше" docs/` давал 91 строку → заподозрил не корпус, а
команду → изолировал на однострочном входе, проверил контроль на
латинице и префикс `(*UTF8)`.

**Варианты.** Развилки нет: ловушка воспроизводится однострочной
командой, запись её в перечень — единственный ход. Крена нет.
