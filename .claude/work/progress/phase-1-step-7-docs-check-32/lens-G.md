# Блокирует выход в CODE

Обе находки этого раздела гейтят **машинерию гейта и закрытия**, а не
поведение кода. Это названо явно, чтобы координатор мог переранжировать:
по букве мандата («гейтит = мешает писать корректный код») они прочие; по
букве шаблона отчёта («Блокирует выход в `CODE`») — гейтящие, потому что
статус шага без них не проставляется.

## G1. Предписанного «счётчика покрытия» не существует: гейт выхода из `GAPS_CLOSE_N` неисполним по построению

**Вопрос.** Четыре живых носителя пайплайна предписывают закрытию завести

раннера (`keys` / `where` / `members` / `unreachable`), который величиной не
