## Торговый фокус (trading-review) — акцент stateless-фаза (PHASE-Q1)

Адверсариальный проход по торговой корректности **stateless-фазы** (резолв
на лету, без гистерезиса режима на уровне фазы; анти-whipsaw только
операнд-уровневый). Грунт — дистиллят корпуса
(`.claude/library/trading/distilled/strategy-patterns.md`,
`system-design.md`).

### Грунт (что говорит корпус)

- **Классификация режима флип-флопит при слишком отзывчивом
  дискриминаторе.** Одиночный быстрый фильтр «слишком дёргается» (одна
  12-мес MA → 14 смен мнения за полгода); корпусное лекарство — **медленный
  MA-кроссовер** как фильтр, т. е. анти-whipsaw в **конструкции индикатора**,
  не отдельным слоем. *Источник говорит* [Carver AFTS, стратегия 5, PDF
  с. 147-150].
- **Режим = знак фильтра, разворот непрерывный; отдельного гистерезиса
  ярлыка нет.** *Источник говорит* [Carver AFTS, стратегия 6, PDF с. 162-164].
- **Анти-whipsaw встроен в сглаживание (адаптивная скорость).** KAMA выводит
  скорость EMA из efficiency ratio (шумно → медленнее); «боковик опознать
  трудно» → консервативный дефолт обоснован. *Источник говорит* [Kaufman,
  гл. 17, PDF с. 1529-1532].
- **Гистерезис в корпусе — на уровне ПОЗИЦИИ против издержек (буферинг),
  не на ярлыке режима.** *Источник говорит* [Carver AFTS, стратегия 8, PDF
  с. 187-189].
- **Персистентность — почему тренды работают** (fat tails, серии одного
  направления); «в боковике не работают». *Источник говорит* [Kaufman,
  гл. 8, PDF с. 587-590].

### Находки

**ТВ-1 (подтверждение PHASE-Q1; не блокирует).** *Источник говорит:*
классификация режима реально whipsaw-ит при слишком быстром дискриминаторе
[AFTS стр. 5]. *Модель:* анти-whipsaw — операнд-уровневый (сглаживающие
периоды индикаторов, структурный `breakoutConfirmationBars`); фаза-уровневого
дебаунса нет, и доки это явно фиксируют как S0 с инкремент-эскейпом (поле
`confirmationBars` на сравнивающее правило — `market-phase-conditional-classification.md`
§Анти-whipsaw). *Вердикт:* операнд-уровневый анти-whipsaw — **корпусно-
грунтованный первичный механизм** (медленный кроссовер [AFTS 5],
KAMA-адаптив [Kaufman 17]); модель его **выражает**. Жёсткий гейт «модель
не выражает торговое правило» **не срабатывает**. Открытый хвост (PHASE-Q1)
— нужен ли **опциональный** фаза-уровневый минимум (hold-N-bars на смену
фазы / гистерезис-полоса на ER-пороге) как гард против авторских быстрых
настроек. *Предполагаю:* при вводе корпусная опора — KAMA-адаптивная
скорость / `confirmationBars`-инкремент, **не** stateful debounce ярлыка
режима.

**ТВ-2 (проверка — пройдено).** Whipsaw фазы не «треплет» **открытую**
позицию: фаза гейтит только **выбор детали на входе** (`EntryScannerJob`),
открытые сделки ведутся по **pinned detail** (`docs/lifecycles/Strategy.md`:
«открытые сделки продолжают сопровождаться по pinned detail»). Издержечный
риск частого перескока режима (корпус лечит его буферингом позиции
[AFTS 8]) здесь **смягчён конструктивно** — перескок влияет на новые входы,
не на сопровождение. *Предполагаю:* это снижает остроту PHASE-Q1; связку
«phase flip ≠ churn открытой позиции» стоит явно учесть при разборе PHASE-Q1.

**ТВ-3 (дверь на будущее — задокументировано).** Stateless не выражает
правило **персистентности режима** («тренд держится N баров»); корпус ценит
персистентность [Kaufman 8]. Уже закрыто как Н11: темпоральные переходы — через
`RANGE_BREAKOUT_CONFIRMED`/`MARKET_STRUCTURE_IS`, дверь на будущее — чтение
**готовой истории структуры** (не фазы). Персистентность выразима операнд-
уровнево (медленные окна). Non-gating, корпусно-согласовано.

**ТВ-4 (торговый плюс ревизии D).** Owner-ключевание устранило STRUCT-Q2 —
латентную **торговую** некорректность: при шаринге результата структура,
посчитанная по «чужому» ER/ATR-входу, отдавалась второму потребителю. Теперь
каждая настройка считает под себя — результат соответствует своим входам
(инвариант «вход настройки → её результат» восстановлен).

### Жёсткий гейт
Кейс «модель не выражает нужное торговое правило» **не срабатывает**:
режимная классификация + анти-whipsaw выразимы (операнд-уровневое
сглаживание — корпусный первичный механизм; фаза-уровневое подтверждение —
документированный инкремент). Stateless-фаза торгово **приемлема**;
гистерезис режима — опциональное уточнение, не пробел выразительности.

### Сводка торгового фокуса
Блокирующих торговых находок — **0**. ТВ-1/ТВ-2/ТВ-3 — non-gating
(подтверждают/уточняют PHASE-Q1, владелец `trading-review` / будущее);
ТВ-4 — торговый плюс D. **PHASE-Q1 остаётся открытым не-гейтящим вопросом
(S0** — анти-whipsaw операнд-уровневый, риск-аппетит принят пользователем**)**,
теперь с корпусным грунтом для будущей проработки и конкретными опорами
ввода (KAMA-адаптив / `confirmationBars`, не stateful debounce). Жёсткий
торговый гейт `CODE` по stateless-фазе **пройден**.
