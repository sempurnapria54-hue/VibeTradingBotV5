Какие пробелы доков мешают специфицировать шаг 10 фазы 2.

## Вход

  событий, журнал по тенанту, агрегаты, read-only API».

  синхронизации — **ведёт док** (до `CODE`).
- **Охват по оси владельца**
  (`.claude/rules/knowledge-ownership-by-service.md`): строк владельца
  `audit-statistics` в карте **ноль**. Это не наблюдение по ходу, а факт
  входа: у сервиса, который шаг строит, нет ни одного собственного
  носителя (V1, V2 линзы C).
- **Против чего шла проверка:** `docs/architecture/` целиком
  (`services.md`, `data-ownership.md`, `contracts.md`, `platform.md`,
  `reserved-extension-points.md`, `tenant-and-exchange.md`),
  `docs/rules/audit-not-runtime-source.md`, `api-access-policy.md`,
  `error-handling-policy.md`, `loss-streak-halt.md`,
  `pnl-reconciliation.md`, `market-data-retention.md`,

  `DealCashFlow.md`, `docs/concept.md`; формы событий
  `libs/domain-model/**/domain/event/` — как носители верификации клеймов
  доков о коде.
- **Вне охвата** (помечено, не проверялось): фаза 4 — сигнал, аллокатор,
  бэктест (и с ними треть формулировки «агрегаты по … сигналам»); фаза 5
  — второй субъект и приглашения; шаг 11 — тесты; шаг 12 — фронт.
- **Особенность шага, названная сразу:** **источника порта нет.** В

**Почему части, а не один файл.** Ориентир объёма — до 40 KB
(`.claude/templates/docs/gap-report.md` §«Потолок объёма»), а мандатные
поля 28 гейтящих находок дают ~230 KB и потолку **не уступают** по тому
же правилу. Копирование их сюда завело бы **второй носитель** каждой
находки (`.claude/rules/carrier-levels.md`), а закрытие идёт по списку
цитат самой находки — то есть по части. Превышение названо, его состав
назван, пересказа в нём нет: полных выводов грепов ни в одной части нет,
вторых форм таблиц нет.

## Стадия остановки

**Стадия 0 — не чиста** (линза A, находка A1: какие производители входят
в шаг и строит ли шаг производителя `auth`).

Находки стадий 1-2 всё же собраны и приведены: они **не зависят** от
исхода A1 — модель журнальной записи, состав агрегатов, актор, inbox,

темы, восемь классов) требует каждой из них. Зависимые от A1 находки
помечены ярлыком «зависимая» в своих частях.

Третья колонка — **число позиций реестра гейтов**, и оно ноль: находки
прогонов шага позициями реестра не становятся, они закрываются своим
`GAPS_CLOSE_N` (`.claude/rules/structure.md`, строка
`code-gate-ledger.json`: «новый шаг реестр не пересобирает — он добавляет
свои **компоненты**, а находки его прогонов гейтом не становятся»). Та же
норма применена шагами 8 и 9.

Части линз A и B в своих сводках проставили в этой колонке число находок;
величина здесь **перебита** нормой сквозного реестра, и расхождение
названо, а не умолчано.

| Что | Число |
|---|---|
| находок всего | 41 (A 20 + B 16 + C 5) |
| гейтящих | 28 (A1-A12, B1-B14, C1-C2) |
| прочее | 13 (A13-A20, B15-B16, C3-C5) |
| с ярлыком `варианты-с-креном` | 32 (A — 15, B — 15, C — 2) |
| с ярлыком `выводимо` | 9 (A — 5, B — 1, C — 3) |
| дефицит `грунт` / `работа` / `подтверждение` | 0 / 27 / 0 |

**Счёт сверен пересчётом по телу частей**, а не сложением объявленных
итогов: гейтящие — A1…A12 (12) + B1…B14 (14) + C1, C2 (2) = 28; прочие —
A13…A20 (8) + B15, B16 (2) + C3…C5 (3) = 13; 28 + 13 = 41. Ярлыки исхода:
15 + 15 + 2 = 32 и 5 + 1 + 3 = 9; 32 + 9 = 41. Ярлык дефицита `работа`:
A — 14, B — 13, C — 0 = 27; «дефицита нет» — 6 + 3 + 5 = 14; 27 + 14 = 41.

## Вынос держателю

**Пунктов нет.** Проверено по каждой гейтящей находке: ни одна не
задевает численной величины риск-аппетита, продуктового scope или срока.

**Запись самопроверки** (`.claude/processes/question-delegation.md`
§«Вынос проходит самопроверку, и она записывается») — по двум
кандидатам, и оба остаются у владельца:

- **состав перечня метрик** (A3, B1) — продуктовым scope является только
  **расширение** перечня сверх названного формулировкой шага («агрегаты
  по сделкам, сигналам, стратегиям»); перечень, равный шагу, выводится из
  формулировки и из уже записанных величин ядра. Выводимая половина
  закрывается владельцем; невыводимой не остаётся, пока перечень не
  расширяют;
- **валюта отчёта** (B10) — развилка закрывается **меньшим** вариантом,
  выводимым из `docs/concept.md` §П1: агрегат ключуется валютой и
  ложного единого числа не показывает. Вынос понадобился бы только при
  выборе пересчёта в единую валюту — тогда выносится ровно этот вариант,
  а не находка целиком.

**Числа, которые назначает владелец, а не держатель** (`question-delegation.md`
§«Число: риск-аппетит против калибровки наблюдения»): глубина хранения
журнала (A12), срок темы и порог алерта на лаг группы (A19), число реплик
(A18) — все входят операндом в **наблюдение**, не в сайзинг, потолок или
остановку торговли.
