# Снапшот без хвоста

## На какой вопрос отвечает этот файл

Что сделано задачей «снапшот без хвоста» и какими замерами это подтверждено.

## Итог

Снапшот v412 собран по правилу «дельта и указатели» и не отсылает к прежним
снапшотам; v411 перенесён в `history/snapshots/`. Инвариант записан в
`.claude/rules/snapshot-format.md` §«Снапшот отвечает сам», довод — в
`.claude/decisions/snapshot-without-tail.md`, энфорсер
`tools/snapshot-tail-check.py` стоит в гейте инструментов корпуса. Правило
формата само несло снятую редакцию — раздел среды «отсылкой к прежнему
снапшоту»; она заменена указателем на дом фактов среды и заведена записью
`tools/retired-check.py`.

Задача называла v346, но действующим был v411 той же формы. Замыкание
построено от v411: v346 лежит внутри него (дайджест, Д2028).

- **Висящие пункты v230-v235 с неподтверждённой судьбой** отнесены к дельте

## Замер старта сессии цепочки

Сессия читает снапшот, роадмап (`phase-2.md`, `roadmap.md`) и всё, на что
снапшот отсылает как на действующее; хроника шага и документы кейсов, на
которые снапшот указывает как на подробности, не входят ни в одну сторону.
Правила приходят сами — ядро безусловно, прочие по маскам. Токены — по
`/context` сессии после чтения.

| Замер | До, на v411 | После, на v412 |
|---|---|---|
| старт: снапшот, роадмап, действующие дома, правила | 134,1K | 221,6K |
| хвост прежних снапшотов | около 1,26M | нет |
| всего нужно прочесть | около 1,39M — больше окна в 1M | 221,6K |
| безусловно загруженные файлы памяти | 32,5K | 37,3K |

Хвост мерился восемью сессиями по 31-33 снапшота; из их сообщений вычтены
правила, пришедшие по маскам при чтении истории, — 35,0K на сессию, по
перечню `/context`. Старт «после» больше измеримой части «до»: дома теперь
несут то, что прежде лежало в хвосте и не читалось. Ядро выросло на ловушки
продуктового кода в `codestyle`, правиле ядра.

Этот замер — и недостающая цифра ярусных правил: на старте сессии цепочки
корпусные правила приходят по маскам первым же чтением снапшота.

```bash
MSYS_NO_PATHCONV=1 claude -p "Прочитай инструментом Read каждый из этих файлов целиком: <перечень> . Ответь ok." --session-id <id> --permission-mode bypassPermissions < /dev/null
MSYS_NO_PATHCONV=1 claude -p "/context" --resume <id> < /dev/null
```

Перечень «до»: `snapshot-v411.md`, `phase-2.md`, `roadmap.md`,
`session-wait-and-continuation.md`, `test-step-pace-measures.md`,
`roadmap-step-execution.md`, `settings.json`, `update-roadmap-progress.md`,
`environment-commands.md`. Перечень «после»: `snapshot-v412.md`,
`phase-2.md`, `roadmap.md`, `roadmap-step-execution.md`, `test-code.md`,
`test-step-pace-measures.md`, `environment-commands.md`, `local-stand.md`,
`test-design.md`, `test-review.md`, `update-roadmap-progress.md`,
`session-chain.md`.
