# Закрытые позиции хвоста кода шага 7

## На какой вопрос отвечает этот файл

Какие позиции хвоста кода шага 7 закрылись и чем.

## Повод

Перенос закрытого из рабочего файла хвоста по
`.claude/rules/closed-work-transfer.md`: позиция, у которой не осталось
форварда, в рабочем файле не держится. Детали ходов живут в отчётах
заходов, здесь — итог и указатели.

**Рабочего файла больше нет.** При закрытии шага 7 (2026-09-03) хвост
снят целиком: позиции без остатка — в таблице ниже, позиции с форвардом
— в §«Позиции с форвардом — куда припаркованы (закрытие шага,
2026-09-03)». Этот файл и есть единственный носитель их итога.

## Позиции с форвардом — куда припаркованы (закрытие шага, 2026-09-03)

Рабочий файл хвоста снят: шаг закрывается, а позиции с форвардом стоя́т
на носителях, которых в коде нет **по построению**, и ждать их внутри
шага 7 нечему. Каждая получила дом со стороны **события, которое её
оживит**, а не со стороны исполнителя, который о ней помнит.

| Позиция | Чего недостаёт | Куда припаркована | Что оживит |
|---|---|---|---|
| **Т2-а** | эмитента точечной отмены встроенной защиты | `backlog.md` §«Названные ограничения кодирования шага 7 — возврат по появлению носителя»; ограничение названо в `docs/components/TrancheProtectionSwitchedHandler.md` §«Точечная отмена встроенной защиты — названное ограничение» | ход, вводящий refinement переключения защиты |
| **Т2-б** | объявленной величины «покрытие после создания» | там же | заведение величины в доме-спеке `docs/spec/protection-coverage.json` |
| **Т2-в** | цепочек замещения в рантайме | там же + `backlog.md` §«Хвост шага 4 (CODE-отложения, 2026-06-11)», буллет `ServiceCommandFactory` | фабрика `REPLACE`-ног |
| **Т7** | прочих детекторов аномалии | `backlog.md` §«Шаг 8 (safety / AnomalyJob)»; дом перечня — `docs/components/AnomalyJob.md` §«Что ищет» | шаг 8 |
| **Т10** | операнда «класс акта» в блок-сете | `backlog.md` §«Названные ограничения кодирования шага 7 — возврат по появлению носителя» | расширение области преконтроля |
| **Т11** | мягкой биржевой ступени | `backlog.md` §«Лестница биржевых safety-состояний — CODE-дельта (2026-08-26)», буллет `Exchange.HOLD` | шаг 8, не позже снятия разведочного режима допуска сверки |

**Почему парковка, а не перенос ожидания внутрь шага.** Позиция ждёт не
работы, а **носителя**: без эмитента гейт был бы мёртвым кодом, без
объявленной величины дом завёлся бы мимо стандарта, без фабрики резолв
нельзя ни проверить, ни опровергнуть. Держать шаг открытым ради этого
значило бы держать его открытым до чужих шагов.
