# Закрытые позиции хвоста кода шага 7

## На какой вопрос отвечает этот файл

Какие позиции хвоста кода шага 7 закрылись и чем.

## Повод

Перенос закрытого из рабочего файла
`.claude/work/progress/phase-1-step-7-code-tail.md` по
`.claude/rules/closed-work-transfer.md`: позиция, у которой не осталось
форварда, в рабочем файле не держится. Детали ходов живут в отчётах
заходов, здесь — итог и указатели.

## Что осталось в рабочем файле

Позиции с живым форвардом: **Т2** (три ограничения преконтроля), **Т7**
(прочие детекторы аномалии — шаг 8), **Т10** (блок-сет не различает класс
акта — вместе с расширением области преконтроля), **Т11** (мягкая
биржевая ступень).

Нумерация оставшихся не сдвигается: пропуски — след переноса, а не
потеря позиций.
