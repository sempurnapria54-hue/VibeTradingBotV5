# Точечная запись ядра двигает колонки аудита строки

## На какой вопрос отвечает этот файл

Что сделано по секции «Точечные запросы обновления не двигают колонки аудита строки».

## Итог

Кодовый заход 209 шага 12 фазы 2 (Д2267-Д2269). Точечные запросы ядра по
строкам с полями аудита — сделка, торговое состояние счёта, состояние счёта на
инструменте, отчёт о происшествии; на 2026-09-28 — 22 запроса обновления и одна
вставка в четырёх репозиториях —
ставят `modifiedAt`/`modifiedBy` сами, значениями тех же поставщиков, что у
слушателя аудита (`PointWriteAudit`). Находка `F9` документа
`.claude/tests/cases/e2e-exit-and-close.md` закрыта, клетка `E4.5` снята с
метки `debt`.

- Дом — `docs/models/domain/other/Auditable.md` §«Системные поля и точечная
  запись»; указатель из `.claude/rules/codestyle.md` §«Auditable по слоям».
- Запросы, идущие каждым проходом, гардированы неравенством записываемого
  стоящему (Д2268); нативная вставка состояния пары переведена с часов базы на
  те же часы.
- Вне ядра таких записей нет: `@Modifying` у `audit`, `statistics`,
