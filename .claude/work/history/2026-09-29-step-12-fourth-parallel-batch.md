# Четвёртая пачка параллельных секций узла 1e шага 12 фазы 2

## На какой вопрос отвечает этот файл

Что сделала четвёртая пачка параллельных секций узла 1e (заход 235) шага 12 фазы 2.

## Итог

Пачка кодовая, три модуля с продовой дельтой (`services/trading-core`,
`services/strategies`, `services/statistics`); три субагента. Пять секций
`.claude/work/backlog.md` сняты (из них одна с двумя подсекциями), одна сужена,
три хвоста дописаны. Закрывающий прогон — модули, модуль сквозного набора и два
его класса после правки (хроника шага, §«Сто шестьдесят седьмой заход (235) —
четвёртая пачка параллельных секций»). Решения — Д2379-Д2389
`.claude/work/decision-digest.md`.

- **Ступень `ENTRY_BLOCKED` по несвежести ставки комиссии — писателя нет** —
  детектор в синке ставок, мягкий сигнал через общий исполнитель блокировки,
  порог свежести и окно контура — конфигурацией
  (`docs/rules/instrument-hold.md` §«Несвежесть ставки комиссии»,
  `docs/components/TradeFeeRateSyncJob.md`); класс `TradeFeeRateRegistryTest`.
- **Слепок внешнего состояния у строки прохода детекции стои́т двух чтений
  биржи** и **Отчёт с блокировкой не несёт в данных, какая сущность его
  вызвала** — находка несёт строки среза по адресу, снимок «до» берёт их
  (`docs/models/domain/other/AnomalyReport.md` §Структура); клетки `U9.25`-`U9.27`,
  сквозная `E4.1` переведена на срез.
- **Дефекты донора, воспроизведённые портом** — окно структуры проверяет
  валидатор двумя кодами, указатель javadoc ведёт в существующий дом
  (`docs/rules/strategy-validation.md`); клетки `U25.9`-`U25.13`.
- **Слова провода, по которым ветвится потребитель, у четырёх компонентов
  терминала не запинены** с подсекциями о второй и третьей оси — сверка у
  потребителя журнала `WireWordContractTest` (`services/statistics`): литералы
  и параметры запросов агрегатов против значений перечней ядра, имена
  компонентов несомых форм против констант читателя; правило —
  `.claude/rules/codestyle.md` §«Пин значения, пересекающего провод: слово или
  символ».
- **Сужена:** §«Снимки отчёта счёт-широкой реакции несут только поля счёта» —
  остался снимок «после».
- **Попутно, вне секций:** стаб площадки сквозного набора отдавал ставку с
  застывшим моментом — новая ступень заблокировала бы входы всех троп
  (`Trail#exchangeServesAccount`); `E7.4` периметра требовала отсутствия
  таблицы строк отказа у `auth`, заведённой заходом 221, — ассерт переведён на
  «строк не изменилось».
