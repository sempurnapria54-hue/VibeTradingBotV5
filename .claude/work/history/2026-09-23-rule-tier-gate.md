# Правило без яруса — красный гейт

## На какой вопрос отвечает этот файл

Что сделано задачей «правило без яруса — красный гейт» и какими замерами это
подтверждено.

## Итог

Ядро `.claude/rules/` объявляется явно — строкой `tier: core` во frontmatter.
Пять правил ядра получили её; семнадцать правил со scope не менялись. Файл без
объявления яруса роняет новую команду гейта `py tools/rule-tier-check.py`.
Решение и форма — `.claude/decisions/rules-tiering.md` §«Ядро объявляется
признаком»; развилки формы — `.claude/work/decision-digest.md`, раздел «Явный
признак ядра».

Изменённые носители: строка `.claude/rules/` и перечень `tools/` в
`.claude/rules/structure.md`, перечень гейта
`.claude/skills/update-roadmap-progress.md`, строка `rules/` в
`.claude/knowledge-tree.md`, запись реестра снятых редакций
`tools/retired-check.py`.

## Энфорсер на временном файле

```bash
printf '# Временное правило\n\nТекст.\n' > .claude/rules/zz-untiered.md
py tools/rule-tier-check.py; echo "КОД $?"
rm .claude/rules/zz-untiered.md
py tools/rule-tier-check.py; echo "КОД $?"
```

## Признак не меняет поведения Claude Code

Зонд `tier: core` без `paths:` загрузился безусловно, шапка в контекст не
вошла. Затем повторён замер `.claude/work/history/2026-09-23-rules-tiering.md`.
