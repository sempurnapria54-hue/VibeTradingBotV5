# Пакет шага сделки несёт только действие выхода

## На какой вопрос отвечает этот файл

Что сделано по секции «Шаг сделки принимает действия, которых никто не исполнит».

## Итог

Кодовый заход 205 шага 12 фазы 2 (Д2258). Шаг уровня сделки работает ребром:
пакет его действий исполнителями не запускается, объявленный выход исполняет
сворачивание (Д2255). Валидация сужала на детали только тип шага, и действие
иного типа или вида проходило создание, чтобы в проходе молча не делать ничего.

Построено: `StrategyDefinitionValidator#validateDealLevelActions` отвергает у
шага детали всякое действие, кроме вида `POSITION` с типом `EXIT_ACTION`
(`STRATEGY_DEAL_LEVEL_ACTION_OUT_OF_SCOPE`). Сужение по **паре**, а не по
одному типу: действие-заявка с типом выхода ядро тоже не исполнило бы —
исполнитель выхода выбирается по виду и типу вместе.

- Дом — `docs/rules/strategy-validation.md` §«Что проверяется на создании (400)»;
  довод — `docs/rules/no-partial-close.md` §«Две законные формы полного выхода».
- Юниты — `U14.9`-`U14.12` (`DealLevelStepScopeTest`); популяция точек отказа
  документа `.claude/tests/cases/strategy-definition-validation.md` получила
  строку 28, прочие перенумерованы.
- Найдено попутно и припарковано: пара вида и типа без исполнителя на уровне
  **транша** тоже проходит создание — `.claude/work/backlog.md` §«Действие
  транша с парой вида и типа без исполнителя проходит создание».
- Реактор — полный; числа — хроника шага, запись захода 205.
