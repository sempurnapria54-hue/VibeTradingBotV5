в плане): коды ошибок (`51603`), ACK ≠ runtime truth, адаптер-

place/cancel/get + `cancelAdvanceAlgos`; **amend-метода нет нигде**;
`OkxProxyController` без candle-passthrough (surface-gap P3).

## RUN — гибрид, на паузе (переезд в новый чат)

**Решение по эскалации — гибрид:** приложение поднимает пользователь
(IDEA run-config), вызовы по плану через `OkxProxyController` на
localhost делает CC. **Исполнено и на паузе** — факты и находки в
run-log `.claude/work/progress/source-api-pilot-run-log.md`:

- **Фаза 1 demo (частично):** негативы N1/N2 + place C1 ×2 → находки
  **F1/F2/F3**; teardown чист (орфанов нет). Цепочка C2–C4 и И-2
  (A1–A4) **отложены** (блокер F3-слой-2).
- **Фаза 2 I3:** **confirmed-by-code** (live deferred) — NPE на
  пустом секрете, `backlog.md` §I3.
- **Фаза 3 prod read-only (P1–P4)** — **в новом чате**.

Ниже — исходная проба среды и процедура (референс, по ним выбран
гибрид).

**Среда готова (проба 2026-06-12):** Postgres `5440`/`5441` слушают,
Vault распечатан (`~/.vault-token` есть), **egress к OKX публичному
API — HTTP 200**.

**Блокеры прогона из CC:**

- в окружении CC нет `mvn`/`mvnw`/собранного jar — приложение
  headless из CC не поднять; ручная сборка classpath под JDK 25 /
  Spring Boot 4 — нецелесообразна и хрупка;
- Vault-токен, которым приложение читает OKX-креды, живёт в
  **IDEA run-config**, не в shell CC → `spring.config.import:
  vault://` из CC не пройдёт;
- автономный подъём **торгового** приложения с постановкой ордеров
  рискует ошибкой профиля → write на prod; по правилу роли `tester`
  прогоны с prod-эффектом — **хвост пользователя**.

**Что подтверждено без прогона:**

- **I3 — статически подтверждён чтением кода.**
  `OkxSigningInterceptor.sign()` делает
  `properties.getSecret().getBytes(...)` → на пустом `secret` —
  **NPE** (а не fail-fast «OKX credentials not configured»).
  Подтверждает баг `backlog.md` §Инфра-долг I3. Живой прогон нужен
  лишь для фиксации точного типа/места исключения.

**Процедура RUN для владельца среды** (пользователь — через IDEA
run-config с Vault-токеном, либо `! <команда>` запуска):

1. Поднять приложение с профилем **`test`** (demo,
   `x-simulated-trading: 1`).
2. Прогнать через `OkxProxyController` по плану: негативы N1/N2 →
   цепочка C1–C4 → И-2 A1–A4 (всё demo, write — только demo).
3. **I3** — приватный вызов на пустых кредах (изолированная
   конфигурация) → зафиксировать NPE vs fail-fast.
4. Профиль **`prod`**, **только чтения**: P1 balance, P4 position,
   P2 instrument, P3 candles. **Ни одного write на prod.**
5. Факты по кейсам → отчёт прогона; вернуть на разбор.

После прогона: отчёт → REVIEW отчёта (`test-review`) → разбор
находок по владельцам → отчёт в `history`; задача закрывается.
