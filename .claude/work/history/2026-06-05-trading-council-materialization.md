# Материализация торгового совета — отчёт о классификации

## На какой вопрос отвечает этот файл

Как классифицированы и размещены фрагменты материала «торговый
специалист, торговый фокус ревьюера, торговая категория в петле»
(чат, 2026-06-04). Временный файл по правилу
`.claude/rules/classification-report.md`.

## Фрагменты

### Ф1. Торговый специалист (назначение, компетенция, опора, стойка, границы)

- **Область:** пайплайн (роль Claude, не продуктовое знание).
- **Тип:** «Что делает Claude в роли X?» → `.claude/agents/`.
- **Тема:** роль торгового специалиста.
- **Итог:** размещён — новый `.claude/agents/trading-specialist.md`
  (kebab-case по роли). Включены: front-load-касание, опора на
  корпус, правило конфликта книга/интернет, стойка грунтовки
  источником, вне-scope (биржевые спеки, аналитик), намеренно
  неопределённая «сбалансированность».

### Ф2. Зонтик «торговый совет», «одно знание — один дом», отвергнутые альтернативы

- **Область:** пайплайн.
- **Тип:** «Почему мы решили так, а не иначе? (пайплайн)» →
  `.claude/decisions/`.
- **Тема:** устройство торгового совета.
- **Итог:** размещён — новый `.claude/decisions/trading-council.md`
  с решением, пятью отвергнутыми альтернативами (отдельная петля,
  интернет-база, отдельная база ревьюера, приоритет по категории,
  аналитик сейчас) и разделом «Не определено намеренно».

### Ф3. Торговый фокус ревьюера (процедурное)

- **Область:** пайплайн.
- **Тип:** «Как именно делать X?» → `.claude/skills/`.
- **Тема:** адверсариальный торговый проход.
- **Итог:** размещён — новый `.claude/skills/trading-review.md`
  (по образцу остальных `*-review`-фокусов: стаб с границами,
  скелетом, форматом находки + ссылка на источник, cross-cutting
  паркингом; процедура обхода — с первых прогонов, не
  спекулятивно). Зарегистрирован в реестре фокусов
  `.claude/agents/reviewer.md` (активен, под-шаг `DOCS_CHECK_N`).

### Ф4. Торговая категория в петле DOCS_CHECK_N / GAPS_CLOSE_N

- **Область:** пайплайн.
- **Тип:** «Как устроен этот методологический процесс?» →
  `.claude/processes/` — оркестрация под-шагов, держит вызывающая
  сторона (скиллы самодостаточны).
- **Тема:** существующий процесс исполнения шага.
- **Итог:** размещён правкой
  `.claude/processes/roadmap-step-execution.md`: дополнение
  под-шага 2 (торговый фокус рядом с концептным) + новый раздел
  «Торговая категория в петле (под-шаги 2-4)» (приоритет по
  тяжести, торговое ведёт + рябь, гейтинг `CODE`, два касания,
  изоляция по текущему шагу + cross-cutting).

### Ф5. Дом книжного корпуса

- **Область:** пайплайн (структура размещения).
- **Тип:** не ложился ни в один существующий тип (внешние
  первоисточники — нового типа место); развилка подсвечена,
  решена пользователем в сессии: `.claude/library/trading/`.
- **Итог:** каталог создан (`.gitkeep`); новая строка в таблице
  `.claude/rules/structure.md` (вопрос «Что говорит торговый
  первоисточник?»; книги — не файлы знания, раздел «На какой
  вопрос…» к ним не применяется); упоминание библиотеки добавлено
  в краткое `CLAUDE.md`. Корпус не наполнялся (граница задачи).

## Проход 2 (2026-06-05): специалист поверх дистиллята

Хэндофф того же материала после выполненной дистилляции
библиотеки. Дельта против прохода 1 — грунтовка дистиллятом.

### Ф1'. Специалист: рабочее знание — дистиллят

- **Область/тип/тема:** те же, что Ф1 (роль → `.claude/agents/`).
- **Итог:** правка `.claude/agents/trading-specialist.md` —
  компетенция + рыночные манипуляции (кросс-каттинг); «Опора на
  знание» переписана: дистиллят по пиллерам (грузить только
  релевантный), PDF в `raw/` — источник правды, критерии нырка в
  PDF (формула/порог, условия/исключения, предпосылки сетапа,
  конфликт «⚠», молчание дистиллята), поведение на «∅ в корпусе
  нет» (не выдумывать, добор через чат); стойка — указатель
  книга/глава/страница из дистиллята.

### Ф2'. Decision: дом знания = raw + distilled

- **Область/тип/тема:** те же, что Ф2 (→ `.claude/decisions/`).
- **Итог:** правка `.claude/decisions/trading-council.md` (файл не
  закоммичен — по месту): пункт «Дом торгового знания» уточнён
  (raw = источник правды, distilled = рабочее знание), компетенция
  + манипуляции, связи + дистиллят.

### Ф3'. Фокус: грунтовка дистиллятом + манипуляционная наивность

- **Область/тип/тема:** те же, что Ф3 (→ `.claude/skills/`).
- **Итог:** правка `.claude/skills/trading-review.md`: грунтовка
  дистиллятом (релевантные пиллеры), примеры наивности к
  манипуляциям (стоп в очевидном месте, вход под спуфинг), формат
  находки — ссылка-указатель книга/глава/страница.

### Ф4'. Торговая категория в петле

- **Итог:** дельты нет — `roadmap-step-execution.md` и реестр в
  `reviewer.md` уже покрывают хэндофф полностью (приоритет по
  тяжести, рябь, гейтинг, два касания, cross-cutting, формат).
