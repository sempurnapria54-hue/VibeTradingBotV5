# Цепочка сессий без держателя

## На какой вопрос отвечает этот файл

Что сделано задачей «цикл неинтерактивных сессий» (2026-09-05).

## Итог

Роадмап теперь движется сессиями подряд без держателя: держатель
запускает цикл с пределом сессий, цикл гонит **новые** сессии `claude -p`
со стоячим промптом и останавливается ровно тогда, когда нужен он.

| Артефакт | Что несёт |
|---|---|
| `tools/session-loop.sh` | сценарий цикла: предполёт, предохранитель по диску, запуск, разбор статуса, журнал |
| `tools/session-prompt.md` | стоячий промпт — единственная задача сессии |
| `tools/session_envelope.py` | разбор конверта ответа (проба и поля сессии) |
| `.claude/skills/session-chain.md` | инструкция держателю: запуск, журнал, почему остановилось |
| `tools/stand/deploy-services.sh` | уборка прежних образов сервиса из узла — часть выкладки |

Решения захода — `.claude/work/decision-digest.md` §«Итерация 2026-09-05
(35) — цепочка сессий без держателя» (Д732-Д738).

## Что проверено прогоном, а не рассуждением

- **Контракт статуса работает:** `--output-format json` + `--json-schema`
  отдаёт поля в `structured_output`; цикл читает их, а не парсит прозу.
- **Все тропы остановки прогнаны живьём:** две сессии `continue` → лимит
  (код 0); `blocked` на первой сессии (код 4); порог диска (код 7, сессия
  не запущена); `CLAUDE_CODE_SIMPLE` из среды (код 2).
- **Проба «пайплайн загружен» работает:** сессия без инструментов чтения
  ответила `claude_md_loaded=true, project=VibeTradingBotV5`.
- **Уборка узла освобождает место:** 16109 → 14521 МиБ (1.55 ГиБ) при
  живых подах; `crictl rmi` на тех же ссылках освобождал 0 (Д734).

## Что осталось названным

- **`gates_green` — обещание сессии, а не измерение цикла.** Цикл верит
  тому, что сессия сообщила; независимая проверка — прогон команд корпуса
  рукой держателя.
- **Дельта в рабочем дереве растёт линейно по числу сессий:** коммитов
  цепочка не делает (`CLAUDE.md`), ревью — за держателем.
- **Стоимость запуска печатается, но не ограничивается** по умолчанию:
  предел — число сессий, либо `SESSION_MAX_USD` явно.
