# Линза E — сверка доков с исполнимой спецификацией (`DOCS_CHECK_26`)

Фокус: **концепция**, узкая задача — семантическая сверка `docs/spec/*.json`
с доками-домами. Стадия — до `CODE`, ведёт док.

Прогон не выполнялся (зелёный по данным оркестратора). Все отрицательные
посылки ниже верифицированы грепом/чтением; команды поиска названы в
трассировках, выводы в отчёт не вклеены.

Семантика формата прочитана по `tools/spec-run.sh` →
`src/test/java/com/example/tradingbot/spec/Spec.java` и `SpecExpression.java`:

- `includes` подключает величины другого файла; **одноимённая величина из
  двух источников — отказ загрузки** (`Spec.addValues`, «Величина объявлена
  дважды»). Проверка работает только внутри одного графа `includes`: копия
  в файле, который никто не включает, не ловится.
- `?идентификатор` **глотает** отказ резолва и возвращает `null`
  (`SpecExpression`, ветка `current == '?'`) — опечатка в имени поля
  неотличима от «поля нет».
- Операции агрегата: `sum count min max any all exists`. **`distinct` нет.**
- `expectRefusal` требует, чтобы вычисление бросило `SpecException`.
- `stateFrom` подгружает артефакт репозитория в состояние примера.

### G3. Заголовочное число шага 7 — `resultProfit` — не имеет исполнимой формы вовсе

**Вопрос.** Где дом формулы результата сделки и предиката области

**Цитаты (носители).**
- `docs/models/domain/aggregate/Deal.md:132-157` — формула в прозе:
  `resultProfit = Σ net по эпизодам + cross-ccy-слагаемое`, плюс

  списка исключений биржи **и** категория экономическая»), плюс контракты

  как результат расчёта»).
- `docs/spec/deal-lifecycle.json:13-14,47` — `resultProfit` фигурирует
  только операндом; `cleanTerminalContract` проверяет `notNull(resultProfit)`,

  **комплементарный** предикат `inReconciliationScope`

  предикат cross-ccy-слагаемого, отличающийся ровно первым конъюнктом
  («курс применён» вместо «расчётная валюта»), не исполним.
- `docs/models/domain/other/DealCashFlow.md:59-66` — `RateStatus`,
  закрытый перечень из 4 значений, на котором стои́т первый конъюнкт, —

**Целевой док.** Новый предмет `docs/spec/deal-result.json` (либо секция в
`pnl-reconciliation.json`); `Deal.md:132-146` сводится к названию величины
