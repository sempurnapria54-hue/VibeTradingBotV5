### D-7 (гейтящий)

1. **Политика сформулирована** — «поактный потолок — предел, а не цель;
   связывает меньший из двух пределов».
2. **Носитель назван и существует** — `docs/rules/risk-policy.md`
   §«Поактный потолок — предел, а не цель сайзинга» (дом политики; на
   него уже ссылалась `order-sizing.json`, теперь ссылка разрешается).
3. **Механика прописана** — читает `SizeCalculator` (размер), проверяет
   `RiskValidator` (поактное неравенство над готовым размером);
   срабатывает на каждом входном действии; резолвится формулой
   `desiredContracts = min(...)`.
4. **Счётный клейм** — критерий связывания и порог `0.9 %` стоя́т на двух
   уже существующих примерах `order-sizing.json` (стоп 3 % цены —
   связывает риск; стоп 0.1 % — аллокация, риск 0.198 % при потолке 1 %).
   Новых примеров узел здесь не заводил: дом формы вне периметра, а обе
   стороны границы в нём уже утверждены.

## 6c. Хвост закрытия — сверка доработки раунда 2

Верификация раунда 2 подтвердила, что **всё заявленное в §6b
приземлилось и проверку выдержало**: пробы воспроизведены сверщиком
самостоятельно (смещение порога → 2 расхождения на обоих граничных
примерах; `riskCeilingBinds → true` → 1, а сверх заявленного и
`→ false` → 2, то есть предикат закреплён в **обеих** полярностях;
вырождение цепочки → 2, по осям 1+1), `bindingStopDistance` выведена
заново из равенства пределов и совпала до последнего знака, достижимость
обоих примеров К2 подтверждена.

При этом сама доработка внесла **два новых гейтящих дефекта** — оба в
конструкции, которой закрывался К1. Мини-петля исчерпана, поэтому правки
идут **хвостом закрытия**: свои проверки, свой раздел, независимая сверка
вместо нового раунда.

| Находка | Исход |
|---|---|
| **В1 (гейт).** Правило утверждало, что переломная дистанция «**растёт** вместе со ставкой комиссии». Направление обратное: `d(f) = P(k − 2f)/(1 − f)` убывает по `f` (`d'(f) = P(k−2)/(1−f)² < 0` при `k < 2`); численно 30.000 → 27.0135 → 24.024 → 18.036 → 0 при `f` от 0 до 0.005. Прогон не ловил, потому что **ни один пример не варьировал `takerFeeRate`** | **закрыто с двух сторон.** Формулировка исправлена на «**убывает** с ростом ставки» с механизмом («дорогой round-trip съедает бюджет риска и уводит перелом к более тесным стопам»). Знак **закреплён примером**: тот же стоп 26 пунктов при вдвое большей ставке (`takerFeeRate = 0.001`) связывает уже потолок риска, а не аллокацию (`bindingStopDistance` 24.024, `riskCeilingBinds` true против false у близнеца на 5 б.п.) |
| **В2 (гейт).** Нота `riskCeilingBinds` расходилась с собственным `expr` на множитель `contractValue`: проза говорила «убыток на стопе одного **контракта**», `expr` сравнивает ценовые величины — на эталоне 3.0 против 30 | **закрыто** — нота переписана: сравниваются **ценовые** величины без множителя стоимости контракта, «ценовой убыток на единицу экспозиции (дистанция стопа плюс round-trip комиссия обеих ног) превосходит долю `riskPerActionPercent / allocationPercents` цены входа». `expr` не трогался — он верен и закреплён примерами |
| **В3.** §Охват числил `order-sizing.json` «вне периметра, не трогалось» и не называл ещё пять фактически правленных файлов; из-за этого §5a объявлял форм-проверку по устаревшему списку | **закрыто правкой самих строк** — §Охват заменён таблицей **пятнадцати** фактически правленных файлов с причиной каждого (список снят с `git`, не с намерения), открытие `order-sizing.json` названо явно с основанием; §5a пересчитан по этому же списку. Попутно найдено и снято последнее попадание формы — ссылка на `.claude/decisions/` в шапке `risk-evaluation.md` |
| **В4.** К12 помечен закрытым, но `trading-constraints.md:24` стал 103 знака | **закрыто** — абзац перевёрстан, длинных строк в правках узла не осталось |
| **В5.** `bindingStopDistance` выведена только для длинной стороны, правило ссылалось без оговорки (для SHORT 26.9865 против 27.0135, молча) | **закрыто** — в правило добавлен пассаж «Предикат сторонне-независим, закрытая форма дистанции — нет»: `riskCeilingBinds` верен для обеих сторон, `bindingStopDistance` выведена для длинного входа, у короткого перелом ближе (26.9865 против 27.0135), и в клеймах о переломной дистанции подразумевается длинная сторона. Нота спеки это уже говорила — теперь говорит и дом политики |

**Прогон и проба хвоста.** Спеки — **20 / 366, зелёный**. Новая падающая
проба на знак зависимости: `bindingStopDistance`, объявленная **растущей**
