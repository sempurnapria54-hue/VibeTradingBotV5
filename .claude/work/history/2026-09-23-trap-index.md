# Ловушки: оглавление на старте, тело по номеру

## На какой вопрос отвечает этот файл

Что сделано задачей «ловушки — оглавление на старте, тело по адресу» и какими
замерами это подтверждено.

## Итог

Разделы ловушек восьми домов, названных снапшотом, стали оглавлениями:
строка на ловушку — область, симптом и номер тела. Тела перенесены дословно в
`.claude/traps/<дом>-traps.md` под заголовками-номерами, подразделы оглавления
и тел повторяют прежние подразделы дома. Правило — `.claude/rules/structure.md`,
строка `.claude/traps/`; решение — `.claude/decisions/trap-index.md`; энфорсер
`tools/trap-index-check.py` стоит в гейте инструментов корпуса. Шесть правил
вне перечня снапшота держат ловушки телами и объявлены долгом
`tools/trap-index-debt.txt`.

## Проверки

- **Ни одна ловушка не потеряна.** Энфорсер: 312 строк оглавления, 312 тел,
  соответствие номеров взаимно-однозначно.
- **Тела дословны.** Сверка каждого тела с исходным пунктом: совпали 310.
  Два тела дома среды (`ENV-001`, `ENV-005`) получили путь дома перед
  §«Воспроизводимые команды»: в новом файле адрес иначе разрешался в него
  самого.
- **Каждая строка несёт область, симптом и номер** — форму мерит энфорсер.
- **Текст домов вне разделов ловушек тождествен исходному** у семи домов. У
  `.claude/skills/update-roadmap-progress.md` добавлена одна строка — команда
  новой проверки в перечне гейта, её требует задача.
- **Входящие адреса.** Два адреса из `measurement-commands.md` на подразделы
  дома среды разрешаются: заголовки подразделов сохранены в оглавлении.
