## На какой вопрос отвечает этот файл

## Единица работы и её заходы

Единица — **один кодовый заход**: закрытие всех находок фокусов
(`.claude/rules/session-work-unit.md`). Вход — раздел «Сводка находок»
отчёта `.claude/work/progress/phase-2-step-10-code-focuses.md`.

**Автор находок их не закрывает** — это и есть причина, по которой закрытие
идёт отдельной единицей (`.claude/skills/conventions-review.md` §«Процедура»).
Симметрично: **эта единица аппрува не выдаёт**. Аппрув есть зафиксированный
исход фокусов с закрытыми находками, и повторный прогон фокусов по
затронутому — следующая единица.

| Заход | Состояние |
|---|---|
| кодовый заход K13 (корпусный) | `записан` — §«Классификация правки по родам» |

Раунда критики и доработки у единицы этого рода нет: корпус она меняет одной
партией, а исход её правок мерит прогон — реактор, тесты модулей и четыре
мутационные пробы.

```bash
grep -rn "aBlankTenantHeaderIsNotAccepted" services/audit-statistics/src/test
```

маршрута. **Клейм `pom.xml` о стартере валидации, таким образом, держится

### Чего заход НЕ делал, и почему это названо

- **Транзакция ребра не сужена.** Вариант (а) находки — вынести три резолва
  идентичностей за границу транзакции — требует **второго бина**: самовызов
  транзакции в Spring не открывает. С помеченным отказом цена резолва внутри
  транзакции равна повтору на следующем проходе, а не потере, — то есть
  больший след перестал что-либо покупать
  (`.claude/rules/design-simplicity.md`).
- **`access_denials` не получила глубины и не вошла в проход чистки.**
  Назначать глубину раньше, чем появится читатель частоты, значило бы
  зафиксировать число, по которому никто не считает; проход же чистки
  ограничен профилем окружения и в `prod` предмета не имеет — то есть покрыл
  бы рост ровно там, где он безопаснее всего. Обе величины задачи выводятся
  из одной наблюдённой частоты, и это записано у неё.
- **Перехватчик `Exception` у `bff` и `strategies` не тронут.** Класс шире
  одного сервиса, но правка чужого сервиса — его находка; здесь она названа
  и припаркована (`.claude/work/backlog.md`).
- **Предикат «принципал либо контур» в общий артефакт не уехал.** Он читает
  контекст Spring Security, и зависимость общего артефакта становится
  обязательной для всех сервисов (`.claude/rules/codestyle.md` §«Новый модуль
  монорепозитория»). Со-расположение названо у всех трёх копий, оживитель —
  задача бэклога.
- **Индекс по одному моменту не оставлен рядом с новым.** Читателя у него не
  осталось бы ни одного: обе выборки пересчёта отбирают классы внутри суток.
  Число индексов на таблице не изменилось, и клейм миграции «индексов пять»
  остался верен.

## Классификация правки по родам

Словарь — `.claude/rules/edit-kind-obligations.md` §«Словарь родов — закрытый»;
исход у каждого рода обязателен, включая «не играет».

| Род | Что ввёл заход | Исход |
|---|---|---|
| `снятие` | снята действующая редакция признака `Objects.equals` («слева … результат вызова — `Objects.equals`», `.claude/rules/codestyle.md`); снят клейм единственности реализации предиката актора («вторая копия правила разошлась бы с первой») у обоих `ActorProvider`; снято поле `ReceptionProperties.topics` вместе с пассажем о нём | правлены **в своих домах** и на месте, второй редакции рядом не оставлено. Свип по популяции носителей: у клейма единственности носителей оказалось **два** (оба `ActorProvider`), у признака `equals` — один (дом конвенции), у поля тем — три (класс свойств, слушатель, `application.yaml`); все пройдены. Записи в реестре снятых редакций не заводится: у признака `equals` снята **клауза**, а не политика, и её пришедшая редакция стои́т в том же абзаце; у клейма единственности снято **состояние** («копия одна»), а не норма |
| `дом` | **играет:** заведён дом хелпера имени значения перечня — `libs/.../domain/util/EnumNames.java`; заведён дом ответа «кто инициировал ход» у третьего сервиса — `services/audit-statistics/.../domain/service/ActorProvider.java` | указатели переведены тем же ходом: все пять точек `name(Enum<?>)` зовут новый дом (свип пуст), единственный читатель актора у `audit-statistics` зовёт бин, а не приватный метод. | `величина` | **играет:** введены три величины конфигурации — размер пула на каждое из двух подключений-владельцев и размер пула кросс-подключения | у каждой назван писатель и место: пишет владелец, разворачивающий сервис, ключом манифеста окружения; дефолт кладёт этот заход и выводит его из параллелизма процесса. ## Свипы правок корпуса

**Свип прямых отрицаний — по конструкции, а не по одному файлу:**

```bash
grep -rnE "(^|[^!=<>a-zA-Z0-9_])![a-zA-Z(]" services/*/src libs/*/src --include=*.java | grep -v "!="
```

Выдача пуста. Донор из области исключён намеренно: портированная область в
нём заморожена (`donor/README.md`).

**Свип `equals` — по получателю, а не по форме записи:**

```bash
grep -rnE "[a-z][A-Za-z0-9_]*\.get[A-Za-z]*\(\)\.equals\(|[a-z][A-Za-z0-9_]*\.name\(\)\.equals\(" services/*/src libs/*/src --include=*.java
```

Выдача пуста. Полный свип `[a-zA-Z0-9_)]\.equals\(` по тем же деревьям даёт
161 вхождение; после вычета `Objects.equals` и `Type.class.equals` остаются
только формы `КОНСТАНТА.equals(x)`, `Enum.VALUE.equals(x)` и
`Enum.VALUE.name().equals(x)` — то есть ровно те, которые дом конвенции
называет безопасной формой. **Третья из них и породила клаузу**: прежний
признак читал её как результат вызова.

**Свип копий хелпера:**

```bash
grep -rn "private static String name(Enum" libs/ services/
```

Выдача пуста.

**Свип читателей снятого поля:**

```bash
grep -rn "getTopics\|reception.topics\|setTopics" services/ libs/ deploy/
```

Две строки: `ReceptionStateJob` читает темы **у контейнера слушателя**
(`container.getContainerProperties().getTopics()`), а не у свойств, и
единственный читатель ключа — выражение самого слушателя.

**Свип имени индекса по всему корпусу:**

```bash
grep -rn "ix_audit_record_occurred" . | grep -v "/target/" | grep -v "^./.git/"
```

Живых носителей три — миграция, док модели, javadoc репозитория, — все
правлены. Прочие вхождения лежат в отчётах закрытых узлов: они описывают
прошлое и правке не подлежат (`.claude/rules/curation.md` §«Чек-лист свипа»),
**кроме** строки таблицы дельты `CODE` хроники — она описывает наличный
состав дельты, а не момент, и приведена к фактике.

мерит. Разделитель — запятая.
