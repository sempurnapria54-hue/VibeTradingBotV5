# Кодовый заход шага 9 — актор записи (`PrincipalAuditor`)

## На какой вопрос отвечает этот файл

Чем закодирован резолв принципала в актора записи на шаге 9 фазы 1.

## Что построено

| Артефакт | Роль |
|---|---|
| `config/JpaAuditConfig` (переписан) | резолвер актора: читает контекст хода и отдаёт имя принципала либо класс контура |
| `config/AsyncSecurityContextConfig` | переносит контекст хода в тред пула асинхронного фасада |

**Носитель дискриминатора — контекст хода.** Ставит его точка порождения
хода (обработка внешнего вызова под предъявленным принципалом), читает —
резолвер в момент, когда persistence проставляет поля аудита. Полем модели
инициатор не выражается: величина у всех записей одна, а писателем поля
стал бы каждый исполнитель — то есть тот, кто о происхождении хода не
знает.

## Решения захода

| Решение | Альтернативы | Почему так |
|---|---|---|
| **Анонимная аутентификация актором не становится** | писать её имя (`anonymousUser`); считать её внешним инициатором | контур доступа отдаёт её на открытой точке (проба живости); записать её именем актора значило бы утверждать, что запись создал субъект, которого контур **не удостоверил** |
| **Перенос контекста — обёрткой исполнителя, а не режимом хранения** | наследуемый thread-local (`MODE_INHERITABLETHREADLOCAL`) | наследование покрывает тред, **созданный** вызовом; фасады исполняются на пуле, где тред переиспользуется, и наследование там не работает вовсе |
| **Планировщик в перенос не входит** | обернуть и его | у запланированного тика внешнего инициатора нет по построению, и пустой контекст — верный ответ, а не потеря |
| **Пустой контекст даёт класс контура** | отказывать в записи; писать «неизвестно» | это значение **по проверенному признаку** («внешнего инициатора нет»), а не умолчание; третьего класса область значений не заводит |

## Пробы — падают без своего кода

`PrincipalAuditorTest` (4 пробы):

| Проба | Что охраняет |
|---|---|
| внешний вызов под принципалом → имя | резолвер вообще читает контекст |
| внешнего инициатора нет → класс контура | значение по признаку, а не отказ |
| анонимная аутентификация → класс контура | не-субъект актором не становится |
| **контекст переживает смену треда на пуле** | перенос работает на переиспользуемом треде |

**У последней пробы есть контроль внутри неё же:** тот же пул **без**
обёртки принципала не видит и отдаёт класс контура. Без контроля проба
прошла бы и на случайно унаследованном контексте, то есть ничего бы не
доказывала. Тред пула при этом **прогревается чужим ходом** до
аутентификации — иначе наследование при создании треда сделало бы
результат ложно-зелёным.

## Что осталось названным ограничением

**Ручная поверхность постановки ступеней не построена** (в системе живут
только операции снятия — `docs/rules/manual-halt.md`), поэтому тропа
«человек нажал → запись в чужом треде» сегодня достижима только через
ручные триггеры джоб. Перенос контекста от этого не зависит: он стои́т на
исполнителе, а не на конкретной тропе.
