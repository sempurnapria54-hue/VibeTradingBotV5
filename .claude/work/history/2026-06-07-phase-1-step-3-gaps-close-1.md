## Что оставлено (нужно перепрогону)

### Решение Э1 — охват шага 3: весь кластер производных рыночных данных

Шаг 3 Фазы 1 охватывает **весь кластер производных рыночных
данных**: индикаторы + структура рынка (`MarketStructure`) + фаза
рынка (`MarketPhase`) — их jobs, модели и сервисы. Шаг не
ограничен индикаторным кластером.

Обоснование:

- `market-data-calculation` — один процесс с тремя jobs и цепочкой
  зависимостей (Structure ← optional IndicatorValue; Phase ←
  IndicatorValue + Structure) — разрез шага рвёт единый процесс;
- структуру и фазу не несёт ни один другой шаг Фазы 1 — без
  включения сюда у них нет шага-дома;
- шаг 7 (`EntryScannerJob` выбирает `StrategyDetail` по фазе)
  потребует готовую фазу — без неё end-to-end цикл фазы не
  собирается.

Отклонённые альтернативы:

- **Узко — только индикаторный кластер.** Структура/фаза без
  шага-дома; режет единый процесс `market-data-calculation`.
- **Отдельный шаг для структуры/фазы.** Режет единый процесс на
  два шага роадмапа; зависимости тянут структуру/фазу обратно к
  индикаторам.

### Формулировка шага 3 в роадмапе

Формулировка шага в `phase-1.md` приведена к решению Э1:
«Индикаторы …» → «Производные рыночные данные: …». Правка
сохранена при откате.
