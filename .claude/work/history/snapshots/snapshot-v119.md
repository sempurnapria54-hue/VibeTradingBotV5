## Что ратифицировано и не пере-решается

Всё из v104-v118, плюс (Д530-Д542):

- **Опознание отказа кредов — по коду, а не по HTTP-статусу**: статус у
  всего семейства один, и по нему **наш** дефект сборки неотличим от
  отвергнутых кредов.
- **Перечней кодов два, а не перечень плюс отрицание** — третий класс
  («прочий отказ источника») существует.
- **Изъятие из ретраибельного — отдельной веткой**, а не конъюнктом в
  предикате повторяемости: там повторяемость из кода ошибки, здесь снята
  природой отказа.
- **Проактивной детекции отдельная ветвь не заводится** — её реакция на
  «не удалось наблюдать» уже построена и верна по существу.
- **Арность принципала — в одном бине; секрет из Vault, умолчаний нет.**
- **`@PreAuthorize` не ставится**, плейсхолдер снят из код-шаблона.
- **Перенос контекста хода — обёрткой исполнителя**, не наследуемым
  thread-local.
- **Применённая миграция неизменяема, включая комментарии** (конвенция
  `codestyle`).
