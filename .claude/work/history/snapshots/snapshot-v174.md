## Среда

Против v132 не изменилась; полное описание — там. Ловушки среды из v156-v173
остаются в силе, включая: полный гейт инструментов в 120 с не укладывается —
прогонять фоновой командой; рабочий бинарь — `py` (`python3` из PATH —
заглушка, её код 49 читается как «не измерялось»); в regex-шаблонах для
`tools/retired-check.py` пользоваться `\s+`; markdown-тело с собственным
heredoc рвёт внешний — писать инструментом записи.

**Новое этой сессии — три ловушки.** Heredoc `<<'PY'` рвётся и на **питоновом
теле** с вложенными тройными кавычками — сложные скрипты писать инструментом
записи, а правки существующих файлов делать точечным Edit, а не `replace` из
heredoc. Второе: `py` — виндовый бинарь и путей `/tmp/**` не видит; временные
файлы для него класть в рабочий каталог и удалять тем же ходом. Третье:
импорт модуля из `tools/` через `importlib` роняет `__pycache__` **в корень
репозитория**, и `tools/retired-check.py` отказывает кодом 2 на нём («каталог
верхнего уровня вне объявленной области») — удалять сразу после импорта.
