## Что сделано после v344

Одна единица: **написан документ кейсов `jsonb-overlay-roundtrip`** —
четырнадцатый и последний предмет уровня 2 (заход 64). Документ —
`.claude/tests/cases/jsonb-overlay-roundtrip.md`, отчёт передачи с таблицей
самопроверки —
`.claude/work/progress/phase-2-step-12-hand-test-jsonb-overlay-roundtrip.md`.
Здесь — только то, что меняет картину.

- **Предмет — пять форм навеса JSONB, живущих семью классами в трёх
  деревьях** (`trading-core`, `market-data`, `strategies`); двенадцать групп
  кейсов. Состав — сам документ, здесь не пересказывается.
- **Второй вход популяции дал класс, которого реестр кандидатов не печатает
  по построению:** писатель снимка отчёта аномалии — навес пишет, конвертера
  не имеет. В предмет не взят по критерию «отказ приходит к читателю» (отказ
  поглощён, читателя в коде нет) и стои́т пробелом `G5`.
- **Новая ось формы: выход кейса есть тождество ПАРЫ, а оператора тождества у
  предмета нет.** Ни один класс общей доменной библиотеки не переопределяет
  сравнение, поэтому способ сравнения выбирается документом и **сам является
  предметом**: рекурсивное сравнение по полям видит потерю, которую сравнение
  строк JSON не видит по построению (потерянного на записи нет в обеих
  строках). У навеса с изъятием тождество к тому же ложно целиком — кейс
  обязан назвать изъятое.
- **Восемь находок владельцам получили секции бэклога тем же заходом.**
  Существенные: изъятия двух копий конвертера навеса правил инструмента
  **асимметричны** — каждая изымает своё поле из двух, и дом изъятия оговорки
  о дереве не несёт; **форма навеса не запинена ничем** — во всей общей
  доменной библиотеке ровно один класс несёт сериализационную аннотацию, и он
  адресован проводу, поэтому переименование Lombok-аксессора теряет уже
  записанное молча; форма последней ошибки строки исполнения **дома в
  `docs/**` не имеет ни одного**; седьмой конвертер берёт общий маппер без
  копии, то есть форма его колонки двигается правкой чужого бина.
- **Девятая находка закрыта правкой на месте.** Соседний документ уровня 2
  (`domain-model-predicates`) передал сюда пробел по посылке «имена
  дискриминатора действия читает конвертер навеса у трёх сервисов». Посылка
  проверена по коду и **не держится**: дерево действий хранится реляционно
  (базовая таблица плюс таблицы по видам), и ни один из семи конвертеров его
  не сериализует. Строка `G3` соседа правлена, адресат переставлен на
  читателя провода.

**Семь находок формы у `platform-shared-logic`** (`Ф-8`-`Ф-14`) апрув не

**Что форма захода уже включает** (не выводить заново) — всё, что
перечисляли v325-v344 §«Вход следующей сессии», остаётся в силе дословно
(`.claude/work/history/snapshots/snapshot-v325.md` …
`…/snapshot-v344.md`). **Заход 64 добавляет три оси:**

- **Посылка, по которой предмет ПЕРЕДАН, проверяется по коду прежде, чем
  исполняться.** Переданный пробел приходит с готовым доводом, и довод этот
  написан тем, кто предмета не открывал; здесь он оказался ложным целиком.
- **Конфигурация без операнда — находка того же класса, что расхождение с
  домом.** Переключатель маппера, у которого среди форм конвертера нет ни
  одного применимого значения, читается следующим как обещание формы, и
  javadoc это обещание повторяет.
- **Копия, расходящаяся НАМЕРЕННО, ломает ожидание «одно на два дерева».**
  Ось копий предписывает одно ожидание паре; там, где копии несут **разные**
  правила, ожидание обязано быть раздельным, и раздельность — сама находка.

## Ловушки

**Ловушки** v206-v344 остаются в силе. Подтверждено этой сессией:

- **Heredoc с закавыченным разделителем в этой оболочке не проходит** —
  оболочка обрывается на «unexpected EOF while looking for matching quote»
  независимо от содержимого. Рабочая форма для длинного текста: написать
  файл инструментом записи во временный каталог **вне репозитория** и
  прицепить его `cat >>`; `target/` в корне при этом не заводить — он роняет
  `retired-check.py` кодом 2.
- **`grep -c` по миграции печатает число колонок навеса** — воспроизводимая
  форма счёта для второго входа популяции; перечень писателей даёт
  `grep -rln 'writeValueAsString\|convertValue'` по трём деревьям.
- Прочие ловушки — снапшоты v283, v285-v344 §Ловушки; они не переписываются.
