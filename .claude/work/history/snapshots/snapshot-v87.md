из последнего §«Что не закрыто» того же отчёта, где стояло «4 позиции пакета
возврата». Проверка на следующий снапшот: число позиций незакрытого пакета
берётся из §«Что не закрыто» отчёта закрытия, а не из его заголовка.

**Второй дефект того же пакета:** у позиций С1-С4 **не было файла-ключа** в
`.claude/work/blind/` — ключом служили таблицы вариантов в самом отчёте, то
есть проход прошёл **первым** входом слепого прохода (перечень с креном,
записанный прогоном), а не **третьим** (запечатанный ключ, писанный до
опроса). Правило дополнено: ключ-файл заводится для **любого** пакета,
включая пакеты возврата.

## Ратифицировано этой сессией — не пере-решать

**Из пакета С (`GAPS_CLOSE_16`):**

- **Действие стратегии состоит из нескольких команд.**
  `CLOSE_POSITION_COMMAND` закрывает позицию, и всё; осмысленное действие —
  **выход из сделки**, отмена живых входных ног входит **в его состав**;
  закрытие позиции означает закрытие сделки. Общий teardown **не заводится**,
  эмиссия действия стратегии с системной тропы **отвергнута**; носителей
  последовательности два, и это не дубль (kill-switch системный — штатный
  выход по стратегии).
- **Инвариант порядка** «сначала отменить входные ноги, потом закрывать» —
  единственное место записи `docs/rules/exit-teardown-order.md`.
- **Триггер пересчёта основной защиты — шаг стратегии**
  `PROTECTION_ADJUSTMENT` с условием «позиция увеличилась».
- **Ветка «операнд допуска не резолвится» и код
  `RECONCILIATION_OPERAND_MISSING` — сняты**; реакция у детектирующего
  контура (отказ операции).
- **Правка 12 провалидирована** (форма перечня + перенос цены дословно).

**Из пакета П (`GAPS_CLOSE_17`) — только то, что меняло принятое:**

- третье число риска пишет **наблюдатель позиции**, и наблюдение включает
  **историю** (нога 2 evidence-cycle) — П1;
- операнд полноты разбивки **составной**:
  `max(t_добычи, billsWindowEnd) − billsWindowBegin` — П4;
- **состав цикла добычи един для всех троп**; тропный гейт остаётся у
  отдельного звена (bills) — П5;
- **два кода холда по исчерпанию** (живая тропа / посмертная добыча),
  реакция одна — П6;
- пустой `billsWindowBegin` ⇒ **суррогат** `Deal.createdAt` (довод: одна
  сделка на инструмент) — П7;
- `NOT_APPLICABLE` пишет **исполнитель закрытия** — П9;
- `currentRiskAmount` — **неотработанная доля** взятого риска; «риск, снятый
  защитой» — **отдельная колонка** — П10;
- **неполное число уводит терминал в аварийный**; пятого признака нет — П11;
- конвенция «**пусто = 0**» для несобытийных полей — в native-слое +
  предусловие `CODE` **п. 14** — П12;
- допуск epsilon **не меняется** — П13;
- плечо — **ручная статичная настройка**; заведён `liquidationDistanceRatio`;
  открывающий вход из популяции guard выведен явно — П14;
- **реджект `contractType ≠ LINEAR`** на заведении инструмента — П15;
- **действие выхода входит в `CODE` шага 7** — П16;
- кейс `AG1.8` (след ADL) + **третий исход** `OBSERVED_ABSENT`, закрывающий
  гейт с записанным допущением — П17/П18.
