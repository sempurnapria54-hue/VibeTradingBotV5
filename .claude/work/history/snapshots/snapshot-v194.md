## Среда

Против v132 не изменилась; полное описание — там. Ловушки среды из v156-v193
остаются в силе, включая: полный гейт инструментов в 120 с не укладывается —
прогонять фоновой командой (`tools/spec-mutation-check.sh` один держит
несколько минут); рабочий бинарь — `py`; в regex-шаблонах для
`tools/retired-check.py` пользоваться `\s+` и делать их терпимыми к разметке;
вывод `py` через пайп идёт в cp1251 и рвётся на кириллице (`export
PYTHONIOENCODING=utf-8`); перед всяким `-P`-прогоном ставить
`export LC_ALL=C.UTF-8`; `\w` у `grep -P` кириллицы не берёт — классы писать
явно (`[а-яё]+`); файл журнала фоновой команды писать в `$TEMP`; многострочная
правка целится в текст **с его отступом**; точная подстановка проверяется
счётом вхождений до записи; спека, переписанная разбором-сборкой JSON, теряет
отступ корпуса — править точечной подстановкой; длинный кириллический heredoc
в Bash рвётся — длинные тела писать инструментом записи файла, не оболочкой.

**Ловушки этой сессии (новые):**

- **Обратный слэш в heredoc `py - <<'PYEOF'` съедается** — литерал `'\\'`
  приезжает в Python как `'\'` и роняет разбор `SyntaxError: unterminated
  string literal`. Обход: `BS = chr(92)` и склейка, либо шаблон без слэшей.
- **Командный блок отчёта бывает отступным, а не ограждённым.** Извлечение,
  ищущее только ` ``` `, у отчётов узлов 3 и 4 `GAPS_CLOSE_5` не находит ни
  одного блока и объявляет их бескомандными. Брать обе формы.
- **`grep -P` без `LC_ALL=C.UTF-8` отказывает кодом 2 при ПУСТОЙ выдаче** —
  «grep: -P supports only unibyte and UTF-8 locales». Пустая выдача читается
  как чистый свип: код возврата смотреть обязательно.
