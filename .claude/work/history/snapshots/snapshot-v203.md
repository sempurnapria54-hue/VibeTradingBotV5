## Среда

Против v132 не изменилась; полное описание — там. Ловушки среды из v156-v202
остаются в силе, включая: полный гейт инструментов в 120 с не укладывается —
прогонять фоновой командой; рабочий бинарь — `py`; вывод `py` через пайп идёт в
cp1251 и рвётся на кириллице (`export PYTHONIOENCODING=utf-8`); перед всяким
`-P`-прогоном ставить `export LC_ALL=C.UTF-8`; длинный кириллический heredoc в
Bash рвётся — правки корпуса писать временным `.py`-файлом либо инструментом
записи файла; точечный прогон модуля идёт **из корня** (`-pl`), а не через `-f`;
`docker` под Git Bash требует `export MSYS_NO_PATHCONV=1`; `cd` внутри составной
команды Bash переносит рабочий каталог сессии.

**Ловушки этой сессии.**

- **Капитализация `beanspec` роняет поле с проводa молча.** У поля, чей второй
  знак заглавный (`rSum`, `kPeriod`), Lombok печатает геттер `getrSum`, а
  сериализатор считает геттером только `get` + ЗАГЛАВНАЯ: свойство не
  опознаётся ни в теле ответа, ни в схеме, и отказа при этом нет. Имя объявлять
  явно (`@JsonProperty` из `jackson-annotations`), исход закреплять пробой на
  проводе.
- **Кортежное сравнение на пустой колонке теряет строки без единого признака.**
  `(a, b) < (x, y)`, дошедшее до пустоты, даёт НЕИЗВЕСТНО, и строка выпадает из
  выдачи. Пустые колонки в ключе — предмет фикстуры, а не её украшение: без
  строки с пустым ключом дефект не воспроизводится.
- **Backslash в кириллическом heredoc Bash съедается** — генератор пробника с
  экранированием писать файлом, а не heredoc'ом.
- **`git show HEAD:<путь>` на новом модуле отказывает:** весь модуль staged и не
  закоммичен. Сверка с прежним состоянием идёт через индекс — `git show :<путь>`.
- **Мутацию, которая ловится компиляцией, батарея обязана различать от зелёной.**
  Тип, а не квалификатор, — сильнейшая охрана выбора подключения: подмена не
  собирается вовсе, и драйвер батареи должен записывать это исходом, а не
  «мутация не поймана».
