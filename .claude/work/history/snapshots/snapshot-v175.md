Против v132 не изменилась; полное описание — там. Ловушки среды из v156-v174
остаются в силе, включая: полный гейт инструментов в 120 с не укладывается —

заглушка, её код 49 читается как «не измерялось»); в regex-шаблонах для
`tools/retired-check.py` пользоваться `\s+`; markdown-тело с собственным
heredoc рвёт внешний — писать инструментом записи; `py` путей `/tmp/**` не
видит; импорт модуля из `tools/` через `importlib` роняет `__pycache__` в
корень репозитория, и `tools/retired-check.py` отказывает кодом 2 на нём.

**Новое этой сессии.** `python` в PATH — та же заглушка, что `python3` (код 49);
в heredoc-скриптах звать `py`. Пробный файл для контроля отрицательного клейма
класть в рабочий каталог и удалять тем же ходом — `py` и `grep` видят его
одинаково, а `/tmp` только `grep`.
