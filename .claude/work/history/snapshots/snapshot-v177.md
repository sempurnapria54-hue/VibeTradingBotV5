## Среда

Против v132 не изменилась; полное описание — там. Ловушки среды из v156-v176
остаются в силе, включая: полный гейт инструментов в 120 с не укладывается —
прогонять фоновой командой; рабочий бинарь — `py` (`python3` и `python` из
PATH — заглушка, её код 49 читается как «не измерялось»); в regex-шаблонах для
`tools/retired-check.py` пользоваться `\s+`; markdown-тело с собственным
heredoc рвёт внешний — писать инструментом записи; `py` путей `/tmp/**` не
видит; импорт модуля из `tools/` через `importlib` роняет `__pycache__` в
корень репозитория, и `tools/retired-check.py` отказывает кодом 2 на нём; `cd`
внутри составной команды Bash сохраняется между вызовами.

**Новое этой сессии.** `py - <<'EOF'` (скрипт со stdin) `__pycache__` в корень
**не роняет** — в отличие от импорта через `importlib`; это рабочая форма для
точечной правки файла, когда heredoc с markdown-телом небезопасен.
`tools/__pycache__/` существует, покрыт `.gitignore` и в выдачу файловых свипов
по `tools/` попадает двоичным файлом — носителем знания не является.
