## Ловушки

**Ловушки** v206-v342 остаются в силе. Подтверждено и дополнено этой сессией:

- **Classpath Windows-JDK в Git Bash — драйв-буквенной формой**
  (`C:/Users/...`) и разделителем `;`; POSIX-путь даёт «package does not
  exist» на каждом импорте, то есть отказ читается как отсутствие библиотеки.
  Подтверждено вторым прогоном.
- **`SimpleAsyncTaskExecutor` пулом не является даже с
  `setConcurrencyLimit(1)`:** лимит ограничивает **одновременность**, а не
  число тредов — каждая задача получает свой. «Тот же тред» строится только
  `ThreadPoolTaskExecutor` с `corePoolSize = maxPoolSize = 1`.
- **`target/` в корне роняет `retired-check.py` кодом 2** («каталоги верхнего
  уровня вне объявленной области»): каталог, заведённый пробой, удаляется до
  гейта.
- **`out=$(cmd); echo $?` печатает код `tail`, а не команды** — коды гейта
  снимаются прямым прогоном, иначе красный прогон читается зелёным.
- **Условие `греп:` в маркере бэклога не терпит `|` внутри регэкспа**;
  слова «Как найдено» в теле секции — маркер провенанса и роняют
  `backlog-check.py`.
- **Heredoc `bash` рвётся на длинном русском markdown** — писать
  инструментом записи по частям и склеивать; точечная правка — через `py -`
  с проверкой единственности якоря.
- Прочие ловушки — снапшоты v283, v285-v342 §Ловушки; они не переписываются.
