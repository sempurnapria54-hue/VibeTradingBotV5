## Среда

Против v132 не изменилась; полное описание — там. Ловушки среды из v156-v201
остаются в силе, включая: полный гейт инструментов в 120 с не укладывается —
прогонять фоновой командой; рабочий бинарь — `py`; вывод `py` через пайп идёт в
cp1251 и рвётся на кириллице (`export PYTHONIOENCODING=utf-8`); перед всяким
`-P`-прогоном ставить `export LC_ALL=C.UTF-8`; длинный кириллический heredoc в
Bash рвётся — правки корпуса писать временным `.py`-файлом либо инструментом
записи файла; точечный прогон модуля идёт **из корня** (`-pl`), а не через `-f`;
`docker` под Git Bash требует `export MSYS_NO_PATHCONV=1`; `cd` внутри составной
команды Bash переносит рабочий каталог сессии.

**Ловушки этой сессии.**

- **Пустой операнд без приведения роняет запрос на стороне базы:** Postgres
  отвечает `could not determine data type of parameter $N`, и модульный тест
  этого не видит — репозиторий там подменён. Приведение (`cast(? as varchar)`)
  ставить у **каждого** необязательного операнда, а исход закреплять пробой
  связывания драйвером, а не чтением.
- **Публикация порта контейнера бывает запрещена диапазоном ОС:** `55432`
  отвергнут (`bind: An attempt was made to access a socket in a way forbidden by
  its access permissions`), `15433` принят. Пробовать другой порт, а не считать
  Docker сломанным.
- **Подменённый бин в кэшированном контексте spring-test живёт одну на все
  пробы.** Заданное одной пробой поведение достаётся следующей; сбрасывать в
  `@BeforeEach`, иначе проба мерит соседку.
- **Мутация может оставить счёт прежним, изменив его состав.** Обращение
  предиката «момент разрыва записан» дало у одной группы те же три дефекта,
  только другие; ловят такую мутацию пробы на **второй** группе. Батарея обязана
  мерить исход целиком, а не по одной пробе на мутацию.
- **`@JsonRawValue` на этом проводе работает, а `@Jacksonized` — нет**, и
  различает их пакет: аннотации `jackson-annotations` Jackson 3 сохранил,
  аннотации `databind` — переименовал. Довод пакетом не заменяет прогона: исход
  закреплён тестом поверхности.
