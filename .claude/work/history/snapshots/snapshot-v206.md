## Среда

Против v132 не изменилась; полное описание — там. Ловушки среды из v156-v205
остаются в силе, включая: полный гейт инструментов в 120 с не укладывается —
прогонять фоновой командой; рабочий бинарь — `py`; вывод `py` через пайп идёт в
cp1251 и рвётся на кириллице (`export PYTHONIOENCODING=utf-8`); перед всяким
`-P`-прогоном ставить `export LC_ALL=C.UTF-8`; длинный кириллический heredoc в
Bash рвётся — правки корпуса писать временным `.py`-файлом либо инструментом
записи файла; точечный прогон модуля идёт **из корня** (`-pl`), а не через `-f`;
`docker` под Git Bash требует `export MSYS_NO_PATHCONV=1`; `cd` внутри составной
команды Bash переносит рабочий каталог сессии; `/tmp` у Git Bash и у `py` —
разные каталоги; точечная правка JSON — заменой подстроки, а не
пере-сериализацией; инструмент записи файла перезаписывает существующий молча;
`-Dtest=...` требует `-Dsurefire.failIfNoSpecifiedTests=false`.

**Ловушки этой сессии.**

- **Вывод фоновой `py`-команды буферизуется до конца прогона.** Файл лога
  пуст, пока скрипт идёт: судить по нему о ходе нельзя, надо дожидаться
  завершения задачи.
- **Мутационный прогон по двум модулям останавливается на первом красном.**
  Пробы второго модуля при этом не исполняются вовсе, и в выдаче стои́т одна
  строка вместо двух — это свойство прогона, а не проба, оставшаяся зелёной.
- **Мутационная батарея жила временным скриптом и снята вместе с заходом:**
  `tools/` — дом объявленных проверок, а не разовой оснастки. Перечень проб и
  форма прогона остались в отчёте.
