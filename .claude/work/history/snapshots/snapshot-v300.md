## Ловушки

**Ловушки** v206-v299 остаются в силе. Новая этой сессии:

- **Жирный маркер внутри фразы рвёт шаблон свипа молча.** Текст
  `**до** тела метода` шаблоном `до\s+тела\s+метода` не берётся вовсе:
  выдача пуста, и пустота читается как «носителей нет». Свип по прозаической
  тропе чтения строится по **неразрывному** куску фразы (`тела метода`), а
  пустая выдача проверяется встречной формой прежде, чем на неё опереться.
- **Прошлая ловушка v299 подтвердилась дважды:** команда из носителя
  запускается **извлечением** блока (`re.findall` по ```` ```bash ````), а не
  переписыванием, и путь для `py` переводится `cygpath -w`.
- Прочие ловушки — снапшоты v283, v285-v299 §Ловушки; они не переписываются.
