  предикату свежести — отложено, горизонт «установившийся режим».

  не-settle-ccy движения по курсу на момент закрытия (вариант 1b).
- `AnomalyReport` — одна сущность, поведение по `severity`; severity
  **не** задаёт блокировку торговли.
- Серия неудач разведена: вход-сайд (мягкая) / управление-сайд
  (kill-switch адресен).
- Свежесть меряется у **обеих** половин резолва (ставка + ключ группы).
- Снапшот закрытия — in-memory, идемпотентность на уровне действия
  (именно эта правка породила узел 1).
