## Среда

Против v132 не изменилась; полное описание — там. Ловушки среды из v156-v195
остаются в силе, включая: полный гейт инструментов в 120 с не укладывается —
прогонять фоновой командой (`tools/spec-mutation-check.sh` один держит несколько
минут); рабочий бинарь — `py`; в regex-шаблонах для `tools/retired-check.py`
пользоваться `\s+` и делать их терпимыми к разметке; вывод `py` через пайп идёт в
cp1251 и рвётся на кириллице (`export PYTHONIOENCODING=utf-8`); перед всяким
`-P`-прогоном ставить `export LC_ALL=C.UTF-8`; `\w` у `grep -P` кириллицы не
берёт — классы писать явно (`[а-яё]+`); файл журнала фоновой команды писать в
`$TEMP`; длинный кириллический heredoc в Bash рвётся — правки корпуса писать
временным `.py`-файлом либо инструментом записи файла; многострочная правка
целится в текст **с его отступом**; точная подстановка проверяется счётом
вхождений до записи; ждать фоновый гейт холостым циклом нельзя.

**Ловушка этой сессии.** Точечный прогон одного модуля идёт **из корня** —
`mvn -o -q -pl services/<модуль> test`; форма `-f services/<модуль>/pom.xml`
разрешала бы зависимости из локального репозитория, то есть проверяла бы
предыдущую сборку. Мутационную пробу удобно ставить копией файла в `$TEMP` и
откатывать `cp` обратно: `sed -i` по исходнику с кириллицей в комментариях
работает, если шаблон целится в латиницу.
