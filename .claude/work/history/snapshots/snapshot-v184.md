## Среда

Против v132 не изменилась; полное описание — там. Ловушки среды из v156-v183
остаются в силе, включая: полный гейт инструментов в 120 с не укладывается —
прогонять фоновой командой; рабочий бинарь — `py` (`python3` и `python` из
PATH — заглушка, её код 49 читается как «не измерялось»); в regex-шаблонах
для `tools/retired-check.py` пользоваться `\s+`; импорт модуля из `tools/`
через `importlib` роняет `__pycache__` в корень репозитория, и
`tools/retired-check.py` отказывает кодом 2 на нём; `cd` внутри составной
команды Bash сохраняется между вызовами; форма `py - <<'PYEOF'` рвётся на
длинном markdown с таблицами — большой раздел писать инструментом записи;
вывод `py` через пайп идёт в cp1251 и рвётся на кириллице (`export
PYTHONIOENCODING=utf-8`); `bash`-heredoc рвётся на многокилобайтном русском
тексте; перенос строки в шаблоне `grep -P` пишется escape-последовательностью;
имя в командном блоке связывается **внутри** блока; в §-адресе имя файла
пишется рядом с адресом; `\b` с кириллицей заменяется на `(?![а-яё])`;
извлечение шаблона из файла якорится различающим началом; в снапшоте снятое
**называется**, а не цитируется; раздел новой единицы называется с её
маркером.

**Ловушка обратного слеша в `py - <<'PYEOF'`** (новая, из этой сессии):
литерал `'\\'` внутри heredoc-скрипта приходит к интерпретатору одиночным
слешем и рвёт строку `SyntaxError`. Рабочая форма — `os.sep` либо запись
скрипта в файл.

**Ловушка слепой линзы, идущей грепом** (новая, из этой сессии): запрет
чтения `.claude/work/progress/**` соблюдается только при **явном исключении
каталога в самой команде** — греп по корню репозитория возвращает строки
запрещённых файлов их содержимым. Линза A на этом и споткнулась; утечка
названа, но независимость одной находки от неё пострадала.
