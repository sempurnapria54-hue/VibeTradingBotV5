**Ловушки среды, на которые эта сессия наступила** (сверх трёх, названных
v155 и остающихся в силе).

1. **`/tmp` в Git Bash и `/tmp` для нативного Python — разные каталоги.**
   Bash пишет в `C:/Users/RomanKrd/AppData/Local/Temp`, а Windows-Python
   читает `C:\tmp`. Путь, переданный **аргументом**, bash конвертирует, и
   скрипт запускается; тот же путь **внутри** скрипта (`io.open('/tmp/…')`)
   не находится. Рабочая форма — `cygpath -m /tmp/…` перед передачей.
2. **`ur"…"` в Python 3 — синтаксическая ошибка**; сырые строки пишутся
   `r"…"`, юникод в py3 и так по умолчанию.
3. **Вставка элемента в кортеж перед `),` без запятой даёт неявную склейку
   строк**, а не новый элемент: `'a' 'b'` — одна строка. Прогон при этом
   зелёный, а элемент молча исчезает.
