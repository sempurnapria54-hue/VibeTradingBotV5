## Среда

Против v132 не изменилась; полное описание — там. Ловушки среды из v156-v186
остаются в силе, включая: полный гейт инструментов в 120 с не укладывается —
прогонять фоновой командой; рабочий бинарь — `py`; в regex-шаблонах для
`tools/retired-check.py` пользоваться `\s+`; `cd` внутри составной команды
Bash сохраняется между вызовами; форма `py - <<'PYEOF'` рвётся на длинном
markdown с таблицами — большой раздел писать инструментом записи; вывод `py`
через пайп идёт в cp1251 и рвётся на кириллице (`export
PYTHONIOENCODING=utf-8`); перед всяким `-P`-прогоном ставить
`export LC_ALL=C.UTF-8`; временный файл писать через `tempfile.gettempdir()`;
в §-адресе имя файла пишется рядом с адресом.

**Ловушки этой сессии (новые):**

- **Файл журнала фоновой команды писать в `$TEMP`, а не в корень.** Путь вида
  `/tmp_gate.log` отвергается «Permission denied», и команда падает кодом 2 —
  то есть исход гейта читается как «не измерялось», хотя ни один инструмент не
  прогонялся.
- **Искать в корпусе по слову со знаком ударения нельзя буквально.** «стои́т»
  несёт комбинирующий U+0301: `sed`/`grep` по «стоит» и по «стои́т»,
  набранному иначе, дают пустую выдачу, и правка читается как непрошедшая.
  Якорить пробу на соседнем слове без ударения.
- **Точная подстановка в текст с переносами строк проверяется счётом
  вхождений до записи.** Две правки этой единицы не нашли цели из-за
  выпавшего слова внутри переноса («Оба писателя», «называет его такой
  записью»); ассерт `count == 1` поймал обе, и файл не был записан ни разу
  частично.
