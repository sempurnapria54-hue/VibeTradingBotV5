# Слой сообщения и сведение общих артефактов

## На какой вопрос отвечает этот файл

Чем закрыта единица разделения слоя интеграции и сведения общих артефактов в
один дом.

## Единица и её заходы

Единица — запрос держателя целиком: отделить внутреннюю шину от интеграции с
внешним, свести общие артефакты в `services/common/` и сгруппировать модели по
слою. Развилки держатель разрешал по ходу — раскладка пакетов, дом общих форм,
глубина маппинга, имя каталога, группировка моделей.

| Заход | Состояние |
|---|---|
| разделение слоёв и сведение артефактов (корпусный) | `записан` — §«Классификация захода по родам» |

Заход один: корпус правится одной партией. Раунда критики у единицы этого рода
нет — её вердикт выносит гейт инструментов и сборка, а не сосед по мини-петле.

## Отправная метка и дельта захода

Метка — `445287fcc1d92b2a5cd0e1cf5f7861ef7bbd088c`. Рабочее дерево на входе в
сессию было чистым (`git status` пуст), поэтому меткой служит дерево `HEAD`, а
не отбитое `git write-tree`:

```bash
git rev-parse HEAD^{tree}
git diff --name-only 445287fcc1d92b2a5cd0e1cf5f7861ef7bbd088c
git diff -U0 445287fcc1d92b2a5cd0e1cf5f7861ef7bbd088c | grep '^+[^+]'
```

## Что сделано

- **Слой сообщения отделён от интеграции.** `integration` разделён на
  `internal/{event,api}` и `external/api` во всех шести сервисах, у которых
  этот пакет был; формы сообщений получили суффикс `Message`, свой пакет и
  мапперы. Дом правила — `.claude/rules/codestyle.md` §«Слой сообщения:
  внутренняя шина»; разбор альтернатив —
  `.claude/decisions/message-layer-split.md`.
- **Домен формы сообщения не строит и не читает.** Фабрики `*Content.of()`
  сняты, писатели факта уехали из `domain.event` в слой шины и получили
  доменную поверхность (`CoreEventWriter`, `StrategyEventWriter`).
- **Общие артефакты сведены в один дом.** Каталог `libs/` снят, его
  содержимое переехало под `services/common/`; модели сгруппированы и
  разведены по слою — `common/model/{domain,message}`.
- **Измерение приведено к новой раскладке.** Ось 1a снята вместе с каталогом;
  ось 1b опознаёт артефакт по `pom.xml`, а не по глубине; популяция
  `enum-domain-pointer-check` выводится теперь и из порождённых носителей.

## Свипы снятого

Формы старых имён после правки:

```bash
grep -rn "libs/" docs .claude/rules .claude/skills .claude/agents tools --include=*.md --include=*.py --include=*.sh
grep -rn "Content\.of(\|OutboxWriter\|common-model" --include=*.java --include=*.xml services
grep -rn "common/domain-model" docs .claude --include=*.md
```

Живых попаданий нет; остаются цитирования снятого как снятого — в
`docs/architecture/services.md` (довод, почему плоское имя заменено) и в
`.claude/work/decision-digest.md` (строки решений Д1473, Д1476, Д1478).

## Окрестность точек вставки

Носители, у которых в окрестности изменённых строк стои́т анафора, названы
поимённо; перечень выведен по метке, а не собран памятью:

- `.claude/rules/codestyle.md` — вставлен раздел §«Слой сообщения: внутренняя
  шина» и правлены соседние таблицы; анафоры окрестности проверены, адресность
  не сдвинута: ссылки соседних пассажей идут именами разделов, а не «ниже».
- `docs/architecture/contracts.md` — правлены пассажи о доме формы события;
  анафоры окрестности адресуют разделы того же файла и остались верными.
- `docs/models/domain/other/AuditRecord.md` — правлены два указателя на общий
  артефакт; текст вокруг не двигался.
- `docs/architecture/services.md` — переписана таблица общих артефактов и
  рационал под ней; анафоры («ниже», «здесь») адресуют ту же таблицу.
- `services/README.md`, `.claude/rules/structure.md` — переписаны клаузы о
  `common/`; анафор в окрестности не осталось.
- `.claude/decisions/monorepo-restructuring-in-place.md` — в таблице скелета
  помечено, что каталог `libs/` снят; анафора «(ниже)» соседней строки
  адресует пассаж того же файла об уцелевшем, и правка её не двигала.
- `.claude/rules/knowledge-ownership-by-service.md` — переименованы владельцы
  общих артефактов; анафоры окрестности («там же», «ниже») адресуют строки
  той же карты и остались верными: строки не переставлялись, менялись имена
  владельцев в клетках.
- `.claude/skills/update-roadmap-progress.md` — из команды дельты убран
  `libs/`, и переписан пассаж о числе деревьев; анафоры окрестности
  («следующая», «выше», «предыдущую») адресуют разделы гейта и соседние
  абзацы того же файла, разделы не переставлялись.
- `.claude/work/history/snapshots/snapshot-v242.md` — переписан указатель на
  отчёт межшагового окна, после чего снимок сменён на v243 и уехал в архив

## Регресс

всю единицу (1256 на входе и на выходе), то есть охрана не потеряна.

мерят область `.claude/work/progress/**` и при пустой области отказывают кодом
2; этот отчёт — её носитель.
