## На какой вопрос отвечает этот файл

Чем закрыты находки прогона `DOCS_CHECK_1` шага 8 фазы 2.

## Вход и метод

- Отчёт прогона — `phase-2-step-8-docs-check-1.md`: 10 находок, 9 гейтящих,
  8 узлов закрытия (A6 и B1 закрываются одним ходом).

  (`.claude/templates/docs/gap-report.md` §«Классификация и направление
  правки»). Кодовая дельта не пишется этим закрытием, а объявлена

  `.claude/skills/closure-population.md`; носительская ось у каждого узла
  обязательна.
- Собственные артефакты закрытия перечитаны как текст (§6 того же
  скилла); что это дало — §«Мини-петля критики», узел 6.

# Популяции гейтящих узлов

## Узел 1 (A1). Идентичность контекста определения

**Правило узла.** Контекст определения стратегии — тенант, биржевой счёт,
инструмент — называется **идентичностями** (`internalId`), а не числовыми
ключами чужой базы.

**Ось 1 — поля-идентичности корня определения.** Команда вывода:

```bash
sed -n '/^## Strategy (корень)/,/^`Status`/p' docs/models/domain/aggregate/Strategy.md
grep -n 'private ' libs/domain-model/src/main/java/com/example/tradingbot/domain/model/aggregate/strategy/Strategy.java
```

| Член | Исход |
|---|---|
| `id` | **правило выполняется**: собственный технический ключ, границу не пересекает — его не публикуют ни событие, ни api (`docs/architecture/data-ownership.md` §Идентификаторы) |
| `internalId` | **правило выполняется**: собственная идентичность, строка |
| `exchangeAccountId` → `exchangeAccountInternalId` | **правлено закрытием**: тип и значение сменились на идентичность счёта (`docs/models/domain/aggregate/Strategy.md` §«Strategy (корень)») |
| `instrumentId` → `instrumentInternalId` | **правлено закрытием**: то же у инструмента |
| тенант (поля не было) | **правлено закрытием**: заведён `tenantId` — таблица определения тенантная, а конверт события несёт тенанта ключом партиции |
| `name`, `status`, `marketPhaseSetting`, `details`, `indicatorSettings`, `marketStructureSettings` | **правило выполняется**: идентичностями чужих сущностей не являются — ни одно поле чужой строки не адресует |

**Ось 2 — носители.** Команды (обе терпимы к переносу строки):

```bash
LC_ALL=C.UTF-8 grep -rlUP '(?s)(exchangeAccountId|instrumentId)' docs/ --include=*.md --include=*.json \
  | xargs grep -lUP '(?s)(strategy|Strategy|стратеги)'
LC_ALL=C.UTF-8 grep -rlUP '(?s)ключ\s+строки\s+(торгового\s+состояния\s+счёта|проекции\s+инструмента)\s+в\s+базе\s+ядра|резолвится\s+по\s+счёту'

LC_ALL=C.UTF-8 grep -rlUP '(?s)(exchangeAccountId|instrumentId)' services/ libs/ --include=*.java --include=*.sql | grep -v /target/
```

| Носитель | Исход |
|---|---|
| `docs/models/domain/aggregate/Strategy.md` | **правлен**: состав корня + два новых пассажа («Контекст называется идентичностями…», «Числовые ссылки живут у копии…») |
| `docs/models/mapping/Strategy.md` | **правлен**: резолв идентичности в число переехал с границы api ↔ domain на границу domain → persistence **копии**; снятая редакция названа |
| `docs/architecture/data-ownership.md` | **не требует правки**: §Идентификаторы и есть дом правила, и он не менялся — менялся носитель, который ему подчинён |

| `docs/models/domain/aggregate/Deal.md`, `docs/models/domain/other/AnomalyReport.md`, `DealCashFlow.md`, `TradeFeeRate.md`, `docs/models/domain/core/BalanceContainer.md`, `docs/spec/cash-flow-linkage.json` | **не требуют правки — и это существенно**: их `exchangeAccountId` числовой законно, потому что строка живёт **внутри** базы ядра и границы не пересекает. Правка «под гребёнку» сломала бы шесть верных носителей |
| `docs/components/EntryScannerJob.md` | **не требует правки**: «читает активную стратегию пары «счёт, инструмент»» верно и после правки — отбор входа читает **копию** по её числовым колонкам |
| `docs/architecture/tenant-and-exchange.md` §«Всякая корневая торговая строка ядра называет биржевой счёт» | **не требует правки**: клейм о строках **ядра**; копия счёт называет, форма ссылки правилом не задана |
| `docs/models/domain/other/CandleGroup.md`, `IndicatorValue.md`, `MarketPhase.md`, `MarketStructure.md`, `docs/models/mapping/InstrumentExternalRules.md`, `MarketPriceData.md`, `TradeFeeRate.md` | **не потребители**: `instrumentId` там — ключ строки внутри базы `market-data` либо ядра, к определению стратегии отношения не имеет |
| `libs/domain-model/.../strategy/Strategy.java`, `services/trading-core/.../StrategyIntakeService.java`, `StrategyEntity.java`, `StrategyRepository.java`, `StrategyDataService.java` | **кодовая дельта**, объявлена в `.claude/work/backlog.md` §«Шаг 8 фазы 2 — CODE-дельта идентичностей и статуса копии»: до `CODE` ведёт док |

**Исполнимая форма оси.** Ось значений здесь **не выразима спекой**:
предмет — тип и смысл поля, а не вычислимая величина; ни одного счётного
клейма узел не вводит. Механический якорь у неё другой и он есть:
популяция реестра `tools/retired-check.py`, запись «радиус торговой
строки», строка `docs/models/domain/aggregate/Strategy.md` переведена с
шаблона пришедшей редакции `exchangeAccountId` на
`exchangeAccountInternalId` — потеря идентичности в этом носителе роняет
прогон.

**Почему отдельной записи снятой редакции у узла нет — названо явно.**
Снятая форма («поле `Long` со значением ключа строки в базе ядра»)
**неотличима плоским текстом** от законной: теми же словами и той же
табличной строкой пользуются шесть носителей ядра, где число верно.
Запись в реестр дала бы шесть ложных дефектов на верных носителях; ось
закрыта перечнем выше плюс переведённой строкой популяции.

## Узел 6 (A6 + B1). Состав проверок активации

**Правило узла.** Класс проверок, объявленный линией реза, имеет
перечисленный состав и механический признак включения в него.

**Ось 1 — предусловия активации.** Перечень выводится **из предмета**:
что обязано быть истинно, чтобы разрешение торговать не было
заявлением. Команда добычи кандидатов:

```bash
sed -n '/^## Исключения: неравенства/,/^## Что проверяется на активации/p' docs/rules/strategy-validation.md
LC_ALL=C.UTF-8 grep -rn 'пуст\w* ⇒\|пустое место' docs/rules/risk-policy.md
```

| Член (кандидат) | Исход |
|---|---|
| допустимость перехода | **правило выполняется**: держит `Strategy.canTransitionTo`, названо в доме цикла |
| единственность `ACTIVE` на паре | **правило выполняется**: проверка приложения плюс `uk_strategy_active_per_account_instrument` |
| существование счёта и инструмента в контексте тенанта | **правлено закрытием**: класс «ссылка определения не разрешается» |
| назначенность чисел риск-аппетита тенанта | **правлено закрытием**: класс «операнд проверки не добыт» |
| пять неравенств на текущих числах | **правлено закрытием**: класс «проверка определения с внешним операндом» |
| ступень лестницы у счёта либо пары | **выведен из популяции с названной причиной**: состояние контура, снимаемое своей тропой и само возвращающее торговлю; запрет пережил бы основание |
| `SUSPENDED` тенанта | **выведен по той же причине** |
