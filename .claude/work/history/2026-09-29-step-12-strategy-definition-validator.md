# Валидатор определений стратегии: доля дистанции, источник уровня, перечни клаузы фазы, код и текст отказа

## На какой вопрос отвечает этот файл

Что сделано по связке секций бэклога о валидаторе создания определения
стратегии.

  (`STRATEGY_LEVEL_SOURCE_NOT_DECLARED`);

- **код** незаданного числа риск-аппетита — `STRATEGY_RISK_APPETITE_NOT_CONFIGURED`,

  `ValidationFixture` вернулся к разрезу по разделителю;
