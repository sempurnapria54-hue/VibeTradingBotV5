## Детектор стагнации

| Сигнал | Замер | Сработал |
|---|---|---|
| С1 — узел возвращается после собственного закрытия | узел разделения дока вернулся третий раз (P4 → Q2 → R1), каждый раз **новым разделом того же файла**; решение не оспаривалось ни разу | **сработал по форме, назван; эскалация не выпускается — см. ниже** |
| С2 — закрытие даёт находок столько же, сколько закрывает | `GAPS_CLOSE_2` закрыл 2, `DOCS_CHECK_3` дал 1 | нет |
| С3 — стоимость прогонов не убывает | 11 → 3 → 2 KB; находок 5 → 2 → 1, гейтящих 3 → 0 → 0 | нет |
| С4 — перебор второй раз подряд неполон | развилок нет | нет |

**Почему эскалация не выпускается.** Диагноз известен и устраняется не
итерацией, а **исчерпыванием разделов**: файл конечен, разделов в нём
восемь, и после этой правки помечены все. Проверяется следующим
прогоном: даст он по этому узлу четвёртую находку — диагноз «перечитывание
не помогает» подтвердится и эскалация выпускается без обсуждения.
