# donor/

## На какой вопрос отвечает этот файл

Что лежит в этом каталоге. Условия, на которых он живёт, — атрибут
ответа.

Монолит фазы 1 целиком — торговля одной стратегией на OKX по одному
инструменту. В монорепозитории он **источник порта, а не единица
развёртывания**: его содержимое расходится по сервисам
`docs/architecture/services.md` шагами 3-10 фазы 2, и каталог исчезает,
когда последний из них закончен.

Условия, пока он жив:

- **Собирается и зелёный.** Из него портируют, и порт сверяется с
  работающим оригиналом, а не с воспоминанием о нём. Живой контур
  источника (`integration.sourceapi.okx.*LiveTest`) требует Vault, OKX и
  postgres-test и в общий прогон не входит.
- **Новой способности здесь не появляется.** Всё новое пишется в
  `services/` и `libs/`.
- **Схема донора — история.** У каждого сервиса своя цепочка миграций
  с `V1` (`.claude/rules/pre-launch-schema-changes.md`).

Почему каталог называется `donor/`, а не именем сервиса —
`.claude/decisions/monorepo-restructuring-in-place.md` §«Почему донор —
`donor/`, а не каталог внутри `services/`».
