# План развития AI-агентов и торгового бота

# Правила планирования

- Стартовая дата плана: **01.05.2026**.
- Рабочая доступность: **15 часов в неделю**.
- Стартовый депозит: **$500**, вносится частями и резервируется под production-проверку.
- До завершения **Вехи 1** ежемесячного пополнения проекта нет.
- После успешной Вехи 1 доступен проектный бюджет: **$500/мес**.
- Пессимистичный сценарий: **бот ничего не приносит, но и не теряет**.
- По ценам в расчётах используется верхний порог.
- Если $500/мес недостаточно для перехода к следующему этапу, в плане явно указывается нужное дополнительное вливание.
- Для крупных расходов в евро используется грубое плановое допущение: **1€ ≈ $1.10**. Перед покупкой пересчитать по фактическому курсу.

Для каждого этапа используется формула:

```text
свободный приток = $500/мес - обязательные текущие расходы
дефицит = max(0, стоимость этапа - бюджет на начало)
ожидание бюджета = дефицит / свободный приток
итоговая длительность = max(время работы, ожидание бюджета)
```

Важно: Веха 1 финансируется только стартовым депозитом и текущими уже оплаченными инструментами. Ежемесячный проектный бюджет начинается только после доказательства состоятельности бота в production-обкатке.


# Типы агентов и правила использования

Агент в плане описывается не только названием роли. Полная модель:

```text
Агент = роль + тип развёртывания + доступ к контексту + права действий
```

## Chat-agent

- **Где работает:** отдельный чат.
- **Контекст:** вручную переданный prompt, выдержки из документации, diff, куски кода, ошибки, логи.
- **Где хранится контекст:** в проектных документах, `AGENTS.md`, `docs/context`, `decision-log`; в чат передаётся только нужный фрагмент.
- **Права:** обсуждает, подсвечивает риски, предлагает сценарии тестирования, помогает формулировать задачи.
- **Запрет:** не меняет код, не видит локальный проект сам, не фиксирует архитектурные решения без подтверждения пользователя.

## Local API-agent

- **Где работает:** локальный `agent-runner` на машине пользователя.
- **Контекст:** локальная кодовая база, docs, `AGENTS.md`, git diff, build/test output, логи.
- **Где хранится контекст:** локальный проект; агент собирает временный prompt и отправляет его во внешнюю модель через API.
- **Права:** читает проект, собирает контекст, вызывает внешнюю модель, сохраняет отчёты.
- **Запрет:** не меняет код без отдельного разрешения.

## Local-only agent

- **Где работает:** локально на локальной модели.
- **Контекст:** локальные документы, локальный индекс, RAG, часть проекта.
- **Права:** поиск, суммаризация, классификация, черновой анализ.
- **Запрет:** не принимает критичные архитектурные/финансовые/production-решения.

## Codex-agent / Tool-agent

- **Где работает:** через Codex или аналогичный coding tool.
- **Контекст:** репозиторий, task prompt, `AGENTS.md`, связанные документы, тесты.
- **Права:** может менять код и запускать тесты в рамках конкретной задачи.
- **Запрет:** не принимает архитектурные решения; результат обязательно проходит review.

## Cloud-agent

- **Где работает:** во временной cloud-среде.
- **Контекст:** временно загруженный проект, configs, datasets, модели, task input.
- **Где хранится контекст:** источник истины остаётся локально; cloud-сервер не является постоянным хранилищем.
- **Права:** выполняет тяжёлую задачу, сохраняет результат, после работы сервер уничтожается.

# Ключевой финансовый вывод

До завершения Вехи 1 проект живёт без ежемесячных пополнений: доступен только стартовый депозит $500, который не тратится на инфраструктуру, а резервируется под production-проверку.

После Вехи 1 появляется бюджет $500/мес. Этого достаточно для постепенной оплаты cloud production и небольших экспериментов, но недостаточно для быстрых крупных покупок вроде MacBook за 7 000€ или мощного сервера за 10 000€. Для таких переходов в плане указываются дополнительные вливания.
