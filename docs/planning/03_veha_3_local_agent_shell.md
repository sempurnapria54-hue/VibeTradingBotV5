# Веха 3. Локальная агентная оболочка без локальных моделей

Цель вехи — автоматизировать работу полезных AI-ролей через локальную оболочку, но пока без локальных LLM. Модель остаётся внешней, контекст собирается локально.

| Этап | Название | MIN | BASE | MAX | Верхний расход |
| --- | ---: | ---: | ---: | ---: | ---: |
| 3.1 | Структурировать проект под агентов | 1 нед. | 2 нед. | 3 нед. | $0 |
| 3.2 | Простой agent-runner | 3 нед. | 6 нед. | 10 нед. | до $100/мес API при автоматизации |
| 3.3 | Reviewer v2 | 2 нед. | 4 нед. | 7 нед. | до $100/мес API при активном review |
| 3.4 | Multi-agent workflow | 3 нед. | 6 нед. | 11 нед. | до $100/мес API при активной автоматизации |

## Этап 3.1. Структурировать проект под агентов

### Цель

Подготовить структуру проекта для будущих агентов и повторяемых workflows.

### Что делаем

- Создать /agents.
- Создать /prompts.
- Создать /codex/tasks.
- Создать /docs/context.
- Создать /decision-log.
- Создать /runbooks.
- Создать /reports.

### Результат этапа

Контекст проекта разложен так, чтобы его могли использовать Chat-agent, Local API-agent и Codex-agent.

### AI-support

| Агент | Тип | Контекст | Права |
| --- | ---: | ---: | ---: |
| Architecture discussion agent | Chat-agent | Текущие доки, спорные вопросы, модели, ограничения | Обсуждает варианты и последствия; не фиксирует решения без пользователя |
| Codex task builder | Chat-agent | Утверждённое решение, ограничения, структура проекта | Готовит coding task/prompt для Codex |
| Reviewer v1 | Chat-agent | Переданный diff, файл, ошибка сборки или кусок кода | Проверяет только переданный контекст |

### Финансы

**Верхний расход этапа:** $0.

Расходов нет. Если cloud production уже работает, текущие расходы до $330/мес продолжаются.

## Этап 3.2. Простой agent-runner

### Цель

Сделать простой локальный agent-runner, который собирает контекст и ходит к внешней модели через API.

### Что делаем

- Читать config агента.
- Собирать контекст.
- Формировать prompt.
- Вызывать API внешней модели.
- Сохранять результат локально.

### Результат этапа

Появляется Local API-agent как повторяемый механизм, а не ручное копирование контекста в чат.

### AI-support

| Агент | Тип | Контекст | Права |
| --- | ---: | ---: | ---: |
| Architecture discussion agent | Chat-agent | Текущие доки, спорные вопросы, модели, ограничения | Обсуждает варианты и последствия; не фиксирует решения без пользователя |
| Test-case agent | Chat-agent | Описание фичи, бизнес-правила, статусы, команды | Предлагает сценарии тестирования: unit, integration, recovery, edge cases |
| Codex task builder | Chat-agent | Утверждённое решение, ограничения, структура проекта | Готовит coding task/prompt для Codex |
| Local API reviewer | Local API-agent | git diff, docs, AGENTS.md, build/test output | Читает проект, формирует review report, код не меняет |

### Финансы

**Верхний расход этапа:** до $100/мес API при автоматизации.

Верхний сценарий учитывает до $100/мес API. При cloud $330/мес свободный приток после cloud+API ≈ $70/мес.

## Этап 3.4. Multi-agent workflow

### Цель

Сделать multi-agent workflow для сложных задач.

### Что делаем

- Один запрос.
- Несколько ролей.
- Сравнение выводов.
- Итоговый summary.
- Финальная задача для Codex.

### Результат этапа

Можно прогонять задачу через несколько ролей без ручного копирования в разные чаты.

### AI-support

| Агент | Тип | Контекст | Права |

| Risk/edge-case agent | Chat-agent | Описание flow, FSM, команд, recovery, kill-switch | Ищет опасные сценарии, рассинхроны, recovery-проблемы |
| Test-case agent | Chat-agent | Описание фичи, бизнес-правила, статусы, команды | Предлагает сценарии тестирования: unit, integration, recovery, edge cases |
| Codex task builder | Chat-agent | Утверждённое решение, ограничения, структура проекта | Готовит coding task/prompt для Codex |
