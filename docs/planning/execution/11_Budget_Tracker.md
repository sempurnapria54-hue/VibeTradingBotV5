# 11. Budget Tracker

## Правила бюджета

- Стартовый депозит: **$500**.
- До завершения Вехи 1 регулярного пополнения **$500/мес нет**.
- После завершения Вехи 1 регулярное пополнение: **$500/мес**.
- Пессимистичный сценарий: бот ничего не приносит, но и не теряет.
- При расчётах использовать верхний порог расходов.
- Обязательные текущие расходы вычитаются из ежемесячного притока.

## Формула ожидания бюджета

```text
Свободный приток = $500/мес - обязательные текущие расходы
Дефицит = max(0, стоимость этапа - свободный бюджет на начало)
Ожидание бюджета = дефицит / свободный приток
```
