## Этап 4.1. Эксперименты с локальными моделями

### Цель

Проверить, что можно делать локальными моделями на текущем ПК.

### Что делаем

- Запустить Ollama/LM Studio.
- Проверить маленькие coder-модели.
- Проверить embeddings.
- Проверить RAG по документации.
- Оценить скорость и качество.

### Результат этапа

Понятно, какие локальные задачи текущий ПК реально тянет.

### AI-support

| Агент | Тип | Контекст | Права |

| Local RAG/Search agent | Local-only agent | Локальные docs, индекс, embeddings | Ищет, суммаризирует, классифицирует |
| Test-case agent | Chat-agent | Описание фичи, бизнес-правила, статусы, команды | Предлагает сценарии тестирования: unit, integration, recovery, edge cases |

## Этап 4.2. Разделение задач между local/external/cloud/server

### Цель

Разделить задачи между локальными моделями, внешними моделями, cloud lab и будущим сервером.

### Что делаем

- Составить список задач.
- Оценить качество local-only.
- Оценить стоимость API.
- Оценить необходимость cloud ephemeral lab.
- Оценить необходимость домашнего сервера.

### Результат этапа

## Этап 4.3. Мелкий апгрейд при необходимости

### Цель

Сделать мелкий апгрейд текущего ПК только если он переиспользуем и полезен.

### Что делаем

- Оценить SSD.
- Оценить RAM.
- Купить только переиспользуемые компоненты.
- Не покупать дорогой GPU в текущий ПК.
