# OKX contracts: open interest

## На какой вопрос отвечает этот файл

Каков контракт операции чтения открытого интереса контрактов
(`open-interest`).

## Внешний источник правды

Дистиллят официального дока OKX (`https://www.okx.com/docs-v5/en/`,
раздел «Public Data → REST API», секция «Get open interest»). При
расхождении с офдоком побеждает офдок; синхронизация — перевыкачка +
дифф при каждом заходе интегратора по источнику и по задаче
«актуализируй» (`.claude/processes/api-docs-completion.md`, канал
чтения — `.claude/skills/integration-okx.md`). Последняя сверка:
2026-06-11 (прогон 3, поле-уровневая дистилляция). Рантайм-сверка:
2026-06-19 (контур source-api, demo — рантайм-заметка в
/api/v5/public/open-interest; провенанс `рантайм`).

## Статус использования

Не используется (в периметре как рыночный контекст; потенциальная
связь — позиционный лимит как доля открытого интереса, форвард к риску на
биржу/портфель, фаза 3, `docs/rules/risk-policy.md`).

## GET /api/v5/public/open-interest

Rate limit 20 req / 2 s по IP + Instrument ID. Query: `instType`
(обяз.: SWAP/FUTURES/OPTION), `instFamily` (обяз. для OPTION),
`instId` (опц.).

**Рантайм (2026-06-19, demo, контур source-api / PG5):** `instType`
фактически **необязателен при заданном `instId`** — запрос
`?instId=ETH-USDT-SWAP` без `instType` вернул `code=0` с корректным
элементом (`instType` выводится из `instId`). Офдок помечает `instType`
обязательным — расхождение зафиксировано прогоном (провенанс
`рантайм`). Сопутствующие негативы: битый `instType` → реджект `51000`;
несущ. `instId` → `51001`.

### Response (элементы `data[]`)

| Поле | Семантика |
|---|---|
| `oi` | Открытый интерес в контрактах. |
| `oiCcy` | Открытый интерес в монетах. |
| `oiUsd` | Открытый интерес в USD. |
| `instType` / `instId` | Идентификация. |
| `ts` | Время данных. |
