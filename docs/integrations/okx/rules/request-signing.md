# Подпись приватного запроса OKX

## На какой вопрос отвечает этот файл

Из чего источник требует собирать подпись приватного REST-запроса.

## Источник правды вне репозитория

Официальный док OKX (`https://www.okx.com/docs-v5/en/`, раздел «Overview
→ REST Authentication», секции «Making Requests» и «Signature»).
Процедура сверки и приоритет офдока —
`.claude/rules/external-source-sync.md`. Последняя сверка: 2026-09-29
(форма prehash, заголовки, формат и окно метки времени).

## Правило

**Всякий приватный запрос несёт четыре заголовка, и один из них —
подпись, которую источник пересчитывает сам.** Запрос, чья подпись не
совпала с пересчётом источника, отвергается целиком, какой бы ни была
операция.

| Заголовок | Что несёт |
|---|---|
| `OK-ACCESS-KEY` | ключ API счёта |
| `OK-ACCESS-SIGN` | подпись запроса — форма ниже |
| `OK-ACCESS-TIMESTAMP` | метка времени запроса — формат ниже |
| `OK-ACCESS-PASSPHRASE` | passphrase, заданная при заведении ключа |

**Подписываемая строка (prehash)** — конкатенация четырёх частей без
разделителей:

```text
prehash = timestamp + method + requestPath + body
sign    = base64( HMAC-SHA256( secretKey, prehash ) )
```

- **`timestamp`** — то же значение, что в `OK-ACCESS-TIMESTAMP`: UTC в
  ISO 8601 с миллисекундами, например `2020-12-08T09:08:57.715Z`.
- **`method`** — метод запроса **в верхнем регистре** (`GET`, `POST`).
- **`requestPath`** — путь эндпоинта, например `/api/v5/account/balance`;
  **параметры `GET` входят в путь**, а не в тело: `?` и query-строка в том
  виде, в каком ушли в запросе.
- **`body`** — тело запроса строкой; у запроса без тела — пустая строка.

**Метка времени живёт 30 секунд.** Источник отвергает запрос, чья метка
расходится с его часами больше чем на 30 секунд, кодом `50102`; запрос
истекает через 30 секунд после метки. Отказ по этому коду — дефект нашей
стороны, а не отказ в кредах (`docs/integrations/okx/rules/auth-rejection-codes.md`);
эталон для сверки часов — `docs/integrations/okx/contracts/server-time.md`.

**Контур в подпись не входит.** Заголовок демо-контура стоит на запросе
рядом с подписью и в prehash не участвует; чей он и на каких запросах
стоит — `docs/integrations/okx/contracts/service-urls.md`.

## Где применяется

Подпись ставит подписывающий клиент коннектора, собираемый на ключи
конкретного счёта (`OkxSignedRestClientFactory`, перехватчик
`OkxSigningInterceptor`); ключи он берёт по адресу счёта
(`docs/architecture/tenant-and-exchange.md`). Публичный клиент запросов не
подписывает: ключей у публичного чтения нет
(`docs/components/IntegrationService.md`).
