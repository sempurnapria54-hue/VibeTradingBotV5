# Классификация runtime-ошибок

## На какой вопрос отвечает этот файл

Как классифицируются неожиданные runtime-ошибки.

## Правило

Неожиданные исключения — технические ошибки runtime-flow: в
`CalculationError` и в результат риск-проверки они не превращаются. Их
ловит граница исполнения и классифицирует тремя кодами
`RuntimeErrorCode`:

| Код | Что это | Retryable |
|---|---|---|
| `INTERNAL_ERROR` | баг приложения, неожиданное состояние | нет |
| `EXCHANGE_ERROR` | сбой взаимодействия с биржей: таймаут, обрыв, ошибка API | да |
| `VALIDATION_ERROR` | нарушение инварианта, не должное дойти до runtime | нет |

`EXCHANGE_ERROR` — общий код: отдельных «неизвестный результат» и
«таймаут» нет, и отдельной ветки FSM по нему тоже. Каждый проход сперва
обновляет факты биржи, затем анализирует состояние.

## Отказ источника в наших кредах изъят из ретраибельного

**Отвергнутые креды — подпись не принята, ключ отозван, passphrase не та,
доступ приостановлен — классифицируются `EXCHANGE_ERROR`, но из его
ретраибельности изымаются.** Повтор помогает там, где отказ **транзиторен**;
отвергнутый ключ от повторения принятым не станет — бюджет истратится и
кончится тем же исходом, только позже и при живых позициях.

**Дом изъятия — здесь, потому что изъятие есть правило классификации.**
Оно говорит, что делает с классом граница исполнения, а не что становится
с биржей; последствие — биржевая ступень 2 кодом
`EXCHANGE_CREDENTIALS_REJECTED` — живёт в доме лестницы
(`docs/rules/exchange-hold.md`), и там же названо ограничение
исполнимости реакции. Прежде изъятие стоя́ло только в доме лестницы: дом
классификации о нём не знал, и правило «`EXCHANGE_ERROR` ретраибелен»
читалось как безусловное.

**Признак изъятия — грунт.** По какому коду и HTTP-статусу источника отказ
опознаётся, корпус не знает; до сбора факта резолвер не пишется
(`.claude/work/backlog.md`, S0 — перечень auth-отказов источника). Пока
факта нет, изъятие объявлено, но не энфорсится — и это
названо, а не умолчано.

**Плановая ротация в класс не попадает:** она идёт при доказанном
отсутствии живого риска и окна не создаёт; дом процедуры и её предусловия
— пайплайн (`.claude/work/backlog.md`, S1 хардненинга секретов). Класс
остаётся для **непреднамеренного** отказа.

## Реакция

```text
Deal → ERROR → safety-flow
если ошибка связана с действием:
    retryable EXCHANGE_ERROR → строка исполнения RETRY_PENDING
    INTERNAL_ERROR / VALIDATION_ERROR → строка исполнения FAILED
```

Это уровни 1-2 внутренней градации; уровни 3-4 — холд инструмента и
биржевая лестница.
