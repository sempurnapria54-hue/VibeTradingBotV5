# Иерархия исполнения торговли

## На какой вопрос отвечает этот файл

Какова иерархия уровней исполнения торговли.

## Правило

Торговля исполняется по фиксированной вертикали; каждый уровень видит
только соседний.

1. **Торговля идёт по стратегии.** Вне стратегии торговых решений нет.
2. **В стратегии — условия и действия:** когда и что делать.
3. **При выполнении условий исполняется `StrategyAction`** — единица
   исполнения уровня стратегии.
4. **`StrategyAction` состоит из команд.** Цепочку заранее никто не
   создаёт: за проход эмитится одна актуальная атомарная команда по
   свежим фактам.
5. **Команда рефреша вправе сходить на биржу столько раз, сколько нужно,
   чтобы добыть факт.** Атомарность не означает «один запрос».

Стратегия не знает про команды, команда не знает про условия стратегии;
биржевые вызовы — деталь конкретной команды.

## Что вне иерархии

Иерархия управляет **созданием торгового намерения**. Снятие риска ей не
подчинено: иначе защитный механизм был бы блокируем тем же контролем, что
и вход.

- **Системные действия** — добыча фактов, финализация, аварийное
  завершение: та же командная механика, но вне стратегии.
- **Kill-switch** — аварийное сворачивание вне реестра команд.
- **Риск-снижающие дочистки** обработчиков — teardown условия перехода,
  аварийное снятие риска, реакция сопровождения.

**Снятие защиты исключением не является:** оно риск не снимает, а
увеличивает, и проходит преконтроль
(`docs/rules/live-risk-protection.md`).
