# Сырой DTO источника не выходит за границу интеграции

## На какой вопрос отвечает этот файл

Какое правило ограничивает распространение сырых DTO источника по слоям.

## Правило

**Сырой ответ источника не выходит за `IntegrationService`.** Наружу
выходит только нормализованный граничный снапшот `*ExternalSnapshot`.

`IntegrationService` получает сырой ответ, проверяет структуру,
обязательные поля и инварианты контракта источника и маппит в снапшот
только те поля, которые обновляют доменную модель. Поля, нужные лишь для
проверки, в снапшот не попадают.

**Снапшот несёт external-поля без доменных перечислений и нормализаций** —
они резолвятся при материализации.

**У каждой сущности, пересекающей границу, снапшот есть.** Цепочка
«сырой ответ → доменная модель» напрямую не допускается: она выводит за
границу persisted-модель с незаполненными обязательными полями. Состав
транзитного снапшота живёт в mapping-доке своей сущности; отдельный файл
заводится только при самостоятельном содержании.

## Контракт чтения

```text
снапшот найден            → *ExternalSnapshot
успешно, но не найдено    → null
ошибка API/разбора/инварианта → исключение
```

`null` означает «не найдено в этом источнике», а не ошибку; трактовка
зависит от сущности.

**Исключение — баланс.** Успешный рефреш обязан вернуть валидный снапшот
с обязательной расчётной валютой; пустой ответ, отсутствие валюты или
негодные поля дают контролируемую ошибку, а не `null`.
