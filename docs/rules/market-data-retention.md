# Retention результатов расчёта рыночных данных

## На какой вопрос отвечает этот файл

Какое у нас правило хранения/чистки результатов расчёта рыночных данных
(индикатор / структура / фаза).

## Правило

Результаты расчёта рыночных данных (`IndicatorValue`, `MarketStructure`,
`MarketPhase`) **не чистятся** — политик удаления / обрезки истории сейчас
не вводим. Все три типа хранят историю рядом строк (строка на свечу /
окно), а не upsert одной строки.

Основание: данных для решения о глубине хранения нет — **нет потребителя
истории**, который задал бы нужную глубину. Вводить retention-политику
превентивно — спекулятивно (инфраструктура от потребности, не на пустом
месте).

## Якорь пересмотра

Когда появится **потребитель истории** результатов (бэктест / аналитика /
иной), вернуться к политике retention и определить глубину/чистку под его
потребность.
