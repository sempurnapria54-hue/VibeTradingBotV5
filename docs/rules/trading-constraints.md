# Ограничения торгового контура

## На какой вопрос отвечает этот файл

Каковы ограничения торгового контура.

## Контур

| Ограничение | Значение |
|---|---|
| площадка | OKX |
| тип контракта | SWAP, **только линейные** (`ctValCcy = baseCcy`) |
| средства | только свои: без заёмных, без долга |
| режим маржи | isolated |
| плечо | ручная статичная настройка инструмента |
| инструменты | в фазе 1 торгуется один |
| позиции | не более одной на инструмент |
| сделки | не более одной активной на инструмент |
| валюта комиссии | только расчётная валюта инструмента |

**Только линейные контракты — потому что весь сайзинг и весь расчёт `R`
построены на линейной формуле** `убыток = |вход − стоп| × контракты ×
ctVal`. У инверсного контракта она другая. Энфорс — реджект на заведении
инструмента; горячий путь не трогается. Ограничение записано и здесь: при
инструменте, заведённом мимо нашей тропы, `R` неверен молча.

**Плечо системного потолка не имеет:** оно связано потолком риска (больше
плечо при том же стопе ⇒ больше размер ⇒ больше убыток на стопе ⇒ упор в
потолок). Единственный жёсткий предел — биржевой максимум инструмента.
Названная цена принята: посылка «ликвидация за стопом» держится
дисциплиной оператора, а наблюдаемость даёт
`Order.liquidationDistanceRatio`.

**Экспозиция сделки потолок имеет.** Суммарный номинал ограничен
катастрофическим потолком сделки (`docs/rules/risk-policy.md`), поэтому
эффективное плечо к базе риска сверху связано им — не настройкой плеча.

**Один инструмент — ограничение контура, а не наблюдение:** гейт входа
проверяет отсутствие активной сделки **по всему контуру**. На нём стоит
отсрочка уровней риска «биржа» и «портфель».

**FUTURES из контура вынесен:** fee-путь построен под SWAP предметно, и
FUTURES в контуре дал бы либо молча неверную ставку, либо отказ на каждом
входе. Доменный тип и delivery-поля контракта остаются: модель шире
контура — это норма.

## Гейт открытия сделки

Новая сделка по инструменту не открывается, пока предыдущая не
терминальна. `ERROR` — активный статус и слот держит.

**Штатный переход в терминал требует подсчитанных движений.** Пока
движения сделки собираются и линкуются, сделка жива и удерживает слот; на
этом стоит однозначность окна линковки.

**Троп в терминал в обход подсчёта две:**

- **аварийный терминал** с best-effort числом: доступен net — считается
  по той же формуле; иначе пусто с маркером «неисчислимо», **не ноль**;
- **закрытие без входа** — ноль пишется только после проверки, что
  операций на бирже не было.

Ручного перевода сделки в терминал мимо FSM нет.

## Закрытие без входа: ноль как результат проверки

Троп три, и все три — траншевые: истечение условия в `PRECHECK` транша,
риск-блок в `PRECHECK` транша, отмена неисполненного входа из его
`ENTRY_SUBMITTED`. Сделка идёт этой тропой, когда так закрылись все её
транши.

Перед записью нуля проверяется факт операций на бирже по этой сделке.
Операций не было ⇒ ноль как **исход расчёта**. Операции были ⇒ сделка по
этой тропе не закрывается: идёт обычным путём финализации.

Определение признака «операций не было» — `docs/rules/deal-without-operations.md`.

**Инвариант чистого терминала не смягчается:** число обязательно всегда;
меняется лишь то, что на тропах без входа оно равно нулю по факту
проверки. Валюта пишется, только если резолвится; не резолвится ⇒ ноль
без валюты плюс `AnomalyReport`.

## Валюта комиссии

**Комиссии платятся только в расчётной валюте инструмента.** Оплата
сторонней валютой — включая биржевые скидки за оплату токеном площадки —
запрещена; режим отключается в конфигурации аккаунта.

**Это инвариант схемы, а не особенность площадки:** заголовочный
результат сделки берётся готовым net в расчётной валюте, и издержка,
уплаченная вне неё, в этот net не входит. Любая площадка с оплатой
комиссии сторонним токеном ломает число одинаково.

**Движение в чужой валюте — аномалия, но число не завышается молча:** оно
персистится, линкуется и входит в результат эквивалентом по курсу на
момент операции. Курс и исход его получения — поля движения. Слагаемое
считается по строкам, где курс применён, тип вне списка исключений биржи
и категория экономическая.

**Операнд сравнения — расчётная валюта инструмента**, не валюта
результата сделки: последнюю пишет финализация, то есть позже записи
движения.
