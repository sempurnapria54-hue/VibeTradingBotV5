# Реестр канонических имён моделей

Реестр имён бизнес-моделей проекта. Навигационная точка входа в `docs/spec/`.

**Реестр — отражение созданных model-документов (включая заглушки), не гейт для принятия решения о том, является ли встреченное имя бизнес-моделью.** Решение принимается по тестам типа сущности в скилле [`spec-document-migration`](../../.claude/skills/spec-document-migration/SKILL.md).

Правила работы с реестром (формат записей, операции, границы содержания) — в скилле [`spec-models-registry`](../../.claude/skills/spec-models-registry/SKILL.md).

Деление на Core и Runtime — по [ADR-0006 §1](../../.claude/adr/0006-spec-principles.md) и [terminology.md](../conventions/terminology.md).

## Core

- **AlgoOrder** — алгоритмический ордер: ордер с условной логикой исполнения (например, стоп-ордер), управляемый биржей по заданным параметрам.
- **AnomalyReport** — отчёт об обнаруженной аномалии: расхождении между внутренним состоянием системы и состоянием на бирже. Результат процесса reconcile. См. [models/core/AnomalyReport.md](models/core/AnomalyReport.md).
- **Balance** — баланс активов на бирже. Состояние средств, доступных для торговли.
- **Deal** — агрегат торговых сущностей в рамках одной сделки. Жизненным циклом управляет FSM на основе стратегии.
- **Exchange** — биржа, на которой система ведёт торговлю.
- **IndicatorValue** — рассчитанное значение технического индикатора по инструменту в определённый момент времени.
- **Instrument** — торгуемый инструмент на бирже (торговая пара, например). Описывает, чем именно торгует система.
- **MarketPhase** — текущая фаза рынка по инструменту (явно определяемая, UNKNOWN вместо null). Готовится MarketPhaseJob из IndicatorValue и MarketStructure; используется для выбора активных StrategyDetails.
- **MarketPriceData** — данные о цене инструмента на бирже: исторические или текущие котировки.
- **MarketStructure** — рассчитанная структура рынка по инструменту: уровни (swing high/low, support/resistance). Готовится MarketStructureJob по настройкам стратегии и используется калькуляторами как готовый вход.
- **Order** — биржевой ордер: заявка на покупку или продажу инструмента, отправленная на биржу.
- **Position** — открытая торговая позиция по инструменту. Результат исполненных ордеров; описывает текущую экспозицию.
- **Strategy** — конфигурация торгового алгоритма: правила входа, выхода, риск-менеджмента для конкретного инструмента или набора инструментов.

## Runtime

- **DealActionState** — хранимое runtime-состояние конкретного StrategyAction внутри сделки: что уже создано/отправлено/завершено. Обеспечивает идемпотентность и recovery после рестарта.
- **DealContext** — runtime-контекст одного прохода FSM сделки. Собирается перед каждой обработкой сделки и пересобирается после команд.
- **ServiceCommand** — атомарная runtime-команда над торговой сущностью либо группой сущностей в рамках одной сделки. Создаётся FSM на основе стратегии.
