# StrategyActionExecutor

## На какой вопрос отвечает этот файл

Кто выдаёт следующую команду одного типа действия стратегии за проход.

## Что делает

За проход смотрит стадию исполнения и выдаёт **следующую** команду
действия либо пустой план — «готово или нечего делать»; прочие исходы
плана — дом `docs/components/models/ActionPlan.md`.

```java
Boolean supports(StrategyAction action);
ActionReadiness readiness(StrategyAction action, DealContext dealContext,
                          DealTranche tranche);
ActionPlan next(StrategyStep step, StrategyAction action,
                DealActionState state, DealContext dealContext,
                DealTranche tranche);
```

Метод поддержки отвечает, исполняет ли этот исполнитель данное действие —
по подтипу и типу действия; по нему диспетчер маршрутизирует.

**Названное ограничение: исполнителя `REPLACE_ACTION` в перечне нет.**
Порядок ног замещения объявлен (`docs/rules/replace-not-amend.md`), а
компонента, который его исполняет, не построено: пакет с замещающим
действием исполнителя не находит и получает пустой план с записью
журнала. Условие снятия — ход, вводящий фабрику замещающих ног; дом
задачи — пункт `.claude/work/backlog.md` о названных ограничениях
кодирования шага 7. Следствие того же: **резолв цели
снятия по корню цепочки замещений** тоже не воплощён — цепочек в рантайме
не возникает, пока фабрики нет.

## Готовность отвечается ДО строки исполнения

`readiness` — гейт предусловия действия, и спрашивается он **прежде**,
чем заведена строка исполнения: действие, чьё предусловие не выполнено,
исполнения не начинает — строка не заводится, бюджет попыток не
расходуется (порядок выбора действия —
`docs/components/StrategyActionOrchestrator.md`).

| Исход | Что значит | Что делает пакет шага |
|---|---|---|
| `READY` | предусловий сверх условия шага нет либо они выполнены | заводит строку и планирует действие |
| `DEFERRED` | предусловие не выполнено, надобность жива | останавливается: обгонять отложенное действие значило бы менять объявленный порядок пакета |
| `IRRELEVANT` | предмета у действия больше нет (цели снятия среди живых защит не осталось) | берёт следующее действие — ждать нечего |

**Умолчание — `READY`.** У действия, которое ничего не снимает и ничьего
покрытия не забирает, предусловия сверх условия шага нет, а условие шага
проверил обработчик. Переопределяет умолчание тот исполнитель, у чьего
действия предусловие есть
(`docs/components/CancelAlgoOrderActionExecutor.md`).

## Стадия выводится из фактов

Секвенс ведёт петля по **подтверждённым фактам**, а не по подтверждению
приёма: создать, отправить, дождаться факта, идти дальше.

**Порядок ног замещения — по риск-классу**
(`docs/rules/replace-not-amend.md`).

## Границы

- Статус исполнения сам не пишет: его двигают исполнители команд и учёт
  повторов.
- Условие шага не проверяет — это сделал обработчик.
- Более одной команды за проход не выдаёт.
