# StrategyActionExecutor

## На какой вопрос отвечает этот файл

Кто выдаёт следующую команду одного типа действия стратегии за проход.

## Что делает

За проход смотрит стадию исполнения и выдаёт **следующую** команду
действия либо пустой план — «готово или нечего делать».

```java
Boolean supports(StrategyAction action);
ActionPlan next(StrategyStep step, StrategyAction action,
                DealActionState state, DealContext dealContext);
```

Метод поддержки отвечает, исполняет ли этот исполнитель данное действие —
по подтипу и типу действия; по нему диспетчер маршрутизирует.

## Стадия выводится из фактов

Секвенс ведёт петля по **подтверждённым фактам**, а не по подтверждению
приёма: создать, отправить, дождаться факта, идти дальше.

**Порядок ног замещения — по риск-классу**
(`docs/rules/replace-not-amend.md`).

## Границы

- Статус исполнения сам не пишет: его двигают исполнители команд и учёт
  повторов.
- Условие шага не проверяет — это сделал обработчик.
- Более одной команды за проход не выдаёт.
