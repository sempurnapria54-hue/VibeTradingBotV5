# DealContextService

## На какой вопрос отвечает этот файл

Кто собирает контекст прохода FSM.

## Что делает

Собирает контекст одного прохода: сделку с графом, биржу, инструмент,
закреплённую деталь стратегии, последний снимок баланса и строки
исполнения обоих видов.

**Служебная сборка — не действие.** Она читает уже приземлённое и между
проходами ничего не переживает. Действие — только **добыча наружу**: поход
на биржу и приземление фактов, чьи попытки и исход durable. Сборка
потребляет то, что добыча приземлила.

## Объёмы загрузки

**Дом предикатов полноты — исполнимая спецификация**
`docs/spec/deal-context-load.json` (`contextComplete`,
`computationAllowed`, `coverageAnswerDistorted`, `exitAnswerDistorted`):
там же примеры того, как усечённая загрузка искажает ответ в обе
стороны.

Всё, по чему считаются персистируемые числа сделки, грузится **целиком**,
иначе число выходит заниженным молча.

| Коллекция | Объём | Почему целиком |
|---|---|---|
| эпизоды позиции | **все**, включая закрытые | по ним считается результат сделки и правые операнды пар сверки; непогруженный эпизод делает предикат «положение закрытия добыто у всех» истинным, а число заниженным |
| ноги сделки | **все** | по ним считаются числа риска и омиссионный член допуска |
| **встроенные защиты ног** (вложенная коллекция) | **все вместе со своей ногой**, включая терминальные | по ним считается покрытие защиты, и без них предикат покрытия работает по неполному множеству — тихо в разрешающую сторону для нарушителя и в запрещающую для штатной сделки |
| отдельные условные заявки | **все живые плюс защитные терминальные** | операнд уровня действующей защиты; цепочка замещений резолвится по указателю предшественника |

**Объём ограничен предметно, а не окном:** число эпизодов, ног и защит
одной сделки задано её собственной конструкцией, а не историей
инструмента.

**Что ограничение продолжает резать:** сущности, **не принадлежащие** этой
сделке — чужие заявки и позиции по тому же инструменту, история закрытых
сделок.

## Границы

Сырые факты биржи в контекст не кладутся: они сперва применяются
командами добычи к базе, затем сервис собирает уже обновлённый граф.

Свежесть баланса сервис не гарантирует — её проверяет обработчик перед
чувствительным к риску действием.

Свежие рыночные данные и контекст расчёта в контекст прохода не входят.
