# StrategyActionCalculator

## На какой вопрос отвечает этот файл

Кто рассчитывает runtime-параметры действия стратегии.

## Что делает

Оркеструет расчёт: считает цену, затем размер и возвращает готовые
параметры команды.

```text
цена   = калькулятор цены.calculate(контекст)
размер = калькулятор размера.calculate(контекст, цена)
      → рассчитанное действие
```

**Контекст приезжает ГОТОВЫМ, а собирает его ядро.** Поток начинается не с
фабрики: все входы сборки — персистентность ядра плюс вызов к соседу
(`docs/components/CalculationContextFactory.md`), а расчёт живёт в общей
библиотеке и к базе не ходит вовсе. Бэктест соберёт тот же контекст из
своего состояния и позовёт **тот же** расчёт — ровно поэтому граница
проведена здесь.

**Пустой контекст либо контекст без действия — контролируемая ошибка**, а
не пропуск: считать нечего, и молчаливый пропуск выдал бы «нечего делать»
там, где вход не собрался.

Возвращает результат расчёта: успех с рассчитанным действием либо ошибку
с описанием.

## Контракт ошибки — возвратный, не бросковый

Субкалькуляторы сигнализируют контролируемую ошибку броском внутреннего
исключения; оркестратор его перехватывает и возвращает ошибку в
результате.

Неожиданные исключения так не оборачиваются — их ловит граница исполнения
прохода.

## Границы

- Решения о применимости действия не принимает — это делает обработчик.
- Команд не эмитит: их строит исполнитель типа действия.
- Тяжёлых данных не считает: читает готовые результаты.
