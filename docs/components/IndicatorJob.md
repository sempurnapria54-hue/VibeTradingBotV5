# IndicatorJob

## На какой вопрос отвечает этот файл

Кто считает технические индикаторы.

## Что делает

Заранее считает индикаторы по настройкам стратегий и сохраняет значения.

- читает стратегии **всех статусов, кроме удалённых**, и их настройки
  индикаторов: открытые сделки неактивных стратегий ведутся по
  закреплённой детали и тоже читают индикаторы, а созданные — для
  готовности прогрева;
- читает закрытые свечи;
- считает значения;
- **сохраняет только значения после зоны прогрева**;
- пересчёт идемпотентен;
- заглядывания вперёд не допускает.

## Прогрев

Величина прогрева в значении не хранится: джоба сама пропускает зону
разгона и сохраняет только пригодные для торговли значения.

Эффективный прогрев — объявленный автором override либо выведенный из
типа и периода (`docs/rules/strategy-condition-contract.md`).

## Границы

- Решения о входе не принимает, сделок и заявок не создаёт.
- Фазу рынка напрямую не считает.
- Свежесть не проверяет: её меряют по сроку настройки-владельца.
