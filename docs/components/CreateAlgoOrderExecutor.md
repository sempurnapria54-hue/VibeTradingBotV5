# CreateAlgoOrderExecutor

## На какой вопрос отвечает этот файл

Кто исполняет создание отдельной условной заявки.

## Что делает

Создаёт локальную условную заявку, генерирует стабильный клиентский
идентификатор, сохраняет рассчитанные параметры условия, заполняет цель
строки исполнения и двигает её статус. На биржу не ходит.

## Плановый риск здесь не пишется

Входной тропы условной заявкой не существует: все типы условия защитные
либо закрывающие. Плановый риск ноги и его операнды пишет исполнитель
создания обычной заявки; этот к ним не причастен.

Преконтроль на этой тропе вызывается **по ветке ослабления защиты**, а не
как вход, поэтому величина планового риска здесь не производится.

## Что пишет: риск, снятый защитой

Постановка защиты меняет операнд четвёртого числа сделки — уровень
действующей защиты, — поэтому исполнитель **пересчитывает четвёрку чисел
риска целиком** той же транзакцией, по общему правилу «кто меняет
операнд, пересчитывает всё».

Формулы — `docs/spec/deal-risk-numbers.json`.

## Размер ступени лестницы

Размер приходит рассчитанным. Для защитного класса последняя ступень
набора получает остаток, а ступень меньше минимального размера даёт
контролируемую ошибку расчёта — исполнитель её не сглаживает.

## Идемпотентность

Анкер — строка исполнения. Повтор до завершения пересоздаёт локальную
сущность по тому же клиентскому идентификатору.
