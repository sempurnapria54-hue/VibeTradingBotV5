# CalculationContextFactory

## На какой вопрос отвечает этот файл

Кто собирает контекст расчёта.

## Что делает

Собирает свежий контекст расчёта для **одного** рассчитываемого действия
из контекста прохода, самого действия и свежих рыночных данных.

## Источники

Runtime-цены, справочные правила инструмента с гидрированной ставкой,
каталоги настроек стратегии для резолва готовых значений по ключу, готовые
значения индикаторов и структуры, снимок баланса из контекста прохода.

**Тяжёлых данных фабрика не считает** — читает готовые результаты.

**Фазу рынка фабрика не запрашивает:** в фазе 1 потребителя у неё нет, и
поле остаётся пустым.

## Границы и защитное поведение

- **Один рассчитываемый действие — один свежий контекст.** Общий контекст
  на шаг или проход не собирается.
- Обязательный вход не резолвится — **контролируемая ошибка расчёта**, а
  не контекст с пустотами: расчёт по пустому операнду дал бы молча
  неверное число.
- Свежесть входов проверяется до сборки: несвежие данные до калькулятора
  не доезжают.
