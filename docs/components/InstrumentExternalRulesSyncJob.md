# InstrumentExternalRulesSyncJob

## На какой вопрос отвечает этот файл

Кто обновляет справочные данные инструмента.

## Что делает

Обновляет из REST биржи справочный навес правил инструмента и ставку
комиссии комиссионной группы счёта.

Правила меняются редко, поэтому хранятся снимком.

## Два источника разной природы

| Источник | Природа | Лимит считается по |
|---|---|---|
| правила инструмента | публичный, подписи не требует | IP и типу инструмента |
| ставка комиссии | приватный, требует подписи и права чтения | **счёту** |

Разная природа не декоративна: у приватного источника лимит по счёту,
поэтому число его вызовов за тик не должно расти вместе с числом
инструментов.

## Ставка читается раз на тик, не на инструмент

**Один** вызов ставок **до** цикла по инструментам даёт карту «тип
инструмента, группа → ставки»; далее матч по паре сырых полей навеса.

**Ось ставки — комиссионная группа, а не инструмент:** вызовы на каждый
инструмент вернули бы одни и те же строки группы многократно, расходуя
квоту счёта и не принося новых фактов.

**Группа не нашлась в ответе** — строка не пишется, ставка группы стареет
штатным путём. Подставлять ставку соседнего типа инструмента нельзя: это
и есть молчаливый отказ.

## Что пишет

- навес правил инструмента — через граничный снапшот;
- ставку: значение группы изменилось — новая строка, совпало — инкремент
  счётчика подтверждений и обновление времени источника. Ставки
  сравниваются численно, уровень счёта — строкой;
- **мягкий холд затронутых инструментов** при исчерпании порога свежести
  ставки либо ключа группы.

**Синк — односторонний писатель холда:** восстановившееся чтение статус не
возвращает, снятие ручное. **На инструменте, уже стоящем в жёсткой
ступени, мягкий запрос синка поглощается** — статус не трогается,
понижение делает только снятие; дом монотонности —
`docs/rules/exchange-hold.md` §«Границы и эскалация».

## Границы

Валюты инструмента синк не пишет: они добываются один раз при заведении
инструмента и подтверждения не требуют.

Выключенный синк источником холда не является — это штатная
эксплуатационная операция.
