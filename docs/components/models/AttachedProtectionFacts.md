# AttachedProtectionFacts

## На какой вопрос отвечает этот файл

Что это за runtime-объект.

## Назначение

Набор фактов, по которому **выводится** состояние встроенной защиты
заявки. Полноценного статуса источник ей не отдаёт, и статус приходится
выводить. RVO, не persisted, провода не пересекает.

## Почему выводится, а не читается

Встроенная защита живёт **атрибутами родительской заявки**, а не
самостоятельной сущностью площадки: отдельного статуса у неё нет ни в
одном ответе. Матрица вывода — `docs/lifecycles/Order.md`; форма и
примеры — `docs/spec/order-lifecycle.json`.

## Границы

- Собственного статуса не хранит: он и есть исход вывода.
- За фактами не ходит — они приходят уже добытыми
  (`docs/components/RefreshOrderExecutor.md`).
