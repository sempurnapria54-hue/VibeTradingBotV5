# HoldSignal

## На какой вопрос отвечает этот файл

Чем описывается требуемая блокировка.

## Назначение

`HoldSignal` — **параметр вызова** исполнителя блокировки: неизменяемый
объект, который детектор собирает на месте и тут же передаёт.

Сам сделку не закрывает — её уводит FSM; параметр адресует
инструмент-широкую либо биржевую реакцию.

## Структура

| Поле | Тип | Назначение |
|---|---|---|
| `scope` | `HoldScope` | Радиус: инструмент либо биржа. |
| `reactionClass` | `ReactionClass` | Что делать. |
| `code` | `String` | Машинный код причины; попадает в отчёт. |
| `instrumentId` | `Long` | Идентичность объекта при инструментном радиусе. |
| `exchangeId` | `Long` | Идентичность объекта при биржевом радиусе; при инструментном — биржа инструмента, если детектор её знает. |

**Критичности сигнал не несёт.** Она задаётся на границе захода в
журнал. Класс реакции — **не** критичность: он говорит, **что делать**, а
не насколько серьёзно.

## Енум `ReactionClass`

| Значение | Что поднимает |
|---|---|
| `SOFT` | мягкий запрет новых входов у инструмента; живые сделки ведутся штатно |
| `FREEZE` | мягкая биржевая ступень: биржа выпадает из выборки входа, командного блок-сета нет |
| `FULL` | жёсткий статус объекта плюс снятие живого риска; на биржевом радиусе — сворачивание с последующей командной тишиной |

Мягкие классы исполняет сам сервис блокировки; до координатора
последовательности доходит только полная реакция.

## Енум `HoldScope`

`INSTRUMENT`, `EXCHANGE`. **Группового значения нет:** радиус шире
инструмента выражается **набором строк** — по строке статуса и по отчёту
на каждый затронутый инструмент.

## Фабрики

Сигнал собирается фабричными методами по паре «радиус — класс реакции»,
чтобы идентичность объекта блокировки нельзя было забыть.
