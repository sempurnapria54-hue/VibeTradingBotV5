# KillSwitchExecutor

## На какой вопрос отвечает этот файл

Кто исполняет аварийное снятие живого риска.

## Что делает

Снимает живой риск сделки прямыми вызовами границы интеграции. Работает
только с живыми сущностями: активной позицией, живыми заявками и
условными заявками; историю не чистит.

**Вне реестра команд:** по типу команды не диспетчеризуется, зовётся
программно. Аварийный тормоз доводит свой ход **сам** и не зависит от
того, жива ли петля.

## Порядок

**Защита снимается последней и только после подтверждённого закрытия
позиции** — живая позиция не оголяется ни на мгновение.

Порядок остального — инвариант выхода
(`docs/rules/exit-teardown-order.md`): сперва живые входные ноги, потом
позиция.

## Подтверждение

Снятие риска подтверждается фактами: командами добычи через диспетчер,
перечиткой графа и проверкой отсутствия живого риска по доменным моделям.

Не подтверждено — ход повторяется, **ограниченно**: предел попыток в
конфигурации. Предел исчерпан — отказ, и эскалацию радиуса держит
координатор последовательности.

## Границы

- Преконтроль риска не вызывается: это safety-тропа.
- Статус блокировки не ставит — его ставит координатор.
- Сделку по FSM не ведёт.
