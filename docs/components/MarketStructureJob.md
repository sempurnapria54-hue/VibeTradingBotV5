# MarketStructureJob

## На какой вопрос отвечает этот файл

Кто готовит структуру рынка.

## Что делает

Заранее считает уровни рынка и сохраняет результат. Вычисление
делегирует резолверу — джоба **тонкая**.

Источник — закрытые свечи; дополнительно готовые значения индикаторов,
адресуемые ключами настройки.

## Шаги

- читает стратегии всех статусов, кроме удалённых, и их настройки
  структуры;
- читает закрытые свечи окна;
- по объявленным ключам извлекает готовые скаляры из значений
  индикаторов **своей стратегии** и подаёт их резолверу;
- зовёт резолвер;
- сохраняет структуру и её ценовые уровни.

## Объявленный вход не готов — консервативный исход

Ключ объявлен, а готового и свежего значения нет — джоба **не зовёт
резолвер**: пишет результат окна со значением «неизвестно», чтобы
потребитель не торговал по недосчитанной структуре.

Ключ не объявлен — резолвер идёт своей веткой без этого входа.

**Различие держит джоба**, а не резолвер: она знает, что было объявлено.

## Границы

- Свечи не добывает.
- Семантику классификации не определяет.
- Свежесть результата не проверяет: её меряют по сроку настройки.
