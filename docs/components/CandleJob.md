# CandleJob

## На какой вопрос отвечает этот файл

Кто готовит базовые свечные данные.

## Что делает

Загружает свежие свечи, дозагружает историю, следит за закрытием свечей и
сохраняет данные. Заглядывания вперёд не допускает.

## Правило закрытых свечей

Для производных расчётов используются **только закрытые свечи**.
Незакрытая свеча меняется до конца интервала, и расчёт по ней означал бы
решение по данным, которых на момент решения ещё не было.

## Границы

- Стратегических сигналов не считает.
- Сделок не создаёт и не ведёт.
- Уровней защиты не считает.
