# InstrumentExternalRulesDataService

## На какой вопрос отвечает этот файл

Кто отдаёт справочные правила инструмента.

## Что делает

Граница домена и хранилища для справочного навеса: отдаёт актуальные
правила и сохраняет их. У биржи правила сам не запрашивает.

Хранение — JSONB-навесом на строке инструмента: чтение через проекцию
навеса, запись через строку-владельца, чтобы её поля аудита обновлялись
штатно.

## Гидрация ставки комиссии

**Ставку в отдаваемый навес наливает этот сервис.** На навесе её нет —
там только ключ группы, а значение живёт своей строкой.

Резолвит актуальную строку ставки по тройке «биржа, сырой тип
инструмента, ключ группы» — биржу сервис знает через
инструмент-владельца. Запрос ограниченный: последняя строка группы.

**Обе тропы чтения навеса гидрируются здесь**, потому что через эту
границу проходят обе. Гидрация в фабрике контекста расчёта накрыла бы
только тропу калькуляторов, и преконтроль блокировал бы каждый вход
отсутствием ставки.

Ставка не резолвится — аксессоры отдают пустоту, и вход блокирует
преконтроль. Подставленного значения сервис не выдумывает.

## Границы

- Правила не добывает: это делает синк.
- Свежесть не оценивает: её меряет время изменения строки-владельца.
