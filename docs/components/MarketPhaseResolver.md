# MarketPhaseResolver

## На какой вопрос отвечает этот файл

Кто резолвит авторские правила фазы в тип фазы рынка.

## Что делает

По клаузам **потребителя** и готовым рыночным данным возвращает тип
фазы. Клаузы приносит вызывающий операндом: резолвер живёт в
`market-data`, а определения стратегий — в чужой базе
(`docs/components/MarketPhaseService.md` — дом контракта запроса).

```text
resolve(клаузы «условие → фаза», готовые значения индикаторов,
        структуры и цены) → тип фазы
```

## First-match по позиции

Истинность условия каждой клаузы спрашивается у вычислителя условий;
**первая истинная клауза задаёт тип**. Не сработала ни одна —
консервативный исход «неизвестно».

Порядок — позиция клаузы в списке.

## Stateless

Решение — функция только от клауз и текущих входов; истории резолвер не
держит и ничего не сохраняет.

**Момента подтверждения у фазы нет:** она не персистится, и гейт «без
заглядывания вперёд» наследуется от входов — они посчитаны только по
закрытым свечам.

## Границы

- Значений индикаторов и структуры не считает.
- Свежесть входов не проверяет: устаревший вход в контекст не попадает и
  даёт «неизвестно».
- Грамматику условий не держит: она в общем артефакте
  `libs/strategy-engine` — её читают и живая торговля, и бэктест, и
  классификация фазы, и вторая копия разошлась бы с первой
  (`.claude/rules/policy-home.md`).
