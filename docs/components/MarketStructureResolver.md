# MarketStructureResolver

## На какой вопрос отвечает этот файл

Кто вычисляет структуру рынка из свечей.

## Что делает

Из закрытых свечей окна выводит структуру рынка: тип, ценовые уровни,
событие подтверждённого пробоя.

```text
resolve(закрытые свечи окна, готовый скаляр эффективности,
        готовый скаляр волатильности, параметры настройки)
  → тип, уровни, событие пробоя, момент подтверждения, границы окна
```

Сам не персистит — его зовёт тонкая джоба.

## Потребляет готовые скаляры, не пересчитывает

Скаляр эффективности (дискриминатор тренда и шума) и скаляр
волатильности (толеранс кластеризации уровней) берутся **готовыми** из
рассчитанных значений индикаторов, если объявлены настройкой.

**Единый каталожный источник** — иначе одна и та же величина считалась бы
двумя способами и расходилась.

Скаляр не объявлен — работает fallback своей ветки; какой именно, задаёт
семантика классификации.

## Границы

- Свечи не грузит и индикаторы не считает.
- Результат не сохраняет и свежесть не проверяет.
- Торговых решений не принимает: тип структуры — факт, а не сигнал.
