# MarkDealErrorExecutor

## На какой вопрос отвечает этот файл

Кто применяет ребро сделки в ошибочное состояние.

## Что делает

Первое звено аварийного системного действия. Читает факт аварии,
обнаруженный обработчиком, и пишет ошибочный статус — в одной транзакции
с завершением своего исполнения.

Статус нетерминален: он передаёт сделку аварийному обработчику.

Торговых решений не принимает, преконтроль не вызывает.

## Не всякое ребро в ошибку едет через это звено

| Природа тропы | Кто пишет |
|---|---|
| **решение** обработчика по подтверждённым фактам | это звено; обработчик гейтит эмиссию |
| **перехват** — enforcement холда, оба обработчика исключений петли | петля прямой записью, без действия и анкера |

Разделение — `docs/processes/fsm-execution-layering.md`: на тропе
перехвата нужен гарантированный перевод, а не ещё одна точка отказа.

**Затребователь первого исполнения — обработчик тропы решения**, второго
(аварийного терминала) — аварийный обработчик.
