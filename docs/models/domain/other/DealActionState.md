# DealActionState

## На какой вопрос отвечает этот файл

Что это за модель `DealActionState` — строка исполнения действия.

## Назначение

`DealActionState` — операционная запись **одного исполнения действия** в
рамках сделки. Отвечает на вопрос «на каком шаге это исполнение и какую
runtime-сущность оно затрагивает». Несёт идемпотентность, восстановление
и бюджет попыток.

**Строка = исполнение, не действие.** Действие стратегии исполняется в
сделке многократно — повторное срабатывание узла сетки, одноимённые узлы,
параллельные ноги в полёте; системные действия повторяются циклами
добычи. Идентичность исполнения — суррогатный ключ.

Строки исполнений **копятся**: завершённое состояние жёстко терминально,
слот не переиспользуется.

`DealActionState` — **единственный держатель связи «действие стратегии —
runtime-сущность»**: заявки и позиции ссылок на действие не хранят.

**Строка исполнения защитного действия служит обязательством
покрытия** — durable-фактом «мы сейчас это устанавливаем»
(`docs/rules/live-risk-protection.md`).

## Структура

Наследует состояние повторов и поля аудита.

| Поле | Тип | Обязательно | Назначение |
|---|---|---|---|
| `id` | `Long` | да | Идентичность исполнения. |
| `dealId` | `Long` | да | Сделка. |
| `actionKind` | `ActionKind` | да | Вид действия. **В схему не персистится** — вид кодируется таблицей. |
| `strategyActionId` | `Long` | у стратегийных | Узел стратегии, чьё исполнение отслеживается. |
| `systemActionType` | `SystemActionType` | у системных | Тип системного действия. |
| `targetEntityType` | `TargetEntityType` | нет | Тип runtime-сущности. Колонка, а не JSONB: операнд ключа уникальности. |
| `targetEntityId` | `Long` | нет | Идентификатор этой сущности; пусто, пока она не создана. |
| `status` | `DealActionStateStatus` | да | Статус исполнения. |

**Поля повторов:** счётчик попыток, снимок предела, время следующей
попытки, последняя ошибка.

**Счётчик — сквозной бюджет отказов одного исполнения**, без обнуления
при продвижении стадии; **предел** читается живьём по типу текущей
команды.

**Стадия исполнения выводится из подтверждённых фактов и полем не
хранится:** явная стадия дублировала бы факты и протухала на рестарте.
Курсора пройденных звеньев нет.

## Енумы

**`ActionKind`** — `STRATEGY`, `SYSTEM`.

**`SystemActionType`:**

| Значение | Что делает |
|---|---|
| `REFRESH_DEAL_CONTEXT_ACTION` | добыча свежих фактов с биржи; дочистка звеном не является |
| `FINALIZE_DEAL_ENTRY_ACTION` | консолидация результата входа; завершение пишет статус подтверждённого входа той же транзакцией |
| `FINALIZE_DEAL_EXIT_ACTION` | число и чистый терминал |
| `FINALIZE_DEAL_ERROR_ACTION` | аварийная тропа; вход в ошибку и терминал — два отдельных исполнения |

**`DealActionStateStatus`:**

| Значение | Что означает |
|---|---|
| `PLANNED` | исполнение выбрано, команды ещё не было |
| `CREATED` | локальная сущность создана, цель заполнена |
| `SUBMITTED` | отправлено на биржу, факт не подтверждён |
| `COMPLETED` | доведено, факты подтверждены. **Жёстко терминален** |
| `RETRY_PENDING` | звено упало на повторяемой ошибке, ждёт следующей попытки |
| `FAILED` | бюджет исчерпан либо ошибка неповторяема |
| `SKIPPED` | исполнение стало неактуальным |

**`TargetEntityType`** — `ORDER`, `ALGO_ORDER`, `POSITION`, `DEAL`
(цель системных действий), `BALANCE`, `NONE`.

## Замещение: две ноги, одна запись на ногу

Замещающее действие исполняется как надмножество создания: нога порождает
**новую** сущность с указателем на замещаемую, плюс отмена старой. Новых
статусов не требуется — следующая команда выводится из фактов.

Порядок ног — по риск-классу (`docs/rules/replace-not-amend.md`).
Замещаемая сущность резолвится по цепочке замещений от целевого действия.

## Инварианты

**Стратегийные и системные исполнения хранятся в двух таблицах**, у
каждой свои ключи: в стратегийной ссылка на узел обязательна, в
системной — тип системного действия. Общей таблицы с nullable-ссылкой и
частичными индексами по виду нет — вместе с nullable-колонкой исчезает и
неоднозначность ключа.

**Ключи частичные, по живым статусам** — «уникальность среди живых»
(`docs/rules/idempotency-via-unique.md`). Завершённые строки ключ не
держат. У каждого ключа есть имя.
