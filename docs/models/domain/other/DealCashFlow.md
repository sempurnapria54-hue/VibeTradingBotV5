# DealCashFlow

## На какой вопрос отвечает этот файл

Что это за модель `DealCashFlow`.

## Назначение

`DealCashFlow` — запись одного денежного движения по счёту, привязанная к
сделке. Носитель **категорийной разбивки** результата: сколько комиссии,
сколько финансирования, сколько штрафа.

**Заголовочное число сделки берётся не отсюда:** оно приходит готовым net
из записей закрытия позиций. Роль разбивки двойная — категорийная
атрибуция и **независимая сверка** суммы движений с этим числом.

## Структура

| Поле | Тип | Обязательно | Назначение |
|---|---|---|---|
| `id` | `Long` | да | Внутренний идентификатор. |
| `dealId` | `Long` | нет | Сделка-владелец. Проставляется **при сохранении** предикатом линковки. |
| `category` | `CashFlowCategory` | да | Категория движения. Резолвится **из типа операции**, а не из знака комиссии. |
| `amount` | `BigDecimal` | да | Знаковая сумма движения. Отвечает на вопрос «сходится ли сумма». |
| `externalFee` | `BigDecimal` | нет | Знаковая **комиссионная компонента** записи, сырая, без нормализации знака. Отвечает на вопрос «сколько комиссии». Взята явно, а не выведена из знака суммы: комбинированная запись исказила бы разбивку. |
| `ccy` | `String` | да | Валюта движения. Сравнивается с **расчётной валютой инструмента**. Чужая валюта — нарушение инварианта, а не рабочий режим: строка персистится, линкуется, пересчитывается и помечается отчётом. Критерием матчинга к сделке не является. |
| `appliedRate` | `BigDecimal` | нет | Курс пересчёта в расчётную валюту, взятый **из свечи на момент операции**. Делает слагаемое чужой валюты воспроизводимым постфактум. |
| `rateStatus` | `RateStatus` | да | Состояние курса на строке. Явный признак, а не вывод из пустоты курса: пустым он бывает по трём разным причинам. |
| `appliedRateCandleInstrument` | `String` | нет | Ссылка на свечу курса: инструмент пары котировки. |
| `appliedRateCandleTimeframe` | `TimeFrame` | нет | Ссылка на свечу курса: таймфрейм. Фиксирует и **разрешение** — секундное либо огрублённое деградацией. |
| `appliedRateCandleOpenTime` | `OffsetDateTime` | нет | Ссылка на свечу курса: время открытия интервала. |
| `exchangeId` | `Long` | да | Биржа-владелец движения. Входит в ключ уникальности: идентификатор записи — номенклатура одной площадки, и при втором источнике столкновение дало бы тихую потерю движения. |
| `externalInstrumentId` | `String` | нет | Сырой биржевой идентификатор инструмента. **Ось предиката линковки**: ответ источника аккаунт-широкий, и без инструментной оси предикат подобрал бы движение чужого инструмента в том же окне. |
| `externalBillId` | `String` | да | Идентификатор записи источника. |
| `externalType` | `String` | да | Сырой тип записи. |
| `externalSubType` | `String` | нет | Сырой подтип записи. |
| `externalOrderId` | `String` | нет | Заявка, если движение с ней связано. |
| `externalCreatedAt` | `OffsetDateTime` | да | Время события источника. Поле аудита, а не собственное: событие источника называется конвенционным именем. |

Три координаты свечи заполняются только при применённом курсе и вместе
однозначно идентифицируют свечу.

**Природа пустой комиссионной компоненты разобрана в одну сторону —
названное ограничение.** Записано «пусто = комиссионной компоненты у
события не бывает»; вторая природа — «источник поля не отдал» — не
названа, конвенции пустоты у записи источника не существует.

Цена ложного прочтения направленная: при омиссии комиссия сделки
**недосчитывается**, и вторая пара сверки расходится в одну сторону на
всей популяции. **Пустота нулём не подменяется:** нулевая комиссия
благоприятнее неизвестной.

## Енумы

**`CashFlowCategory`** — категория движения: реализованный результат,
торговая комиссия, финансирование, ребейт, штраф ликвидации, прочее.
Категория «прочее» — принимающая корзина для нераспознанного типа.

**`RateStatus`:**

| Значение | Что означает |
|---|---|
| `NOT_REQUIRED` | движение в расчётной валюте, курс не нужен |
| `APPLIED` | курс получен и применён |
| `RATE_UNAVAILABLE` | курс требовался и не получен |
| `SETTLE_CURRENCY_UNAVAILABLE` | расчётная валюта инструмента не резолвилась |

Пустота у курса перегружена тремя смыслами, поэтому признак заведён
значением: «пусто по природе» и «пусто по отказу» обязаны различаться.

На состоянии курса ключуются область суммирования чужой валюты и
множество строк, ждущих догона курса.

## Линковка к сделке

Записи источника не несут ссылки на сделку. Предикат линковки — **биржа,
инструмент и попадание времени события в окно линковки** при
нетерминальной сделке.

**Отложенной линковки нет:** движение, попавшее в окно живой сделки,
линкуется тем же проходом, который его сохранил. Ждать закрытия окна
незачем.

Однозначность держит инвариант «одна активная сделка на инструмент».

**Долгоживущая пустая ссылка — форвард-слот** под движения счёта вне
периода жизни сделок.

## Персистентность

Таблица `deal_cash_flows` по сделке, наследует поля аудита.

**Ключ идемпотентности** — пара «биржа, идентификатор записи источника»:
повторная добыча того же движения не порождает второй строки.

Обязательность времени события обеспечивается **на границе разбора**, а
не колонкой.

Денежные величины — `numeric(36,18)`, строковые и енум-колонки —
`varchar(64)`.
