# InstrumentExternalRules

## На какой вопрос отвечает этот файл

Что это за модель `InstrumentExternalRules` — справочные правила
инструмента.

## Назначение

Актуальные внешние правила инструмента, полученные от биржи и сохранённые
как снимок: округление цены и размера, расчёт размера в контрактах,
проверки минимумов и максимумов, биржевой потолок плеча, торгуемость,
ключ комиссионной группы.

Правила меняются редко, поэтому хранение снимка оправдано. Обновляет
синк справочных правил.

**Валюты инструмента здесь не живут** — их дом сам инструмент: валюта
расчёта есть атрибут контракта, а этот навес заведён под **волатильную**
часть спецификации.

## Структура

Собственного идентификатора у класса нет: единственный ключ —
инструмент-владелец. Модель хранится **JSONB-навесом на строке
инструмента**, своей таблицы не имеет.

**Наследником базового аудита модель не является:** у навеса нет своей
строки, наследовать поля не во что. Поля аудита у него — колонки
строки-владельца.

| Поле | Тип | Назначение |
|---|---|---|
| `instrumentId` | `Long` | Инструмент-владелец, ключ навеса. |
| `instrumentType` | `InstrumentType` | Доменная проекция типа инструмента. |
| `contractType` | `ContractType` | Доменная проекция типа контракта. **Читатель — тропа заведения инструмента:** нелинейный контракт отвергается. |
| `status` | `Status` | Доменная проекция статуса инструмента. |
| `externalInstrumentType` | `String` | Сырой тип инструмента. |
| `externalInstrumentId` | `String` | Идентификатор инструмента на бирже. |
| `externalContractType` | `String` | Сырой тип контракта. |
| `externalContractValue` | `String` | Стоимость контракта. |
| `externalContractValueCurrency` | `String` | Валюта стоимости контракта. |
| `externalTickSize` | `String` | Шаг цены. |
| `externalLotSize` | `String` | Шаг размера. |
| `externalMinSize` | `String` | Минимальный размер. |
| `externalMaxLimitSize`, `externalMaxMarketSize`, `externalMaxTriggerSize`, `externalMaxStopSize` | `String` | Максимальные размеры по типам заявок. |
| `externalMaxLeverage` | `String` | **Биржевой максимум плеча** — авторитет преконтроля. |
| `externalFeeGroupId` | `String` | **Ключ комиссионной группы**, не ставка: ось резолва строки ставки. Стареет самостоятельно. |
| `externalState` | `String` | Сырой статус инструмента. |

Поля с префиксом внешнего источника хранят значения в номенклатуре
источника; доменные проекции служат runtime-логике.

**Конвенция префикса означает «значение источника в его номенклатуре», а
не «байт-в-байт нетронутое»:** нормализация допускается там, где ниже
маппинга величина обязана быть проектной нормалью, и фиксируется в
per-source секции маппинга.

## Ставка комиссии

**Ставка на навесе не хранится.** Здесь только ключ группы; сама ставка —
`docs/models/domain/other/TradeFeeRate.md`.

Читателям она доступна **аксессором на этой модели**: гидрирует его
хранилищный слой навеса, без отдельного поля контекста и без вызова биржи
из калькулятора. Поверхность чтения тем самым не меняется. Писатель ряда
ставок — владелец биржевого счёта, не синк инструментов
(задача переезда реестра — в бэклоге).

**Исключение поля из навеса выражает ХРАНИЛИЩНЫЙ слой, а не форма.**
Аксессор ставки в сериализуемый JSON не попадает, и обеспечивает это
конвертер навеса своими средствами: сериализационная аннотация на
доменной модели означала бы, что форма знает о своём хранении, а её
читают все сервисы — включая те, у которых этого хранения нет.

## Свежесть

**Собственных полей свежести у навеса нет.** Измеритель — время
изменения **строки-владельца**: метка живёт вне JSON и переживает любую
перезапись навеса, а её nullability выражается колонкой и миграцией.

Ключ группы стареет самостоятельно, отдельно от ставки; реакция на
несвежесть — мягкая, инструментного радиуса.

## Персистентность

JSONB-колонка на строке инструмента. Отдельной таблицы нет; поля аудита —
колонки владельца.
