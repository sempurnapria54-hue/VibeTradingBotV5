# BalanceContainer

## На какой вопрос отвечает этот файл

Что это за сущность `BalanceContainer`.

## Назначение

`BalanceContainer` — снимок состояния счёта на бирже: последняя известная
системе картина средств. Потребители — сайзинг, преконтроль риска,
проверка расчётной валюты, диагностика замороженных средств и
**терминальное ребро сделки**: `MarkDealClosedExecutor` и
`MarkDealEmergencyClosedExecutor` читают `externalAvailableBalance` строки
расчётной валюты, чтобы опустить `Exchange.riskBase` до остатка
(`docs/rules/risk-policy.md` §«Носитель базы и её писатели»). Годность
снимка для этого хода — отдельное условие: строка расчётной валюты есть и
снимок не старше терминала, иначе база не двигается и заводится
журнальный отчёт.

**Второй читатель остатка — первое наблюдение базы риска.**
`RefreshBalanceExecutor` читает `externalAvailableBalance` строки
расчётной валюты, чтобы заполнить пустую `Exchange.riskBase` той же
транзакцией, что приземляет снимок; наблюдением считается только строго
положительный остаток (`docs/components/RefreshBalanceExecutor.md`).

`Balance` — снимок одной валюты внутри контейнера; раздел этой модели, а
не самостоятельная сущность.

## Структура контейнера

| Поле | Тип | Назначение |
|---|---|---|
| `id` | `Long` | Внутренний идентификатор снимка. |
| `exchangeId` | `Long` | Биржевой счёт, которому принадлежит снимок. |
| `externalUpdatedAt` | `OffsetDateTime` | Время обновления снимка на стороне биржи. База проверки свежести. |
| `externalTotalEquity` | `BigDecimal` | Общий капитал счёта. |
| `externalAdjustedEquity` | `BigDecimal` | Скорректированный капитал. |
| `externalAvailableEquity` | `BigDecimal` | Свободный капитал уровня счёта. **Базой риск-политики не является** — диагностическая величина. |
| `balances` | `List<Balance>` | Балансы по валютам. |

**Единица и валютный состав полей уровня счёта не объявлены.** Все три
агрегируют все валюты счёта, а их номинацию источник не называет и модель
не записывает. Отсюда:

- **риск-контур их не читает** — база риска берётся из строки расчётной
  валюты;
- **сравнивать их с величинами в расчётной валюте нельзя** — ни в
  неравенствах потолков, ни в допуске сверки. Понадобится — номинация
  становится несущей и добывается прогоном контура тестов источника
  **до** ввода потребителя.

## Структура `Balance`

| Поле | Тип | Назначение |
|---|---|---|
| `id` | `Long` | Внутренний идентификатор. |
| `balanceContainerId` | `Long` | Родительский контейнер. |
| `externalCurrency` | `String` | Валюта. |
| `externalUpdatedAt` | `OffsetDateTime` | Время обновления снимка валюты на бирже. |
| `externalEquity` | `BigDecimal` | Капитал по валюте. |
| `externalCashBalance` | `BigDecimal` | Денежный остаток. |
| `externalAvailableBalance` | `BigDecimal` | Доступный остаток. У строки **расчётной валюты инструмента** — операнд движения базы риска вниз и её первого наблюдения; **самой базой не является** (`docs/rules/risk-policy.md`). Единица определена по построению — валютой строки. |
| `externalFrozenBalance` | `BigDecimal` | Замороженный остаток — диагностика, почему часть средств недоступна. |

## Инварианты

- Контейнер **не торговая runtime-сущность**: он не выставляется, не
  отменяется, живого риска не создаёт, торгового жизненного цикла и
  своего статуса не имеет.
- Обновление — **только рефрешем баланса**, с семантикой полной замены:
  валидный снимок целиком заменяет прежний список валют.
- **Свежий снимок обязан содержать расчётную валюту.** Её отсутствие —
  контролируемая ошибка счёта, а не нормальная ситуация.

## Свежесть

Состояние «устарел» не хранится, а вычисляется: время обновления плюс
настроенный срок.
