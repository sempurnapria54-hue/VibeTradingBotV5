# SubscriptionTicketApiResponse

## На какой вопрос отвечает этот файл

Какую форму имеет билет подписки на поток, который периметр выдаёт браузеру?

## Назначение

`SubscriptionTicketApiResponse` — ответ собственной точки периметра
`POST /api/v1/bff/stream-tickets`, вызываемой под bearer-токеном предъявителя.
Форма порождена периметром и принадлежит `bff`. Билет предъявляется параметром
`ticket` при открытии подписки (`GET /api/v1/bff/stream`), потому что браузерный
`EventSource` заголовка `Authorization` не ставит.

## Поля

| Поле | Тип | Назначение |
|---|---|---|
| `ticket` | `String` | Значение билета, предъявляемое при открытии подписки. Связывает предъявителя и его тенанта. |
| `expiresAt` | `OffsetDateTime` | Момент, после которого билет негоден для открытия подписки, UTC. Равен моменту выдачи плюс срок билета — ось окружения периметра `perimeter.ticket.ttl`. |

Пишет форму точка выдачи, на каждом вызове: тенант выводится из членств
предъявителя тем же резолвом, что у контекста (`TenantContextApiResponse.md`).

Срок проверяется при **открытии** подписки; установленный поток по истечении
срока не рвётся. Истёкший билет клиент заменяет новым, пересоздавая подписку.

## Границы

- Отказ выдачи и отказ открытия идут единым error-DTO поверхности; билет
  непредъявленный, испорченный либо просроченный — класс
  `ACCESS_UNAUTHENTICATED` (`docs/rules/error-handling-policy.md`).
- Форма записей потока — `StreamRecordApiModel.md`.
- Правила билета, пересоздания подписки и позиции чтения —
  `docs/architecture/contracts.md`; доступ к поверхности —
  `docs/rules/api-access-policy.md`.
