# TenantContextApiResponse

## На какой вопрос отвечает этот файл

Какую форму имеет контекст предъявителя, который периметр отдаёт браузеру?

## Назначение

`TenantContextApiResponse` — ответ собственной точки периметра
`GET /api/v1/bff/context`, вызываемой под bearer-токеном предъявителя. Форма
порождена периметром и принадлежит `bff`. Тенант браузер не называет — он его
узнаёт из этого ответа: периметр выводит тенанта из членств предъявителя у
`auth`.

## Поля

| Поле | Тип | Назначение |
|---|---|---|
| `tenantId` | `String` | Идентичность тенанта предъявителя (`internalId` тенанта, `docs/models/domain/core/Tenant.md`). |
| `role` | `String` | Роль предъявителя в этом тенанте — значение `Membership.Role` (`docs/models/domain/other/Membership.md`). |

Пишет форму точка контекста, на каждом вызове, из резолва контекста тенанта;
резолв и кэш членств — `docs/architecture/contracts.md` (контекст тенанта в
вызове).

## Границы

- Отказы резолва — членств больше одного без выбора, владелец членств
  недоступен — идут единым error-DTO поверхности
  (`docs/rules/error-handling-policy.md`).
- Тот же контекст периметр передаёт владельцам заголовками при пересылке;
  форма заголовков — `docs/architecture/contracts.md`.
