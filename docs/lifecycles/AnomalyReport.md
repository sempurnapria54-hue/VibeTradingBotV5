# AnomalyReport lifecycle

## На какой вопрос отвечает этот файл

Через какие состояния проходит `AnomalyReport`.

Структура модели — `docs/models/domain/other/AnomalyReport.md`.

## Две тропы обработки

Разводит их **критичность**: гоняется ли снятие живого риска.

| Тропа | Кто ведёт | Как проходит |
|---|---|---|
| **критичная** — реакции со снятием риска | поиск нарушений инвариантов и координатор последовательности | создание → обработка → снятие риска подтверждено → завершение |
| **журнальная** — реакции без снятия риска | производители-детекторы | отчёт создаётся **уже завершённым по существу**: снимки собираются при создании, обработки нет |

**Мягкая биржевая ступень отчёт производит, и он некритичен:** его пишет
исполнитель блокировки, природа факта — состояние. Ручная постановка той
же ступени отчёта не производит — его производит автоматический триггер.

## Статусы

| Статус | Что означает |
|---|---|
| `CREATED` | инцидент зафиксирован, снимки состояния собраны |
| `IN_PROGRESS` | обработка идёт |
| `KILL_SWITCH_EXECUTED` | снятие риска выполнено и подтверждено |
| `COMPLETED` | обработка завершена |
| `ERROR` | непредвиденная ошибка обработки; текст ошибки пишется в отчёт |

**Журнальная тропа завершается сразу:** создание и завершение — один шаг,
потому что обрабатывать нечего.

## Матрица переходов

```text
(нет)                 -> CREATED
CREATED               -> IN_PROGRESS | COMPLETED | ERROR
IN_PROGRESS           -> KILL_SWITCH_EXECUTED | COMPLETED | ERROR
KILL_SWITCH_EXECUTED  -> COMPLETED | ERROR
COMPLETED             -> (терминальный)
ERROR                 -> IN_PROGRESS | COMPLETED
```

**Гейт терминала критичной тропы — подтверждённое снятие риска.** До
подтверждения отчёт остаётся в обработке: журнал обязан показывать, что
реакция начата и не завершена.

## Идемпотентность зависит от природы факта

| Природа | Дедуп |
|---|---|
| **состояние** — держится во времени | применяется: пока состояние держится **на объекте радиуса**, второго отчёта по тому же ключу не заводится |
| **событие** — своё происшествие | не применяется: каждое событие — своя строка, они обязаны быть счётными |

Операнд дедупа состояния — **стоящее состояние объекта**, не статус
отчёта: журнальная тропа завершает отчёт сразу, и по статусу отчёта
дедуп не сработал бы никогда. Ключ и дом правила —
`docs/models/domain/other/AnomalyReport.md`,
`docs/rules/error-handling-policy.md`.
