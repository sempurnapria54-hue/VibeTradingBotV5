# DealActionState lifecycle

## На какой вопрос отвечает этот файл

Через какие состояния проходит исполнение действия.

Структура модели — `docs/models/domain/other/DealActionState.md`.

## Кто управляет

Статус ведёт слой команд, а не FSM напрямую.

| Кто | Что делает |
|---|---|
| диспетчер действий стратегии | **читает** статус и цель, выбирает одну команду за проход; статус не пишет, кроме перевзвода ожидающего повтора |
| исполнитель системных действий | **читает** статус и подтверждённые факты звеньев, эмитит следующую команду; перевзводит ожидающего повтора и **пишет закрытие неактуального** |
| исполнители команд | **пишут** статус и цель по результату исполнения; звено, пишущее в сделку, двигает исполнение **той же транзакцией** |
| политика повторов | переводит в ожидание повтора либо в отказ при исчерпании бюджета |

## Статусы

**Живые:** `PLANNED`, `CREATED`, `SUBMITTED`, `RETRY_PENDING`.

**Финальные:** `COMPLETED`, `FAILED`, `SKIPPED`.

**Завершённое состояние жёстко терминально:** строка не
переиспользуется, новая надобность — новое исполнение. Частичные ключи
уникальности держат только живые строки.

## Матрица переходов

```text
(нет)          -> PLANNED
PLANNED        -> CREATED | SKIPPED
CREATED        -> SUBMITTED | RETRY_PENDING | FAILED | SKIPPED
SUBMITTED      -> COMPLETED | RETRY_PENDING | FAILED
RETRY_PENDING  -> PLANNED | CREATED | FAILED
COMPLETED | FAILED | SKIPPED -> (терминальные)
```

| Ребро | Когда |
|---|---|
| в созданное | локальная сущность создана, цель заполнена |
| в отправленное | команда ушла на биржу |
| в завершённое | факт **подтверждён наблюдением**, а не подтверждением приёма |
| в ожидание повтора | звено упало на повторяемой ошибке |
| в отказ | бюджет исчерпан либо ошибка неповторяема |
| в пропущенное | исполнение стало неактуальным |

## Писатель закрытия неактуального

Закрытие неактуального исполнения происходит там, где действие больше
**никто не называет**, — поэтому его пишет **ревизия живых исполнений**, а
не точка выбора одного названного действия: до неё такая строка не
доходит.

Ревизия идёт один раз за проход, до передачи управления обработчику, и
своей транзакцией.

## Отложенное действие исполнения не начинает

Действие, чьё предусловие не выполнено — например снятие защиты до
подтверждения замены, — строки исполнения **не заводит** вовсе: бюджет
попыток не расходуется, шаг ждёт следующего прохода
(`docs/rules/live-risk-protection.md`).
