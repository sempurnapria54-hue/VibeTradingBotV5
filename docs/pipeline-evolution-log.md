# Pipeline Evolution Log

История изменений пайплайна работы с Claude на этом проекте: агенты, скиллы, процессы, концепция.

**Правила лога:**
- Append-only. Старые записи не редактируются.
- Каждая запись — заголовок с датой и кратким описанием + 2-5 строк сути.
- Сюда пишутся **сделанные** изменения, не запланированные.
- Записи добавляются в хронологическом порядке (новые — наверх).

## 2026-05-14 — Введён единый бэклог открытых задач

**Что:** создан `docs/planning/backlog.md` — единый список открытых задач,
ADR-кандидатов и тем для проработки. Структура: секции по теме (Документация /
Содержательные ADR / Архитектура / Тесты), внутри пометки приоритета
(Now / Next / Later / Someday). Закрытые задачи не удаляются, помечаются
с датой и ссылкой.

**Зачем:** до этого открытые пункты жили только в `setup-strategy-summary.md`,
который по природе исторический и задним числом не редактируется. По итогам
ADR-0001 добавилось 5 новых TBD-пунктов + крупная задача миграции
`docs/domain/processes/` — нужно единое место, отражающее текущее состояние
очереди.

**Связные изменения:**
- В `setup-strategy-summary.md` добавлена сноска со ссылкой на backlog;
  сам список TODO в summary не редактируется (исторический срез).
- ADR-0001 содержит 5 TBD-пунктов, продублированных в backlog.

**Источник:** чат ADR-0001 → решение о вынесении очереди в отдельный файл.
