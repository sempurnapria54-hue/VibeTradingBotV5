# ADR-0005: Расположение шаблона ADR

## Status

Accepted — 2026-05-15

## Context

ADR-0004 (Расположение шаблонов spec-документов) перенёс шаблоны
spec-документов из `docs/spec/_templates/` в
`.claude/templates/documents/`. В Долгосрочных последствиях ADR-0004
явно оставил открытым вопрос про `0000-template.md` (шаблон ADR):

> Прецедент `0000-template.md` (шаблон ADR в `.claude/adr/`)
> остаётся отдельным паттерном — шаблон лежит рядом с экземплярами.
> Альтернативно его можно было бы перенести в
> `.claude/templates/adr/0000-template.md`, но это выходит за scope
> настоящего ADR и может быть рассмотрено отдельно при необходимости.

Сейчас, в той же сессии, что приняла ADR-0004, возник вопрос — почему
один шаблон лежит в `.claude/adr/`, а другие в `.claude/templates/`.
Расхождение мешает: при работе с шаблонами читателю и Claude нужно
помнить два разных места.

ADR-0005 закрывает этот вопрос — фиксирует решение, которое ADR-0004
оставил «при необходимости». Это ровно тот сценарий, который ADR-0004
предусмотрел.

## Decision

Шаблон ADR `0000-template.md` переезжает из `.claude/adr/` в
`.claude/templates/documents/adr.md`.

### Итоговая структура `.claude/templates/`

```
.claude/templates/
├── README.md
└── documents/
    ├── adr.md                      # шаблон для нового ADR в .claude/adr/
    ├── model.md
    ├── lifecycle.md
    ├── process.md
    ├── integration-mapping.md
    ├── reference.md
    └── invariant.md
```

### Переосмысление семантики `documents/`

ADR-0004 определял `documents/` как «шаблоны документов спецификации».
ADR-0005 **расширяет** определение: `documents/` — это шаблоны
markdown-документов проекта в широком смысле. Включая ADR.

Это сознательное расширение, не размывание:
- Все шесть spec-шаблонов + шаблон ADR — это шаблоны markdown-файлов,
  по которым создаются конкретные экземпляры в репозитории.
- Они отвечают на вопрос «как структурировать новый документ X».
- README в `.claude/templates/` обновляется соответственно — таблица
  расширяется строкой для `adr.md`, шапка таблицы переписывается.

Если в будущем появятся шаблоны принципиально иной природы (например,
prompts/, workflows/), они попадут в свои подпапки рядом с `documents/`,
не в `documents/`.

### Переименование

Файл переименовывается из `0000-template.md` в `adr.md`. Обоснование:
- Нумерация `0000-` имела смысл в `.claude/adr/`, где шаблон стоял
  перед `0001-`, `0002-`, ... как «нулевой элемент» схемы. В
  `.claude/templates/documents/` нумерация теряет смысл.
- Имя `adr.md` зеркалит схему именования других файлов в подпапке
  (`model.md`, `process.md`, ...): имя файла = тип создаваемого
  документа.
- Слово `template` в имени избыточно — путь `.claude/templates/`
  это уже сообщает.

### Связь с ADR-0004

ADR-0004 принят и не редактируется (правило append-only). Положение
«прецедент остаётся отдельным паттерном» в Долгосрочных последствиях
ADR-0004 описывает состояние на момент его принятия. ADR-0005 фиксирует
**последующее** решение, предусмотренное самим ADR-0004 как
возможное «при необходимости».

В `.claude/adr/0000-template.md` блок «Технические примечания» не
добавляется — это шаблон, не принятый ADR. Правила append-only к
шаблонам не применяются.

## Alternatives

### Альтернатива 1 — оставить `0000-template.md` в `.claude/adr/`

Не переносить. Сохранить паттерн «шаблон лежит рядом с экземплярами».

**Отклонено**: создаёт расхождение между шаблонами разных типов.
Шесть шаблонов spec-документов в `.claude/templates/`, один шаблон
ADR — в `.claude/adr/`. Принцип ADR-0004 (единое место для шаблонов)
теряет универсальность.

### Альтернатива 2 — `.claude/templates/adr/0000-template.md`

Параллельная подпапка `adr/` внутри `.claude/templates/`. Сохранение
имени `0000-template.md` и схемы нумерации.

**Отклонено**: вводит дополнительный уровень папок ради одного файла.
Семантика `documents/` остаётся узкой (только spec-документы), что
требует постоянного решения «куда положить новый шаблон» для каждого
будущего случая. Плоская структура с расширенным `documents/` проще
в навигации.

### Альтернатива 3 — `.claude/templates/documents/adr-template.md`

То же место, но с суффиксом `-template` в имени.

**Отклонено**: суффикс избыточен. Контекст «это шаблон» задан путём
`.claude/templates/`. Имена других файлов в `documents/` — без
суффикса (`model.md`, не `model-template.md`). Единообразие важнее
явности.

## Consequences

### Изменения в файловой структуре

**Переезжает (с переименованием) физически:**

| Старый путь | Новый путь |
|---|---|
| `.claude/adr/0000-template.md` | `.claude/templates/documents/adr.md` |

После переноса в `.claude/adr/` остаются: README.md, 0001..0005 ADR.

### Изменения в документации

**`.claude/templates/README.md`** — таблица расширяется. Шапка
«Шаблоны документов спецификации (`docs/spec/`)» переписывается на
более общую формулировку («Шаблоны markdown-документов проекта»),
добавляется строка для `adr.md` с указанием, что шаблон применяется
для документов в `.claude/adr/`.

**`.claude/adr/README.md`** — раздел «Шаблон» (если есть) или любая
ссылка на `0000-template.md` обновляется на новый путь.

**`.claude/flow/playbook.md`** — Сценарий 1 (Архитектурное решение →
ADR) ссылается на шаблон ADR. Путь обновляется. Если ссылки нет —
шаг можно пропустить.

**`.claude/planning/backlog.md`** — пункт Someday про возможный перенос
`0000-template.md`, добавленный knowledge-curator в этой же сессии,
закрывается с переносом в раздел «Закрытые» с ссылкой на ADR-0005.

**`.claude/pipeline-evolution-log.md`** — добавляется отдельная запись
о принятии ADR-0005.

**`CLAUDE.md`** — если содержит ссылку на `0000-template.md` или явно
говорит «шаблоны ADR в `.claude/adr/`» — обновляется.

### Project Knowledge в claude.ai

Затронуты прикреплённые файлы (дополнительно к ADR-0004):
- `.claude/adr/README.md` — уже в списке обновления для ADR-0004.
- `.claude/flow/playbook.md` — уже в списке.
- `CLAUDE.md` — уже в списке, если потребует правок.

Состав PK не меняется.

### Долгосрочные последствия

- Все шаблоны markdown-документов проекта централизованы в
  `.claude/templates/documents/`. Единое место для поиска и создания.
- Семантика `documents/` расширена до «шаблоны markdown-документов»
  (от исходного ADR-0004 «шаблоны spec-документов»). Это нужно
  учитывать при оценке будущих кандидатов на эту папку.
- Прецедент закрыт: «шаблон лежит рядом с экземплярами» больше не
  применяется на этом проекте (по крайней мере, для markdown-шаблонов).
- Закреплён прецедент использования цепочки ADR (родительский ADR
  предусматривает дочерний «при необходимости», дочерний принимается
  в той же или последующей сессии без правки родительского).
