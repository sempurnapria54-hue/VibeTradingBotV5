# 10. Decision Log

Файл для фиксации важных архитектурных, финансовых и процессных решений.

## Правила

- Решение фиксируется только после явного подтверждения пользователя.
- Если вопрос обсуждается, статус `DRAFT` или `OPEN`.
- Если решение принято, статус `APPROVED`.
- Если решение отменено, статус `SUPERSEDED` или `CANCELLED`.

## Шаблон записи

```markdown
## YYYY-MM-DD — Название решения

Статус: DRAFT / APPROVED / SUPERSEDED / CANCELLED
Связанные вехи/этапы: ...

### Решение
...

### Причина
...

### Влияние
- ...

### Что нужно изменить
- [ ] Документация
- [ ] Код
- [ ] Тесты
- [ ] Codex tasks
```

## Решения

### 2026-05-02 — Старт трекинга проекта

Статус: APPROVED  
Связанные вехи/этапы: все

#### Решение

Трекинг проекта ведётся через общий файл статуса, отдельные progress-файлы этапов, budget tracker и weekly reviews.

#### Причина

Нужно видеть продвижение по этапам, фактические часы, бюджет, блокеры и решения.
