## Правила статусов

| Статус | Значение |
|---|---|
| TODO | Этап ещё не начат |
| IN_PROGRESS | Этап в работе |
| BLOCKED | Этап заблокирован технически/архитектурно |
| WAITING_BUDGET | Этап ждёт накопления бюджета |
| WAITING_DECISION | Этап ждёт решения пользователя |
| DONE | Этап завершён |
| CANCELLED | Этап отменён |

## Как обновлять

1. Каждый день добавлять строку в progress-файл текущего этапа.
2. Раз в неделю обновлять прогресс, блокеры и недельный отчёт.
3. После закрытия этапа обновить этот общий трекер.
4. Если этап требует денег, сверить `11_Budget_Tracker.md`.
