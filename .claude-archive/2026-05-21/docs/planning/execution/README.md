# Трекеры прогресса проекта

Набор файлов для отслеживания продвижения по вехам и этапам.

## Основные файлы

- [09_Статус_и_прогресс_проекта.md](09_Статус_и_прогресс_проекта.md) — общий трекер.
- [10_Decision_Log.md](10_Decision_Log.md) — журнал решений.
- [11_Budget_Tracker.md](11_Budget_Tracker.md) — бюджет и ожидание денег.
- [12_Weekly_Reviews.md](12_Weekly_Reviews.md) — недельные отчёты.

## Progress-файлы этапов

Все отдельные трекеры лежат в папке [progress](progress).

## Ежедневное правило

В конце работы по проекту добавлять одну строку в progress-файл текущего этапа:

```markdown
| 2026-05-02 | 2.0 | Что делал | Что получилось | Блокер или — | Следующий шаг |
```

## Недельное правило

Раз в неделю обновлять:

1. Общий статус проекта.
2. Progress текущего этапа.
3. Budget tracker.
4. Weekly review.
5. Decision log, если были решения.
