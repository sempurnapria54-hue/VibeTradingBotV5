Цель вехи — довести приложение до состояния, когда оно может быть локально обкатано на OKX production API. Демо API не используется. До этой вехи ежемесячного пополнения $500/мес нет; доступен только стартовый депозит $500, который резервируется под production-проверку и вносится частями.

## Этап 1.1. Базовая торговая архитектура

### Цель

Довести основу торгового контура до состояния, когда на неё можно безопасно навешивать backtest engine, UI и live-запуск.

### Что делаем

- Финализировать Strategy.
- Финализировать Deal FSM.
- Финализировать ServiceCommand.
- Довести Order / AlgoOrder / Position.
- Довести recovery после рестарта.
- Довести audit/history.
- Довести kill-switch.
- Проверить базовые инварианты сделки.

### Результат этапа

Рабочий скелет: Strategy → DealOpeningService → Deal FSM → ServiceCommand → Order/AlgoOrder/Position.

## Этап 1.2. Backtest engine внутри приложения

### Что делаем

- Брать Strategy.
- Брать временное окно свечей.
- Идти по свечам последовательно без look-ahead.
- Имитировать входы, выходы, SL/TP.
- Учитывать комиссии/проскальзывание на уровне конфигурации.
- Сохранять сделки бэктеста.
- Подготовить основу для фонового запуска.

### Результат этапа

Рабочий backtest engine: Strategy + candles window → simulated trades → backtest statistics.
