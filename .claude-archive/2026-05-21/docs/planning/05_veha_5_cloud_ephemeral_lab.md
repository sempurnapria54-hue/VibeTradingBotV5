Цель вехи — использовать облако как временную лабораторию: создать сервер под задачу, выполнить эксперимент, сохранить результат локально, уничтожить сервер.

## Этап 5.1. CPU/RAM cloud lab

### Цель

Использовать временный CPU/RAM cloud-сервер для экспериментов без оплаты простоя.

### Что делаем

- Создать сервер под задачу.
- Запустить agent-runner/RAG/backtests.
- Скачать результаты локально.
- Удалить сервер.

### Результат этапа

Появляется временная лаборатория для задач, которые неудобно гонять на локальном ПК.

### AI-support

| Агент | Тип | Контекст | Права |
| --- | ---: | ---: | ---: |
| Cloud execution agent | Cloud-agent | Временно загруженный проект/datasets/configs | Выполняет задачу, отдаёт результат локально, сервер удаляется |
| DevOps agent | Chat-agent | Провайдер, целевая схема, ограничения, runbook | Готовит checklist, команды, deploy/rollback-plan |
| Test-case agent | Chat-agent | Описание фичи, бизнес-правила, статусы, команды | Предлагает сценарии тестирования: unit, integration, recovery, edge cases |

### Финансы

**Верхний расход этапа:** до $50/мес при редком использовании.

Верхний расход до $50/мес при редком использовании. Если cloud production + API уже стоят $430/мес, общий расход $480/мес, свободный приток ≈ $20/мес.

## Этап 5.2. GPU cloud lab

### Что делаем

- Создать GPU-сервер под задачу.

- Скачать результат локально.

## Этап 5.4. Ephemeral workflow

### Цель

Автоматизировать ephemeral workflow.

### Что делаем

- Скрипт создания сервера.
- Скрипт загрузки данных.
- Скрипт выполнения задачи.
- Скрипт скачивания результата.
- Скрипт удаления сервера.

### Результат этапа

Cloud lab становится повторяемым процессом, а не ручной настройкой каждый раз.

### AI-support

| Агент | Тип | Контекст | Права |
| --- | ---: | ---: | ---: |
| DevOps agent | Chat-agent | Провайдер, целевая схема, ограничения, runbook | Готовит checklist, команды, deploy/rollback-plan |
| Cloud execution agent | Cloud-agent | Временно загруженный проект/datasets/configs | Выполняет задачу, отдаёт результат локально, сервер удаляется |
| Codex task builder | Chat-agent | Утверждённое решение, ограничения, структура проекта | Готовит coding task/prompt для Codex |

### Финансы

**Верхний расход этапа:** $0.

Расходов нет кроме фактических часов cloud lab.
