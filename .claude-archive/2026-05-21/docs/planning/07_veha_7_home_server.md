Цель вехи — поэтапно прийти к собственной мощной вычислительной базе, не покупая дорогую конфигурацию вслепую.

## Этап 7.1. Базовый dev/backtest/server

### Цель

Собрать базовый домашний dev/backtest/server.

### Что делаем

- Подобрать железо.
- Подготовить storage.
- Развернуть БД/Kafka/monitoring.
- Перенести backtest workers.
- Развернуть agent-runner.

### Результат этапа

Появляется постоянная домашняя вычислительная база без сильного AI-упора.

### AI-support

| Агент | Тип | Контекст | Права |
| --- | ---: | ---: | ---: |
| DevOps agent | Chat-agent | Провайдер, целевая схема, ограничения, runbook | Готовит checklist, команды, deploy/rollback-plan |
| Architecture discussion agent | Chat-agent | Текущие доки, спорные вопросы, модели, ограничения | Обсуждает варианты и последствия; не фиксирует решения без пользователя |
| Cloud execution agent | Cloud-agent | Временно загруженный проект/datasets/configs | Выполняет задачу, отдаёт результат локально, сервер удаляется |

### Финансы

**Верхний расход этапа:** до 2 500€ ≈ $2 750.

Верхний бюджет 2 500€ ≈ $2 750. При свободном $500/мес без текущих расходов ожидание 6 мес; с cloud/API — дольше. При решении переходить нужен разовый бюджет ~$2 750.

### Что делаем

- Подобрать GPU.
- Добавить RAM.
- Добавить SSD.
- Запустить локальные coder-модели.
- Запустить RAG.
- Проверить параллельных агентов.
