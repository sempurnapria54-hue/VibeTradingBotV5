### Получить свечи (последние) (REST)

**Endpoint:** `GET /api/v5/market/candles`

**Что делает простыми словами:**

* Возвращает **последние** свечи по инструменту (без авторизации).
* Лимит этого эндпоинта — **до 1 440 последних свечей** (по выбранному `bar`).

**Доступ / лимиты / аутентификация:**

* Permission: Public
* Rate limit: **40 запросов / 2 секунды**, правило — **IP**
* Auth headers: **не нужны**

---

## Query-параметры

* `instId` (**обязательный**) — имя инструмента на бирже, например `ETH-USDT-SWAP`.
* `bar` (опционально) — размер свечи. По умолчанию `1m`.

  * Примеры: `1m/3m/5m/15m/30m/1H/2H/4H`
  * Дневные/недельные/месячные: `6H/12H/1D/2D/3D/1W/1M/3M` (**открытие по UTC+8**)
  * Те же интервалы, но с открытием по **UTC+0**: `6Hutc/12Hutc/1Dutc/2Dutc/3Dutc/1Wutc/1Mutc/3Mutc`
  * ⚠️ **Регистр важен**: `1H` ≠ `1h`, `1Dutc` ≠ `1DUTC`.
* `after` (опционально) — пагинация: вернуть свечи **строго старше (раньше)** указанного `ts` (ms).
* `before` (опционально) — пагинация: вернуть свечи **строго новее** указанного `ts` (ms).

  * Если передать **только `before`**, биржа вернёт **самые последние** данные.
* `limit` (опционально) — количество свечей в ответе.

  * Максимум: `300`
  * По умолчанию: `100`

---

## Важные особенности

1. **Порядок свечей** в `data` — обычно **от новых к старым** (самая свежая первая).

2. Поле `confirm`:

* `0` — свеча **ещё не закрылась**, данные могут меняться.
* `1` — свеча **закрыта**, данные финальные.

3. Первая свеча в ответе может быть **неполной** (`confirm=0`).

* Её **не стоит** «дёргать» бесконечно в цикле — достаточно нормального polling-интервала.

---

## Пример запроса

```bash
curl -X GET 'https://www.okx.com/api/v5/market/candles?instId=ETH-USDT-SWAP&bar=1m&limit=100' \
  -H 'Content-Type: application/json'
```

## Описание полей ответа

**Верхний уровень:**

* `code` — код результата. `"0"` = успех.
* `msg` — сообщение об ошибке (обычно пустое при успехе).
* `data` — массив свечей.

**`data[i]` — одна свеча, массив строго из 9 элементов:**
Формат: `[ts, o, h, l, c, vol, volCcy, volCcyQuote, confirm]`

* `ts` — время **открытия** свечи (Unix ms).
* `o` — Open (цена открытия).
* `h` — High (максимум за свечу).
* `l` — Low (минимум за свечу).
* `c` — Close (цена закрытия).
* `vol` — торговый объём.

  * Для **SPOT**: количество в **базовой валюте** (например BTC).
  * Для **SWAP/FUTURES**: обычно трактуют как объём в **контрактах** (точную единицу смотри в спецификации инструмента).
* `volCcy` — торговый объём (для **SPOT** — в **котируемой валюте**).
* `volCcyQuote` — торговый объём в **котируемой валюте** (например в USDT для `BTC-USDT`).
* `confirm` — закрыта ли свеча:

  * `0` — не закрыта
  * `1` — закрыта

## WS-заметка (чтобы не путаться)

Если тебе нужны свечи **в реалтайме**, у OKX есть публичный WS-канал (без логина):

* URL path: `/ws/v5/business`
* Каналы имеют формат **`candle<bar>`**, например: `candle1m`, `candle5m`, `candle1H`, `candle1D`, `candle1Dutc` и т.д.

Пример подписки:

```json
{
  "id": "1512",
  "op": "subscribe",
  "args": [
    {
      "channel": "candle1m",
      "instId": "ETH-USDT-SWAP"
    }
  ]
}
```
