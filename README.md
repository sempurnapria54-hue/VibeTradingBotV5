# Vibe Trading Bot

## На какой вопрос отвечает этот файл

С чего начать, впервые открыв репозиторий.

Алготрейдинговый бот. Java 25 + Spring Boot 4 + PostgreSQL.
Базовые правила проекта — `CLAUDE.md`; карта базы знания —
`.claude/knowledge-tree.md`.

## Запуск зависимостей (Postgres + Vault)

```bash
docker compose up -d
```

Vault UI — <http://localhost:8200>. Инициализация, unseal и запись
секретов, а также проброс `VAULT_TOKEN` — `.claude/skills/environment-commands.md`
§«Воспроизводимые команды»: там же живут проверенные прогоном пути JDK и
Maven.

## Сборка и запуск

Команда сборки и лаунчер Python **здесь не дублируются** — у них один дом
(`.claude/skills/environment-commands.md` §«Факты среды — проверено
прогоном, не выведено»). Копия в этом файле стареет первой: две прежние
редакции README предписывали `./mvnw` и `mvn`, которых в среде нет.

Рантайм-прогон приложения делает пользователь в IDEA.

## Проверка

- `GET /actuator/health` сервиса — проба живости, открытая у каждого
  сервиса без предъявления.
- **Всё прочее требует bearer-токена провайдера идентичности**; открытые
  исключения перечислены классами в доме политики
  (`docs/rules/api-access-policy.md`), здесь только указатель.
