# tests/

## На какой вопрос отвечает этот файл

Что кладётся в этот каталог.

**Сквозной набор** — уровень 3 шага «Тесты»: тропы через несколько сервисов,
наблюдаемые только снаружи — поверхностью стороны, её базой, темой брокера и
журналами процесса. Один maven-модуль реактора, у которого есть только
`src/test`; ни во что он не собирается и единицей развёртывания не является,
поэтому лежит здесь, а не в `services/` (довод и отвергнутые места —
`.claude/decisions/test-contour-design-pass.md`, решение 8).

**Чёрный ящик одного сервиса сюда не кладётся** — он предмет одного владельца и
живёт в `src/test` своего сервиса; сквозное — ничьё.

**Сторона тропы — процесс, поднятый jar'ом своего модуля**, поэтому набор
гоняется фазой `verify`, а не `test`: `mvn -o -am -pl tests verify`. Без jar'ов
либо на jar'е старше классов своего модуля прогон отказывает «не измерялось», а
не пропускается.

Набор тестов системы целиком, все три уровня — `.claude/tests/test-suite.md`.
Устройство сквозного набора — `.claude/skills/test-code.md` §«Уровень 3 — сквозной
набор»; кейсы троп — `.claude/tests/cases/e2e-*.md`; метки прогона — `e2e`
(в каждом прогоне) и `smoke` (против стенда, по расписанию).
